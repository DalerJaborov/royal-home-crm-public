# Somon owner leads

Monitoring is disabled by default. A paginated ID-only baseline must finish before any advertisement can be sent. Later first observations have an explicit uncertain-date warning; they are not asserted to be new publications. A non-business profile with at most two active real-estate ads may pass without an explicit owner claim. When the total number of ads is greater than two, a complete seller profile and individual categories are checked incrementally under the shared rate limit. Incomplete or unsupported profiles are held for manual review. These signals do not prove ownership.

Source requests use a database-backed budget and lease. 403 stops the source; 429 and network/5xx errors pause it. The listing scan has a durable cursor and warns if the coverage limit or a backlog is reached. The Telegram send is reserved atomically and fenced against stop/recipient changes; an unconfirmed result is never automatically replayed. Contact fingerprints are keyed and phone values/photos are not stored. Accepted receipts expire; minimal seen IDs and contact fingerprints are retained to suppress duplicate outreach. The keyed fingerprints depend on the current settings encryption key: key rotation requires an explicit migration/disable plan before use.

Targeted tests cover access control, source leases, baseline, provider errors and concurrency on an isolated database. Exact original publication times and ownership cannot be established reliably from the observed source fields. Categories may change during inspection, source counts can be inconsistent, and large or incomplete profiles require manual review. Full official CRM release gates and separate production acceptance are required for changes.
