# Shabnam synthetic group evaluation

This opt-in suite replays 24 fictional group scenarios through the production Telegram adapter and reply formatter. Each case has a stable ID, a human-assigned input language and an expected route. Review failed case IDs and their assertions individually, especially unexpected write eligibility or sensitive tools in a read-only turn.

Run from the repository root in PowerShell after installing the existing workspace dependencies and building the shared package.

~~~powershell
$env:SHABNAM_CONVERSATION_EVAL = '1'
Push-Location apps/api
node ../../node_modules/vitest/vitest.mjs run --maxWorkers=1 --reporter=verbose tests/assistant-conversation-eval.unit.test.ts
Pop-Location
Remove-Item Env:SHABNAM_CONVERSATION_EVAL
~~~

For a version comparison, use separate worktrees and copy only the same `assistant-conversation-eval.unit.test.ts` and `helpers/assistantGroupFixture.ts` into each revision's `apps/api/tests` directory. Run the command in each worktree. Add `--reporter=json --outputFile=<local-report-path>` if a machine-readable comparison is needed.

The adapter calls inert substitutes for the model, CRM, Telegram, speech and the public catalog. The suite checks route, relevant tool availability, confirmation eligibility, and selected formatting and delivery rules. It grades a few Russian and Tajik labels generated by the adapter itself. It does not grade the model's prose or language, run CRM write tools or validate real Telegram, audio or the database. The fixture keeps the existing focused unit tests independently runnable.
