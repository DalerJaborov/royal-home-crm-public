# voice-separator

Маленький HTTP-сервис: берёт звук видео и убирает из него голос, оставляя музыку.
Нужен для авто-озвучки: ролик с чужим закадровым голосом -> чистая музыка -> новая озвучка поверх.

Внутри: `audio-separator` (модель `Kim_Vocal_2.onnx`, CPU) отделяет голос, затем `faster-whisper small`
слушает то, что осталось от музыки, и считает слова. Если слов много, голос не убрался и такую музыку брать нельзя.

Запросы обрабатываются строго по одному (это и есть очередь). Модели грузятся при старте и лежат в памяти.

## Запуск

```
docker build -t royalhome-voice-separator apps/voice-separator
docker run -d --name voice-separator -p 8090:8090 royalhome-voice-separator
```

Модели скачиваются при сборке образа (в `/models`), во время работы интернет не нужен.
Порт: `PORT` (по умолчанию 8090). Прочее: `SEPARATOR_MODEL`, `WHISPER_MODEL`, `MODELS_DIR`, `WORK_ROOT`.
Потоки процессора по умолчанию = все ядра.

## Как вызвать

Проверка готовности (отвечает 200, когда обе модели загружены):

```
curl http://localhost:8090/health
# {"ok": true, "model": "Kim_Vocal_2.onnx"}
```

Разделение: тело запроса = аудиофайл (лучше WAV 44.1 кГц стерео; принимается всё, что читает ffmpeg).
Обязателен `Content-Length`; не больше 200 МБ и 600 секунд звука.

```
curl -X POST --data-binary @voice.wav -D headers.txt -o music.flac http://localhost:8090/separate
```

Ответ 200: тело = музыка без голоса (FLAC, 44.1 кГц стерео), `Content-Type: audio/flac`. Заголовки:

| Заголовок | Что значит |
|---|---|
| `X-Speech-Words` | сколько слов распознано в оставшейся музыке (целое) |
| `X-Speech-Seconds` | сколько секунд речи найдено (1 знак) |
| `X-Separate-Ms` | время разделения, мс |
| `X-Check-Ms` | время проверки на речь, мс |
| `X-Speech-Text` | первые 200 знаков распознанного текста, URL-кодированный UTF-8 (может быть пустым) |

Ошибки: JSON `{"error": "..."}` с кодом 400 (не аудио, пусто, дольше 600 с), 413 (больше 200 МБ), 500 (сбой разделения).
Сервер на плохом запросе не падает; в лог идёт одна строка на запрос (длительность, мс, слова), без звука.
