## D. Дубли и шум (мнение по прочитанному, ОЦЕНКА)

1. **Озвучка объявляется трижды одной мыслью:** (1) строка в подписи 1-го файла `🎙 Озвучка одобрена: mp3 придёт сразу после файлов…`, (2) хвост под «Отправлено N из N» `🎙 Озвучка — следующим сообщением…`, (3) подпись к самому mp3 `Озвучка к ролику №N, версия R, одобрена. Вклейте этот голос сами…`. Плюс текст озвучки внутри подписи (или вторым сообщением).
2. **«Задерживается» дважды:** строка в задании (`narrationLine`) и отдельное сообщение A4 (с копией false, т.е. наблюдатель не видит).
3. **«Без озвучки» дважды:** строка в задании (`🔇 Без озвучки…`) и отдельное сообщение A5 при переключении (copy true).
4. **Итог «Отправлено N из N»** дублирует «файл i из N» в каждой подписи + строку «Дальше в очереди: K роликов» в подписи файла 1 + кнопки очереди; для одного файла итог (N=1) — чистый шум.
5. **Факты карточки под каждым файлом** (7 строк × N файлов, решение 19.09) — осознанный дубль.
6. **Квитанция несёт 3-4 факта сразу** (принят/публикация, строка файла, «Озвучку CRM наложила», «остался старый ролик»), а результат публикации приходит отдельным пушем; «✅ Что я сдал» читает первую строку квитанции.
7. **«Объект №N передан другому монтажёру»** — один текст в двух местах кода (`montajerHandover.ts:84` и `routes/settings.ts:1888`): кандидат на одну дверь.
8. **Формат номера разный:** везде «Объект №N», в A6 `ОБ-…` (`formatShortCode`).
9. **Копирование наблюдателям несогласованно:** вопрос «чей ролик» (с кнопками) копируется, а отказ «сейчас не ждёт от вас ролик» без кнопки (то же событие) — нет; A4 не копируется, A5 копируется.
10. **Мёртвый код:** просьба о втором файле «без голоса» (`voicelessCopyAsk`, `VOICELESS_COPY_HINT`, кнопки `mj:nv`, `mj:nvx`) выключена константой, но тесты и разбор остались; `bot.ts:648` «Это личный чат с CRM-ботом…» недостижим для монтажёра.
