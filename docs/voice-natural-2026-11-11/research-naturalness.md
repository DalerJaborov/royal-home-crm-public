# Как сделать телефонного голосового агента ElevenLabs максимально живым (ноябрь 2026)

Метки: ФАКТ (ссылка на первоисточник, читал 11.11.2026) / ОЦЕНКА (мой вывод) / НЕТ ДАННЫХ. Код не менялся, платных вызовов не было. Читал код и память проекта только чтобы привязать выводы.

## 0. Главное за минуту

1. Фоновый шум: у ElevenLabs он ЕСТЬ (раздел «Audio environment»), по умолчанию громкость 0,15, а в старой справке проекта (`docs/robot-voice-options-2026-10-09.md` стр. 74) написано «не нашлось». Если в новом аккаунте у агента включён `background_sound` или фильтр `phone`, это первый кандидат на «голос стал хуже». Проверка: выключить и сравнить на 3 живых звонках. На G.711 фон я бы выключил совсем (раздел 3).
2. Скорость: `speed` НЕ работает на v3, v4 и v4 Turbo. Память проекта говорит «speed 1.15» на eleven_v4_turbo, значит значение, скорее всего, молча игнорируется. Темп надо задавать текстом, тегом `[slow]`, паузами и длиной реплик.
3. Таджикский синтез есть только у v3, v3 Conversational, v4, v4 Turbo. У Flash v2.5 и Multilingual v2 таджикского НЕТ. Русский есть у всех.
4. Главный источник «ИИ-звучания» не голос, а текст: длинные реплики, списки, канцелярит, «Понимаю», одинаковые зачины. Все вендоры сходятся на 1-2 коротких предложениях и одном вопросе за ход.
5. Числа, цены, телефоны, адреса: писать СЛОВАМИ до синтеза (на tg замеры проекта показали, что цифры читаются с ошибками).

## 1. Голос и настройки ElevenLabs

- ФАКТ: для агентов реалтайм-модели Flash v2.5 и Eleven v4 Turbo (~100 мс задержка в таблице моделей); v4 Turbo названа самой выразительной для агентов. https://elevenlabs.io/docs/overview/models.md
- ФАКТ: у v4/v4 Turbo доступны только Stability и Similarity; Style и Speed недоступны, SSML `<break>` не поддерживается. https://elevenlabs.io/docs/overview/capabilities/text-to-speech/eleven-v4
- ФАКТ: Stability 0,30–0,50 даёт эмоциональную, живую подачу (иногда нестабильную); 0,60–0,85 стабильную, но монотонную. Similarity: выше = чётче, но очень высокие значения искажают. Малые изменения заметно меняют «характер». https://elevenlabs.io/docs/eleven-agents/customization/voice/best-practices/conversational-voice-design.md
- ФАКТ: «самые естественные разговоры идут на 0,9–1,1x»; диапазон speed 0,7–1,2, но только для Flash v2/v2.5. https://elevenlabs.io/docs/eleven-agents/customization/voice/speed-control.md
- ОЦЕНКА (рекомендуемое для старта, дальше крутить на слух): v4 Turbo, Stability 0,40–0,45 (проект уже использовал 0,45 для Elena), Similarity около 0,75, без Style. Если реплики «плывут» между звонками, поднять Stability до 0,5. Если звучит как диктор, опустить до 0,35.
- ФАКТ: тот же сторонний совет «0,35–0,45» стоит в справке проекта; официально задан только диапазон 0,30–0,50 для живой подачи.
- ФАКТ (клон голоса на v4): v4 воспроизводит дефекты обучающего аудио, в том числе фоновый шум и искажения; Clone Strength для большинства голосов начинать с 0%. https://elevenlabs.io/docs/overview/capabilities/text-to-speech/eleven-v4 Это важно для «клона сотрудника» (план проекта для tg): запись должна быть чистой, без шума.
- ФАКТ: при разных языках голоса и текста v4 говорит на целевом языке без акцента образца; при одном и том же языке сохраняется акцент образца. В библиотеке голосов с языком tg нет (замер проекта 11.11, skill tajik-phrasebook/phone-voice.md).
- ФАКТ: поддержка языков агента: «язык фиксирован на весь звонок», для каждого языка лучше свой голос из библиотеки (пресеты языков). https://elevenlabs.io/docs/eleven-agents/customization/voice/customization/language.md

### Expressive mode и теги
- ФАКТ: expressive mode включается сам при модели `eleven_v4_turbo`; теги, которые может выдавать LLM: `[laughs]`, `[whispers]`, `[sighs]`, `[slow]`, `[excited]`; каждый действует на ~4–5 слов; выразительность различается по голосам и языкам, каждый язык тестировать. https://elevenlabs.io/docs/eleven-agents/customization/voice/expressive-mode.mdx
- ФАКТ: в промпт нужно явно вписывать, когда какой тег: «[laughs] для юмора, [slow] для ключевой информации»; ElevenLabs рекомендует задавать тон правилами в промпте, а не надеяться на модель.
- ФАКТ: тон «вставлен в системный промпт» назван местом, где живёт основная разница; разрешение на самоисправление на ходу («ой, то есть…»), пауза после серьёзной новости, зеркалить эмоцию. https://elevenlabs.io/blog/webinar-recap-building-ai-agents-that-sound-natural
- ФАКТ (Vapi): смех не чаще 1 хода из 4–5, не открывать два хода подряд смехом. https://docs.vapi.ai/prompting-guide
- ОЦЕНКА для вашего канала: на 8 кГц шёпот, вздох и смех плохо различимы (нет верхов), поэтому из тегов держать только `[slow]` (на цифрах и суммах) и очень редко `[sighs]`/`[laughs]` (1 на звонок максимум). На таджикском expressive-эффект непроверен: сначала А/Б на слух. Память проекта: expressive уже был ВЫКЛ, это нормальное безопасное состояние.

### Паузы
- ФАКТ: у v4/v3 `<break time>` не работает; паузы делать многоточием `…`, тире, запятыми, структурой текста; заглавные буквы дают нажим («ВОТ это»). https://elevenlabs.io/docs/best-practices/prompting и https://elevenlabs.io/docs/overview/capabilities/text-to-speech/best-practices
- ФАКТ (Vapi): запятые и точки дают стабильную просодию у всех TTS; тире и SSML ведут себя непредсказуемо, проверять на своём голосе.
- ФАКТ: теги `[pause]`, `[short pause]` встречаются в примерах v4, но в списке агента (expressive) их нет: в агенте надёжны только пять тегов выше.
- Образец текста для промпта: «Короткие паузы делай запятой или многоточием. Не используй тире и скобки в реплике: их голос читает странно.» (ОЦЕНКА: в проекте уже есть запрет «—» в публичных текстах.)

## 2. Ход разговора: перебивание, паузы, филлеры

- ФАКТ: turn eagerness: eager / normal / patient. Eager для быстрых сервисных звонков; по умолчанию везде eager делает агента «напористым»; patient на моменты, когда человек диктует номера, почту, адрес. Менять посреди звонка можно через Workflows. https://elevenlabs.io/blog/what-is-turn-taking и https://elevenlabs.io/blog/webinar-recap-building-ai-agents-that-sound-natural
- ФАКТ: поле `spelling_patience` (auto/off): агент ждёт дольше, когда человек диктует цифры и названия; `speculative_turn`: начинает генерировать ответ в паузе, ниже воспринимаемая задержка, но дороже по LLM. https://cdn.jsdelivr.net/npm/@elevenlabs/elevenlabs-js@2.51.0/api/types/TurnConfig.d.ts
- ФАКТ: человеческая пауза между репликами ~200 мс; у ElevenLabs 142 мс медиана до звука на v4 Turbo; реальное перебивание останавливает речь за <200 мс. https://elevenlabs.io/blog/what-is-turn-taking
- ФАКТ: soft timeout: `timeout_seconds` 0,5–8, рекомендуют 3,0; по умолчанию выключен (-1); filler произносится один раз за ход; можно LLM-генерируемый filler. С июня 2026: до 7 дополнительных фраз и `max_soft_timeouts_per_generation` 1–8 (по умолчанию 1). Дефолтная фраза «Hhmmmm...yeah.» (1–200 знаков): её для русского и таджикского ОБЯЗАТЕЛЬНО заменить (поддерживает языковые переопределения). https://elevenlabs.io/docs/eleven-agents/customization/conversation-flow и https://elevenlabs.io/docs/ja/changelog/2026/6/8
- ОЦЕНКА: soft timeout 2,5–3 с; 5-7 коротких фраз вроде «Секунду…», «Так, смотрю», «Сейчас гляну», «Угу, минутку», чтобы не повторялась одна и та же. Для tg: «Як дақиқа», «Ҳозир мебинам» (?) (проверять носителем).
- ФАКТ: слова-подтверждения человека («угу», «ага») можно внести в список игнорируемых при перебивании, чтобы агент не обрывал себя на каждом «угу»; интеракции можно отключать для юридических фраз. https://elevenlabs.io/blog/what-is-turn-taking
- ФАКТ: `turn_model` turn_v3 по умолчанию (turn_v2 можно выбрать). Новое распознавание по умолчанию с июня 2026 `scribe_realtime`. https://elevenlabs.io/docs/ja/changelog/2026/6/8
- ФАКТ: Retell: backchannel и «natural filler words» отдельные настройки; филлеры экономно (~раз в 2–3 предложения), backchannel_frequency по умолчанию 0,8 у них. У ElevenLabs отдельного исходящего backchannel («угу» пока человек говорит) в документации НЕТ (НЕТ ДАННЫХ), только игнор-лист. https://docs.retellai.com/build/interaction-configuration.md (по пересказу поиска)
- Sesame (ФАКТ): ключевое для «присутствия»: естественный тайминг, паузы, перебивания, ударения, подстройка тона, постоянный характер. https://sesame.com/research
- Vapi/OpenAI-совет по филлерам: 2–4 «неполированных» признака на ход, если ход слишком гладкий, добавить зачин и переформулировать; для деловой роли «дай мне посмотреть», «секунду» вместо «э-э»; подстраиваться под собеседника: торопится, филлеров меньше. https://docs.vapi.ai/prompting-guide
- ОЦЕНКА для агентства недвижимости: филлеров в TTS-тексте мало и только разговорные («ну», «так», «значит», «слушайте»), не «эээ»: на 8 кГц и ASR-шуме «эм/ээ» легко превращаются в артефакт. Память проекта: «заполнители ВЫКЛ» ставилось: оставьте выключенным у ElevenLabs-механизма и делайте живость текстом.

## 3. Телефон G.711 8 кГц: голос и фоновый звук

- ФАКТ: SIP у ElevenLabs использует G.711 (PCMU/PCMA) на 8 кГц или G.722 на 16 кГц; формат аудио агента для WebSocket на SIP не влияет; G.722 это единственный «широкополосный» вариант, если провайдер его поддерживает. https://elevenlabs.io/docs/eleven-agents/phone-numbers/sip-trunking.md
- ФАКТ: полоса телефона ~300–3400 Гц; при 8000 отсчётов/с всё выше 4 кГц отбрасывается: пропадают «с», «ф», «ш» (шипящие), дыхание, «воздух» и присутствие, на которых держится «живость»; «пятьдесят» и «шестьдесят» могут сливаться; голос, тёплый и близкий в кабинете, на линии бывает глухим. Рекомендация: выбирать голос, который остаётся чётким в телефонной полосе, и тестировать его по реальному телефонному пути, а не в кабинете. https://www.assemblyai.com/blog/mu-law-vs-a-law-text-to-speech-phone-calls
- ФАКТ (там же): запрашивать у TTS сразу нужный формат (8 кГц), а не пересэмплировать самому; апсемплинг 8→16 кГц добавил шипение, из-за которого VAD терял ходы; пакеты µ-law дополнять байтом тишины 0xFF, а не нулями (клик/шум). Применимо к вашему мосту: `elevenLabsVoiceClient.ts` по умолчанию берёт `pcm_16000` и парсит `ulaw_8000`; (ОЦЕНКА) проверить, не лучше ли просить `ulaw_8000` у агента напрямую, а собственный пересэмплер 16→8 оставить только как запас.
- ФАКТ: качество G.711 «toll» (MOS ~4,1–4,3). https://www.voipmonitor.org/doc/Audio_Codecs_-_Comprehensive_Guide
- ФАКТ: фоновый звук ElevenLabs: presets `office1`, `office2`, `restaurant`, `city`, `typing`, `elevator1`–`4`; громкость по умолчанию 0,15 (диапазон 0,01–1,0 относительно голоса); петля с кроссфейдом; микшируется ПОД голос ПОСЛЕ фильтра голоса; фон не слышит ни агент, ни распознавание; своего файла нельзя загрузить; в предупреждениях: на плохом соединении микширование фона может давать «рваный» звук; отключение: `source_type`/`source_id` = null (простое отсутствие поля при обновлении НЕ выключает!). https://elevenlabs.io/docs/eleven-agents/customization/voice/audio-environment.md
- ФАКТ: отдельный «голосовой фильтр» `tts.audio_effects.filter_preset_id` (пример `"phone"`) искусственно делает голос «телефонным». ОЦЕНКА: на настоящей телефонной линии он дважды срезает полосу (сначала фильтр, потом G.711), для живых звонков по PSTN его нужно держать выключенным; он нужен только для демо в браузере.
- ФАКТ (другие вендоры): у Vapi `backgroundSound` по умолчанию «office» именно на звонках по телефону и выключен в веб; в форуме Vapi есть жалобы «annoying noise when calling by phone number»; Dasha рекомендует 0,3–0,5 «едва заметно», 0,4 как старт, и «снизить или выключить, если страдает разборчивость». https://support.vapi.ai/t/27563301/background-office-sounds , https://blackbox.dasha.ai/docs/advanced-features/ambient-noise
- ФАКТ: в Retell-форуме ровный фон прятал артефакт речи, а после выключения артефакт стал слышен; это значит: фон может и маскировать, и ухудшать; а PSTN даёт ещё µ-law компандирование. (по пересказу поиска, это чужой вендор)
- ОЦЕНКА (механизм, почему шум портит голос по телефону): (1) G.711 8-битный логарифмический: шум занимает часть динамического диапазона и добавляется к квантовому шуму; (2) шум и речь делят одну узкую полосу 300–3400 Гц, фон маскирует именно согласные (разборчивость падает раньше, чем «громкость»); (3) оператор/сотовый кодек и шумоподавитель на стороне слушателя (VAD/denoise в телефоне) воспринимают микс «речь+постоянный шум» и «пампят» (качает громкость) голос; (4) петля фона слышна как повтор; (5) настоящая запись клона с шумом (v4 повторяет шум обучающего аудио).
- Рекомендация (ОЦЕНКА): фон выключить; «живость» делать паузами, длиной реплик и текстом, а не микшированием. Если очень нужен «офис»: `office1`, громкость 0,03–0,05 (ниже дефолтных 0,15; слух сверить по ТЕЛЕФОНУ, не по наушникам кабинета), без фильтра `phone`. Если звонок идёт через ваш мост, а не SIP-транк ElevenLabs, проверить, не микшируется ли фон дважды (код проекта: `grep ambient apps/api/src` ничего не нашёл, амбиента в коде сейчас нет, значит это настройка в кабинете ElevenLabs).
- ФАКТ: tool call sounds (Typing / Elevator) играют только во время выполнения инструмента; по умолчанию режим «только если агент заговорил перед вызовом»; для операций до ~1 с лучше «нет» или «Typing», для >3 с «elevator»; при перебивании останавливаются. https://elevenlabs.io/docs/eleven-agents/customization/tools/tool-configuration/tool-call-sounds.md ОЦЕНКА: на 8 кГц музыку лифта лучше не включать (тот же аргумент), поиск объекта заполнять фразой.
- Как проверить ухом (предложение, ОЦЕНКА): один и тот же сценарий 3 звонка подряд: (а) фон выкл, фильтр выкл; (б) office1 0,05; (в) office1 0,15. Один голос, одна фраза, оценивать «звучит как человек?» и «чётко ли слышно числа и суммы». Без звонка владельцу: через симуляции/записи.

## 4. Текст реплик: как не звучать как ИИ

ФАКТ (общее у Vapi/OpenAI, ElevenLabs, Retell):
- 1–2 предложения на ход; не более 2–3 вариантов за раз; длинный список: назвать 2 и спросить «ещё?». https://docs.vapi.ai/prompting-guide
- Один вопрос за ход; одно поле собрать, подтвердить, идти дальше. https://elevenlabs.io/blog/how-to-prompt-a-conversational-ai-system
- Никакого markdown, заголовков, списков, URL; вместо перечня «сначала… потом… и ещё…». Модели по умолчанию любят списки, это надо запретить явно.
- Ответ «только строкой, которую надо произнести» (без ремарок, звёздочек, скобок).
- Читать подтверждение высокоточных данных (номера, суммы, имена) обратно один раз; для обычной квалификации просто короткое «ага, понятно» без пересказа. https://docs.vapi.ai/prompting-guide
- Перед долгим действием сказать, что делаешь («секунду, смотрю базу»). https://elevenlabs.io/blog/how-to-prompt-a-conversational-ai-system
- Не знаешь: коротко и прямо, без извинений и выдумок; «записал для команды», а не «сделано» (запрет ложного завершения).
- Промпт ≤ ~2000 токенов; повторять 1–2 критичных правила; раздел `# Guardrails` получает особое внимание модели. https://elevenlabs.io/docs/agents-platform/best-practices/prompting-guide
- Тон задавать один раз, не дублировать по промпту.

ОЦЕНКА (разговорные частицы и подтверждения для RU, 8–10 штук, чередовать, не повторять подряд): «ага», «угу», «так», «понятно», «ясно», «хорошо», «ну да», «отлично», «секунду», «слушайте». «Понимаю/Я вас понимаю» только на жалобу и раз за звонок (в проекте уже правило из `liveVoiceConsultantPersona.ts`). «Конечно», «безусловно», «с удовольствием помогу» убрать (канцелярит-маркеры ИИ).
ОЦЕНКА: убрать: «Чем могу вам помочь?», «Благодарим за обращение», «в рамках», «осуществить», «данный», «ваш запрос», тире «—», двоеточия, скобки, эмодзи, «Конечно!» в начале каждого хода.

### Образец блока для промпта (RU, ОЦЕНКА, составлен по перечисленным источникам)
```
# Как ты говоришь
Ты говоришь по телефону, а не пишешь. Один-два коротких предложения за раз, потом пауза для собеседника.
Один вопрос за раз. Ответ начинай с живой реакции на то, что человек сказал: «ага», «понятно», «ну да». Не повторяй один и тот же зачин два хода подряд.
Никаких списков, перечислений, тире, скобок, звёздочек. Варианты называй одним предложением: «есть двушка в Сино и такая же в Исмоили Сомони, какая интереснее?».
Если потерял мысль, скажи это по-человечески и начни фразу заново. Пока ищешь, скажи что делаешь: «секунду, смотрю».
Говори на «вы». Имя человека используй один раз. Слово «понимаю» только если человек недоволен.
Если не знаешь, скажи «это точно скажет агент» и ничего не придумывай.
# Числа, цены, адреса (ВАЖНО)
Пиши числа только словами, как их произносят вслух: «шестьдесят тысяч долларов», «двухкомнатная, на пятом этаже из девяти».
Телефон диктуй группами по две-три цифры словами с запятыми: «девять ноль ноль, двенадцать, тридцать четыре, пятьдесят шесть».
Время: «в три тридцать», «в половине четвёртого». Дату: «пятнадцатого ноября».
Адрес без сокращений: «улица Рудаки, дом двенадцать, квартира пять».
```

### Числа, цены, адреса, телефоны вслух
- ФАКТ: ElevenLabs: у TTS проблемы с цифрами и символами; два режима `text_normalisation_type`: `system_prompt` (по умолчанию: LLM сама пишет словами, без задержки, но иногда ошибается) и `elevenlabs` (нормализатор после LLM: надёжнее, чуть добавляет задержку). Телефон: «цифры по одной, группами». Для коротких моделей числа читаются хуже (Flash v2.5). https://elevenlabs.io/docs/agents-platform/best-practices/prompting-guide , https://elevenlabs.io/docs/best-practices/prompting/normalization
- ФАКТ: нормализация ElevenLabs документирована только на английском; правил для ru/tg нет. Для русского и таджикского писать словами самим.
- ФАКТ (проект, skill tajik-phrasebook/phone-voice.md, замер 11.11): на tg цифры читаются с ошибками («80» как «82»/«800», «65 000» как «650 ҳазор», «10:30» как «даҳ сиву даҳ»); те же числа словами распознаны верно; при tg нормализацию ElevenLabs выключили (Codex 03.11). Значит: tg числа словами по правилу `packages/shared/spokenNumber`, в промпте тоже.
- ФАКТ (Vapi/Softcery): читать код/цифры по одному, «никогда не пропускай цифру»; повторять идентификаторы для подтверждения («вы сказали ноль, девять, …, верно?»); валюту называть словом, а не кодом. https://www.softcery.com/lab/voice-agent-prompt-engineering
- ФАКТ (Retell): телефон по цифрам с паузой между группами (разделитель в тексте); время «три тридцать PM»; даты «пятнадцатое января», а не 1/15. https://docs.retellai.com/build/prompt-situation-guide.md
- ФАКТ (ElevenLabs): на запись телефона от человека включать patient или `spelling_patience`, при диктовке не перебивать; при повторе назвать группами и спросить «верно?».
- ОЦЕНКА: цены в недвижимости: «шестьдесят две тысячи долларов», а не «62 тысячи $»; «шестьдесят две пятьсот» разговорная форма допустима, если так говорит наш агент; площадь «шестьдесят пять квадратов»; не называть три-четыре числа подряд: максимум два числа за реплику (цена и район), остальное по вопросу. Адреса: топонимы с ударением проверять словарём произношения (аlias-замена словом работает и на v4 Turbo/tg, замер 11.11 в phone-voice.md; но только слова с буквами ҳ ӯ ӣ қ ғ ҷ, иначе звучит и в русском).
- ФАКТ: словарь произношения: alias и phoneme (IPA/CMU); phoneme работает на v4, v4 Turbo, Flash v2, v3; на других моделях только alias; несколько словарей на агент; для заглавной и строчной формы отдельные записи. https://elevenlabs.io/docs/eleven-agents/customization/voice/pronunciation-dictionary.md

## 5. Как начинать звонок

- ФАКТ (Vapi): представиться по имени и компании, затем одно предложение-вопрос. Пример у них: «Привет, это Алекс из City Dental. Чем могу помочь?» Исходящий звонок: сразу сказать, кто звонит и зачем. https://docs.vapi.ai/prompting-guide
- ФАКТ: первая фраза агента фиксируется в `first_message` и машинно переводится LLM-ом для других языков: проверять вручную. https://elevenlabs.io/docs/eleven-agents/customization/voice/customization/language.md
- ОЦЕНКА RU, входящий: «Роял Хом, добрый день. Слушаю вас.» (одна короткая, не «Здравствуйте! Вас приветствует виртуальный ассистент компании…»). Исходящий: «Здравствуйте, это Лариса из Роял Хом. Вы оставляли заявку, удобно сейчас говорить?» (вопрос «удобно ли» даёт человеку право отказаться и снижает ощущение робота-обзвона).
- ОЦЕНКА TG (из `phone-voice.md` проекта): «Ассалому алайкум, Royal Home, гӯш мекунам.» / «Ассалому алайкум! Аз ширкати Роял Хом занг мезанем.» Без «лутфан» (решение владельца).
- ОЦЕНКА: не говорить «я голосовой помощник» без прямого вопроса (правило проекта 10.10); на прямой вопрос ответить честно и коротко. (Проверить юр. требования: в ряде стран закон требует раскрытия ИИ при звонке; для Таджикистана НЕТ ДАННЫХ.)

## 6. Таджикская часть

- ФАКТ: tg поддержан только моделями v3/v3 Conversational/v4/v4 Turbo. https://elevenlabs.io/docs/overview/models.md
- ФАКТ (проект, 11.11, phone-voice.md): в библиотеке голосов с языком tg нет; русский голос на таджикском даёт «аканье» и глотает «ҳ» на конце; словарь IPA с ударением помогает; оценивает носитель. Для максимальной «живости» на tg путь по плану проекта: клон голоса сотрудника-носителя на чистой записи (без шума, один стиль речи, v4 повторяет шум и дефекты записи).
- ФАКТ: распознавание без заданного языка уходит в арабский/турецкий; язык задавать.
- ОЦЕНКА: на tg реплики ещё короче (1 предложение), числа только словами, имя собственное и названия районов в словарь произношения; «лутфан»/«илтимос» не использовать; ответ на «спасибо» «Марҳамат»; прощание «Саломат бошед». Живые подтверждения брать из `references/live-agent-phrases.md` скилла tajik-phrasebook (80 фраз), частицы разговорной речи («хуб», «ҳа», «мефаҳмам» (?)) проверять носителем.

## 7. Что проверить в кабинете и коде у вас (список действий, ничего не менялось)

1. `background_sound`: null? `filter_preset_id`: null? (А/Б на 3 звонках, раздел 3.)
2. Модель агента: ru и tg `eleven_v4_turbo`; `speed` поле не влияет: убрать надежду на 1.15.
3. Stability ~0,40–0,45, Similarity ~0,75; свой голос на каждый язык.
4. Soft timeout 2,5–3 с, русские/таджикские фразы, 5–7 вариантов; дефолт «Hhmmmm...yeah.» заменить.
5. Turn eagerness: normal/eager в разговоре, patient (или `spelling_patience: auto`) на сбор номера телефона; для tg (медленнее распознавание, 1–2,3 с по замеру 24.10) eager + speculative_turn.
6. Формат аудио на мосту: проверить `ulaw_8000` вместо ресемплинга 16→8.
7. Промпт: блок «Как ты говоришь» + «Числа» (раздел 4), без списков и тире; ≤ 2000 токенов.
8. Для tg: числа словами, словарь произношения только для слов с ҳ ӯ ӣ қ ғ ҷ.
9. Проверять не на владельце, а симуляциями (правило владельца) и записью реального звонка на 8 кГц; слушать именно запись телефонного пути.

## 8. Не найдено / ограничения
- НЕТ ДАННЫХ: официального рецепта ElevenLabs для G.711 (кроме списка кодеков), громкости фона для телефона, влияния expressive mode на tg.
- НЕТ ДАННЫХ: страница «Prompting Eleven v4» в доступной мне версии почти не говорит про не-английский, филлеры и стабильность.
- Pipecat/Hume: по ним получил только общие вещи (задержка 500–800 мс круг, тестировать на 10–20 эталонных диалогах); ничего специфичного для вашего канала.
- Многое по Vapi/Retell у меня из поисковых пересказов, не из полных страниц (Retell filler/backchannel). Проверять перед применением.
- Сторонние блоги (growwstacks, callin.io и др.) в вывод не брал: цифры без источника.
