# Конституция оболочки «Нового вида» (пачка C, 20.11.2026)

Источник: разбор интерфейса 20.11 (`critic-uiux.md`, раздел «Конституция оболочки», п. 6, 12, 13, 15).
Решение владельца 20.11: одна оболочка без багов, старая тема удаляется.

## Одно место

Все числа шрифта, скруглений, теней и все цвета слоёв нового вида живут в одном блоке —
«КОНСТИТУЦИЯ ОБОЛОЧКИ» в `apps/web/src/theme-look-royal.css`. Остальные `theme-look-royal-*.css`
берут их только через `var(--…)`. Сторож — `npm run audit:look` (`scripts/audit-look.mjs`,
шаг `precheck` и CI; проверен поломкой — `scripts/audit-look.test.mjs`).

| Шкала | Было (слои нового вида) | Стало |
|---|---|---|
| Размер шрифта | 19 значений + 12 `clamp()` | 8 токенов `--rh-fs-xs…4xl`: 13 · 14 · 15 · 17 · 20 · 28 · 32 · 40; на телефоне и под пальцем sm 15, md 16 |
| Скругление | 25 значений | 4: `--rh-r-sm` 8 · `md` 16 · `lg` 24 · `full`; плюс 0 и 50% |
| Тень | 60 разных | 3: `--rh-ui-shadow-sm`, `--rh-ui-shadow`, `--rh-ui-shadow-lg`; линия без размытия (`0 0 0 1px var(--…)`) — граница, не тень |
| Цвет вне токенов | 90 литералов | 0 в слоях экранов; новые токены: выключатель, звонок, бренды каналов, затемнение, граница поля |
| Точки перелома | 19 | 6: 360, 390, 768, 820, 1024, 1440 (`max-width` на 0,02 меньше) |
| Переключатели | 6 видов | 2: **Segmented** (серый трек, выбранный на светлой таблетке) и **Tabs** (без трека, выбранный мягким синим); чёрная таблетка — только у меню |
| Кнопки | soft / gray / dark / primary | 4 вида: primary · secondary · ghost · danger; выключенная — с причиной подписью |
| Поля | заливка без рамки (1,2:1) | граница `--rh-ui-field-line` ≥ 3:1 к карточке, фону и подложке в обеих темах (тест) |

Точка 820 — граница телефонной разметки `useMobileUx` (`MOBILE_UX_QUERY`); когда разметка переедет
на 768, 820 уходит из списка. Перевод старых точек: «узкое» правило растягивалось ВВЕРХ до ближайшей
границы списка (640 → 767.98, 1100 → 1439.98; `min-width: 1180` → 1440) — полоса между ними получает
вид, уже придуманный для меньшего места, поэтому вылета за край перевод не добавляет.

## Компоненты (`apps/web/src/components/look/ui.tsx`)

- `RhSegmented` — радиогруппа, стрелки/Home/End, в Tab-порядке одна кнопка. Перенесены фильтр
  «Ждут / Мои / Все» чатов.
- `RhTabs` (разделы страницы, связь вкладка ↔ панель) и `RhNavTabs` (вкладки-ссылки). Перенесены
  вкладки карточки клиента.
- `RhButton` — `variant: primary | secondary | ghost | danger` (прежние имена — синонимы),
  `disabledReason` — кнопка выключена, причина видна под ней и озвучивается чтецом.
- `rhStepByKey` — одно правило клавиш для всех переключателей.

Прежняя разметка `.seg`, `.seg.rh-tabs`, `.seg-ai`, `.ry-ctabs`, `.ry-chats-switch` красится теми же
токенами `--rh-seg-*` / `--rh-tab-*`, поэтому вид один и там, где компонент ещё не подставлен.

## Сторожа геометрии

`tests/e2e/helpers/lookGeometry.ts` — три новых вида: `smallText` (текст < 13), `smallTap` (нажимаемое
< 44; ссылка в предложении не считается, флажок — по подписи, растянутая ссылка — по строке),
`selectClip` (выбранный пункт шире списка). Обязательны на экранах с кадров владельца (`@smoke`),
проверены поломкой; на всех 48 экранах — пока без них (сначала проход по разделам).

## База исключений

`.look-audit-baseline.json` — только четыре раздела директора (Отчёты, Реклама, Деньги, Контроль):
их в тот же день переделывает ветка `feat/look-director-sections`. После её влития — перевести на
токены и `npm run audit:look -- --shrink`. База только убывает.
