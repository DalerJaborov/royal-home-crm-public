# 20.11.2026 — Главная «Нового вида»: одно ядро на все роли, графики с анимацией, выключатели блоков

- Что изменилось:
  - Директор/админ, РОП и агент переведены на ядро главной `apps/web/src/components/look/home/`
    (как монтажёр, маркетинг, СБ, менеджер, акционер с #320). Блоки — компоненты в
    `blocks/director.tsx`, `blocks/rop.tsx`, `blocks/agent.tsx`, состав и порядок — `registry.tsx`
    (`HOME_BLOCKS`, `HOME_LAYOUT`), `pages/TodayRoyal.tsx` — тонкая обёртка. Копии
    `greetingFor`/`useMinuteNow`/`channelBrand`/`monthPace` из TodayRoyal убраны, одно место — `time.ts`.
  - Одна граница ошибок блока: ядро теперь ставит общую `components/BlockBoundary.tsx` (журнал
    `[блок today.<id>]`, «Повторить» перезапрашивает упавшее, вкладка на старой сборке получает
    «Обновить страницу»), а не свою копию; заглушка с именем блока встаёт в его клетку сетки (`span`).
  - Нужные данные роли без новых запросов: у директора — «Заявки за 30 дней» (`marketing.pulse30`) и
    «Комиссия по месяцам» (`commission12`, только при праве на деньги) из уже приходящего снимка; у
    агента — «Позвонить сейчас» (`firstCallDue` + `assignedBySupervisor` сводки, без номеров) и «Мой
    месяц» (`funnel` сводки, за месяц — проверено по routes/dashboard.ts). У РОП — «Графики по
    команде» (`TeamCharts`: `/dashboard/charts`, `/dashboard/insights` — существующие маршруты,
    право `dashboard.analytics` проверяет сам компонент): единственные новые запросы, и только у РОП.
  - Графики появляются с анимацией (столбики от оси, полосы от края, плита плана слева направо):
    только `transform`, только под `prefers-reduced-motion: no-preference`, один раз при появлении.
    Библиотек не добавлено — общие `Rh2BarChart`/`Rh2Bars` (`charts.tsx`). Чистая оболочка гасит
    ЛЮБОЕ движение (`html[data-shell="clean"] * { animation: none !important }`), поэтому у графиков
    главной — `!important` с более точным селектором; полоса Rh2Bars доезжает до СВОЕЙ доли (`--v`),
    а не во всю ширину (e2e это проверяет числами).
  - Одно правило — одно место: подпись месяца («Ноябрь 2026», «ноя») переехала в
    `packages/shared/src/monthLabels.ts`; отчёт PDF на сервере (`reportPdf/theme.ts`), «Графики по
    команде» и графики главной зовут её оттуда (поймал `audit:rules`), тест сверки — в
    `apps/api/tests/shared-rules-one-place.test.ts`.
  - Профиль → «Вид и приложение» → «Главная» (только «Новый вид», отдельным куском сборки): блоки
    своей роли с крупным переключателем и «выше/ниже», «Вернуть как было». Хранится в личных
    настройках `preferences.home.blocks[роль]` (схема `homePreferencesSchema` в shared, БЕЗ миграции:
    Agent.preferences — JSON). Новый блок, появившийся после сохранения, встаёт на своё место
    включённым; блок чужой роли не добавить (отсев в ядре, а не в сохранённом списке). Раскладка
    прежнего входа на общем устройстве не применяется (как автовыход 19.09).

  дашборде всегда были самые нужные данные с анимацией графиков и всем что надо, что можно включать и
  отключить».

- Что осталось:
  - Умолчание раскладки ПО РОЛИ, которое задаёт директор/админ, требует места в общей настройке
    компании: подходящего JSON-поля в `Settings` нет (`uiShellRollout` не годится — запись под
    подтверждением входа и строгая схема ломает откат). Нужна миграция `Settings.homeLayout Json
    @default("{}")` + `GET/PUT /api/v1/ui-shell/home-layout` (директор/админ, `settings.manage`),
    ядро уже принимает порядок/выключенные — личное поверх ролевого. Остановлено перед миграцией.
  - Карта `docs/product-map-simple.json`: у экрана «/» ушло ~100 косвенных связей «через общую часть»
    — пульт теперь на глубине 4 (Dashboard → TodayRoyal → registry → blocks → PultClean), а
    `closureOf` в `scripts/product-map-simple.mjs` смотрит до глубины 2. `map:gate` зелёный (экраны и
    пути на месте); тот же долг, что записан координатором 19.11 (closureOf), — отдельной правкой.
  - Агенту на телефоне чистая оболочка (а значит и «Новый вид») по-прежнему не включается
    (`hooks/shellDevicePolicy.ts`) — там прежняя мобильная главная; e2e смотрит узкие ширины агента
    через местный предпросмотр `?shell=clean&agentMobilePreview=1`.
  - `components/look/RoyalBlock.tsx` (граница из #319) больше не используется главной — ядро ставит
    общую `BlockBoundary` само; файл основы не тронут, удалить вместе с его тестом — решение координатора.
  - Старая вкладка (сборка до этой правки) при смене темы сохраняет настройки без `home` и стирает
    личную раскладку главной — один раз, до обновления вкладки.
