# Список чатов: «Все» первой, подгрузка при прокрутке, имена по интересу, фото, архив

Решение владельца 26.11.2026 по макетам `D:\CRM-wt\_design-26-11\01-chat-list` (вариант A, имена из C).

## Что изменилось
- Вкладки: «Все / Ждут / Мои», «Все» первая и открыта по умолчанию (`RoyalInboxFilters`).
- Подгрузка при прокрутке сама, без «Показать ещё (N)», на ПК и телефоне: `hooks/useLoadMoreSentinel.ts`
  (IntersectionObserver, порция 40, серые строки, наблюдатель пересоздаётся на каждую порцию). Заменено и в
  `MobileChatsList`. Страницы остались offset-ными (курсора не вводили: порядок задан вниманием и свежестью групп,
  дубли режет накопитель страниц на клиенте).
- Имя безымянного по интересу: `lib/chatInterest.ts` читает `leadDraft` диалога, затем факты досье. «Ищет 2к · Шохмансур»,
  бюджет «до 650 тыс.» отдельной подписью, в кружке метка «2к», у продающего значок. Настоящее имя всегда главнее.
- Фото: `ContactProfile.avatarKey/avatarFetchedAt` (миграция `20261126170000`), `lib/contactAvatar.ts`: Instagram,
  Messenger, Telegram, один раз на человека (условная отметка до скачивания), safeOpen, 96px webp, лимиты байт и
  пикселей, закрытое хранилище `uploads-private/avatars`. Отдача: подписанная ссылка `/attachments/s/<имя>?…&v=a`
  тем, у кого есть `messages.view` или `messages.viewOwn`. WhatsApp фото не отдаёт: кружок с буквой.
  Цвет кружка держится за `avatarSeed` (id досье).
- Архив: `lib/chatArchive.ts` + запрос списка. Без карточки и тише 30 суток (строго раньше границы) уходит из
  «Все/Ждут/Мои», поиск находит, новое сообщение возвращает, с карточкой не архивируется. Строка «Архив · N»,
  `?archived=1`. Ничего не хранится и не удаляется. Рубильник `chatArchiveEnabled` (Настройки, по умолчанию ВКЛ).
- Мелочи: кружки круглые, на 320px вкладки не наезжают друг на друга.

## Проверено
- API: `chat-list-archive-interest-avatar.test.ts` (16), `grouped-conversations.test.ts` (14, порция берётся из ответа).
- Web: `MessagesChatList.test.tsx` (13), `RoyalChats.test.tsx` (порядок вкладок). Сторожа проверены поломкой:
  без пересоздания наблюдателя, без выключения на загрузке и без условия «нет карточки» тесты краснеют.
- Замер на стенде, 3100 диалогов по 30 реплик (1731 архивных): страница 40 строк ~210 мс при включённом архиве и
  ~230 мс при выключенном (то есть как раньше), счётчики точные (1369 + 1731). Поиск по тексту ~1,5 с: как было.
- Кадры: `D:\CRM-wt\_shots-chat-list` (1440, 390, 320).

## Не сделано
- Ручное «В архив» / «Вернуть» и свайп: нужна колонка и миграция данных, оставлено на потом.
- Старые виды (не «Новый вид») получили подгрузку и имена, но не кружки с фото.
- Фото Instagram сервер с VPS качает с CDN Meta напрямую (см. шапку `clientAvatar.ts`): возможны таймауты, тогда кружок с буквой.
