# 2026-11-21 — «Похоже на … заметки совпадают на 84%» больше не ловит ярлыки бота

## Что было
- Снимок владельца (iPhone): «Прочее обращение» из WhatsApp показывало подряд три подсказки
  «Похоже на … — заметки совпадают на 82–84%. Может, один человек?» с тремя разными людьми.
- Причина: `lib/fuzzySearch.ts::fuzzySimilarClientNotes` вырезал из заметок перед сравнением только
  строки с пятью значками (🏷💼🔑❓📞). Ярлыки `ai/leadKind.ts` «🌍 ВНЕ ДУШАНБЕ — клиент назвал «…»,
  мы работаем только по городу» и «🚫 НЕ НАШ ПРОФИЛЬ…» в список не попали. У карточек из одного
  такого ярлыка отличается лишь название города — сходство 77–84%.
- Замер прода 21.11 (только чтение): подсказку получали 20 карточек, 162 пары; все от ярлыков 🌍/🚫,
  ни одной с общим номером. 114 пар были выше порога пуша руководству (0.75, `services/leads/intake.ts`,
  та же функция), то есть ложный пуш «Похоже на дубликат карточки» тоже уходил.
- Ещё: отклонённые «Разные люди» отсекались ПОСЛЕ `LIMIT 3` — три отклонённые пары закрывали четвёртую.

## Что сделано
- Правило класса вместо списка: системная строка — любая строка, первым знаком которой стоит значок
  (U+2190–U+2BFF и U+1F000–U+1FAFF; буквы, цифры, кавычки не входят). Одно правило в двух видах
  (JS для открытой карточки, регулярка Postgres для кандидатов), их равенство сверяет тест на базе.
- Остаток короче 40 знаков не сравнивается: общая фраза пересказа («Клиент ищет дом») — не уникальное
  содержание, у разных людей совпадает дословно.
- Отклонённые пары передаются в SQL и отсекаются до `LIMIT`.
- Одна дверь: правка в `fuzzySimilarClientNotes` чинит и баннер карточки (ПК и телефон — один
  `SimilarNotesWarning`), и пуш руководству при новой заявке.

## Чем проверено
- Новый `apps/api/tests/client-similar-notes-system-lines.test.ts`: равенство JS/SQL; все ярлыки
  `decideLeadKind` вырезаются целиком (новый ярлык без значка покрасит тест); случай ПО-000935;
  короткая фраза; настоящее совпадение под ярлыком находится; отсев отклонённых до LIMIT.
- Поломка нарочно (старый список значков, без порога длины и без отсева): 5 из 6 красные.
- Тот же запрос на проде (только чтение): после правки подсказок 0 из 20, пар выше 0.75 — 0.

  правки) — настоящее совпадение слов в цитате подсказку не даст.
- Ручное объединение 21.11 16:30 UTC (журнал действий, `matchedBy: manual`): у влитой карточки в
