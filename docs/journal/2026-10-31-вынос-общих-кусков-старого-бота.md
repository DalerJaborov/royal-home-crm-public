# 31.10.2026 — Вынос общих кусков старого бота (шаг 2 описи, подготовка к удалению)

- Что изменилось: чистый перенос без смены поведения. Из `ai/leadQualifier.ts` вынесены
  разбор телефонов (`lib/shared/phoneText.ts`), голос агентства, правила продавца и подписи
  типов объектов (`ai/agencyVoice.ts`), короткая реплика агента и помощники истории
  (`ai/shortAgentReply.ts`). Из `messengers/conversation.ts` — запись диалога и отметки
  отправки/доставки (`messengers/conversationStore.ts`). Из `messengers/comments.ts` — приём
  вебхука и фильтр своих (`messengers/commentIngest.ts`), вызовы Graph/YouTube для ответа и
  скрытия (`messengers/commentGraphActions.ts`). Из `messengers/propertyShowcase.ts` — журнал
  показов (`lib/propertyExposures.ts`) и тип `ShowcaseResult` (`ai/showcaseResult.ts`).
  `WEBSITE_SESSION_RE` — в `lib/shared/websiteSession.ts`. Старые модули переизлучают имена,
  живые модули (ядро, робот на звонках, CRM) переведены на новые адреса.
- Почему: чтобы ни один живой модуль не импортировал файлы старого движка, и его можно было
  удалить целиком (шаг 8 описи `legacy-inventory-20261031.md`).
- Чем проверено: сборка api (код 0), `audit:deps:gate`, `audit:rules`, `audit:mocks`, `map` +
  `map:check`, задетые тесты (подмены `vi.mock` шести тестов переведены на новые пути).
- Что осталось: в живых модулях остаются только осознанные связи со старым движком —
  `cron.ts` (`recoverStuckPendingMessages`, `processDueComments` — общий раздатчик),
  `lib/stuckConversations.ts` (`processMessengerTurn`), `lib/phoneLeadWatchdog.ts` (`acceptLead`),
  `routes/settings.ts` (`DEFAULT_BOT_PERSONA`, `DEFAULT_COMMENT_PROMPT`), `ai/botAudit.ts`.
  Они уйдут вместе с самим движком (шаги 7-9).
- Внимание при выкате: правка затрагивает файлы, входящие в хеш ядра
  (`customerActionJournal`, `customerContactIntent`, `customerNewLeadBridge`, `customerQualifierContext`,
  `customerIngressNormalize`) — только строки импорта, но `coreHash` изменится, и ревизию
  ядра нужно продвинуть обычным порядком после вливания.
