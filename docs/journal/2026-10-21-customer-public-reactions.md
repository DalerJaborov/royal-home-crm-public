# Public reactions and revision refresh

Standalone praise, appearance criticism and price objections receive short
language-matched replies without an unrelated property card, contact request
or vacancy question. Seller-ad detection reuses the existing moderation
sequence and distinguishes an audience contact invitation from a buyer request.
Office information uses the same company facts with a Tajik presentation.

Routine revision refresh retains historical UNKNOWN sends and their peer
quarantine, while allowing unrelated work to advance once those attempts are
closed and inactive. Ready, in-flight, recent or unfinished attempts still
block refresh. No uncertain send is retried and no receipt is invented.

Regression coverage includes signed public flows, renderer behavior and the
HTTP/database publication gate. Recovery child-process tests explicitly use
the same synthetic encryption environment in parent and child.

This is a source-only port onto the cleaned public repository. Private incident
reports, actual customer dialogues and development history are not included.
Cloud validation, merge and production repository adoption are separate steps;
this port must not trigger a duplicate production release.
