# 2026-11-24: Шабнам выбирает голос по одному

**Что.** После «Озвучить» (черновик, расшифровка, текст «озвучь…») Шабнам показывает не список из всех голосов, а один голос: имя, пол, образец файлом и кнопки «Выбрать / Назад / Дальше / Муж. / Жен. / Все / язык / Отмена». Первым идёт голос по умолчанию, старт с последнего выбранного сотрудником (`narrationLastChoiceFor`). «Выбрать» — прежняя платная кнопка `fnr:p`, деньги ElevenLabs до неё не тратятся.

**Рубильник.** `freeNarrationVoiceStepper` в Настройках озвучки (по умолчанию ВКЛ). Выключен — прежний список голосов кнопками.

**Одна логика.** Порядок и голос по умолчанию — `pickNarrationVoice` из `packages/shared`, как в CRM; чистый разбор кнопок и фильтров — `apps/api/src/lib/narrationVoiceStepper.ts`.

**Тесты.** `narration-voice-stepper.unit.test.ts`, блок «голос по одному» в `free-narration-draft.test.ts`, число чекбоксов в `NarrationSettingsPanel.test.tsx`.

**Не сделано (PR3).** Шаблон и концовка после выбора голоса и «Другой шаблон» для свободного текста (у свободного текста нет структурных фактов, шаблон к нему не применим; у объекта он уже есть в карточке `nar:`). Выбор голоса и шаблона при добавлении объекта через Шабнам: мастер пока шлёт `{ none: true }` или общую озвучку.
