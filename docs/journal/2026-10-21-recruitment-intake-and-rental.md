# Recruitment intake and rental responses

The current customer request takes precedence over recruitment advertising context:
an explicit rental request projects rental intent, and a verified unavailable
rental-service response ends without a property or recruitment questionnaire.
The canonical rendered question is also `none`, so state does not await the
discarded model suggestion. Russian/Tajik text and durable DM planning are covered.

Recruitment templates and questions accept a resume or a short self-description;
work examples and portfolios are optional. Templates remain closed until staff
explicitly save an open position. Current business conditions are read from CRM.

The owner explicitly requested a temporary pause of repeated SMS confirmation
for all settings and the recruitment catalog until 21 November 2026. The bounded
server policy expires at 06:30 UTC that day without a restart. The production
compose default enables that reviewed window; an empty environment override
disables it earlier. Invalid or later deadlines fail closed. Normal login,
active-account checks, permissions, ADMIN/DIRECTOR role checks and authenticator
verification remain. Employee management and other nonsettings operations retain
their step-up guard. No MFA elevation is fabricated: status reports maintenance
separately, and temporary authorization is audited as maintenance. Owner control
transactions retain their permission/idle/configuration checks and record the
actual authority. Tests cover ordinary strict behavior, catalog writes under the
temporary policy, absent authentication, role denial, nonsettings guards and
automatic expiration.

The first full cloud workflow passed, but artifact download lost its network
connection and correctly prevented release. The CLI now retries that read at
most three times for transport errors, using a separate empty directory per
attempt. Missing/forbidden artifacts still fail immediately. Exact source SHA,
successful workflow and complete test/source report requirements are unchanged;
unit tests cover recovery from a partial download and bounded terminal failure.
