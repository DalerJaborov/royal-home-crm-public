# Ночной аудит CRM — второй пакет, 24.10.2026

Отдельный public worktree `night-audit-20261024-phase2` от `0466aca`; первый полный API-прогон продолжает работать на неизменном первом пакете.

- Импорт сохраняет прежний TJS по умолчанию только для пустого значения, а неизвестную явную валюту отклоняет через существующую схему. Шаблон объектов получил обязательное число окон. CSV определяет разделитель вне кавычек в первой логической записи, учитывая CR/LF и экранированные кавычки.
- Поля найма используют единые прежние границы API: заметки2000, причина отказа500. Формы проверяют текст до отправки и сохраняют длинное старое значение для исправления; политика хранения не расширена.
- Перенос задачи через ассистента выбирает только живую задачу по общему TASK_WHERE, сохраняя историческую дату отменённых показов.
- Формы общих настроек сохраняют набранное после rollback неудачной записи через происхождение фактического объекта кэша. Обычные переключатели по-прежнему оптимистичны; канонический ответ и новые правки проверены отдельно.
- Очистка незавершённого видео повторно проверяет актуальную сессию под блокировкой строки перед удалением частей. Неудачная очистка диска сохраняет строку для повтора. Ограничения filesystem/DB атомарности описаны отдельно.
- В собственном независимом node_modules обновлены совместимые зависимости по опубликованным advisory; принудительные major overrides не применялись. Prisma/client/adapter согласованы на7.10.1. Независимый npm audit после обновления вернул0 известных advisory. Это не утверждение об отсутствии всех уязвимостей.
