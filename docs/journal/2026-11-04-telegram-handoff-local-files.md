# 2026-11-04 — исходники монтажёру через локальный Telegram Bot API

Загрузка исходника на 428 МБ через multipart исчерпала память контейнера CRM. В локальном режиме CRM теперь копирует исходник в общий том и передаёт Telegram Bot API путь к нему. Telegram сам читает файл с диска и отправляет его документом.

После подтверждения или явного отказа временная копия удаляется. Если ответ потерялся, копию уберёт действующий крон очистки тома. В облачном режиме используется multipart с прежним лимитом.
