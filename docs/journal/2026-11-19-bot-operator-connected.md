  назначение агента — прежнее.

- П6: `acceptLead` стирает только память версии 1, память оператора остаётся с «заявка принята».

  часы, вакансии, бренд аккаунта, номер офиса.

**Свод с #301 (сторож лидов «обещал звонок — карточки нет», 52a231ff).** Фразы заявки оператора написаны без слов
условного обещания («напишите», «нависед», «если»): `promisesAgentContact` иначе не считает их обещанием, и
незаведённая заявка прошла бы мимо сторожа. Фраза на грубость — без «передаю сотруднику» (сторож завёл бы заявку
грубияну). Совместимость держит тест `bot-operator-phrases` (копия словарей #301; после свода — сам `promisesAgentContact`).
Пометка оператора (`scenario: "note"`) — то же задание `customer-lead-only-intake`, которое сторож считает «заботой
приёма ядра»: поэтому пометка без карточки после всех повторов теперь сама поднимает тревогу.
