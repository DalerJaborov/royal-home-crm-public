# 27.11.2026 — недозвон: уведомлений больше никому

**Что было.** С 26.11 (#473) после N недозвонов подряд агенту ставилась задача «напишите в мессенджер, не отвечает — переведите в «Неактивные»» и строка в колокольчике; «Телефон агента не отвечает» — тоже строкой агенту.

**Решение владельца (27.11).** «Уведомление можешь не отправлять никому больше»; «у нас нет больше неактивных» (раздел удалён 16.11).

**Что изменилось.**
- `lib/noAnswerStreak.ts`: при выключенном рубильнике `NO_ANSWER_LEADERSHIP_ALERTS` эскалация не делает ничего — ни задачи, ни колокольчика, ни пуша. Функция `notifyAgentNoAnswerFollowUp` (с текстом про «Неактивные») удалена.
- `lib/telephony/agentNoPickupGuard.ts`: только тихая запись в журнал ошибок.
- Вид задачи `no_answer_agent_followup` оставлен, чтобы созданные 26–27.11 задачи гасли сами при разговоре.
- Причина недозвона словами (занято / номер выключен / сеть не пропустила) по-прежнему пишется в историю клиента.

**Проверено.** `no-answer-agent-only` (переписан: ничего никому), `call-outcome`, `call-tracking`, `auto-tasks`, `env-reaches-container`, `client-call` — 75/75 на базе стенда; `tsc` api чистый.

**Осталось.** Открытые задачи `no_answer_agent_followup`, созданные за сутки на проде, закроются при разговоре; удалять их SQL-ом — только с «да».
