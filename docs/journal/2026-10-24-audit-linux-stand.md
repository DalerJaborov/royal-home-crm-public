# Стенд аудита: Linux-проверка, 24.10.2026

Облачный подготовительный этап3305fdc выявил ошибку подключённого пакета тестов: два реальных вызова создания ссылки полагались на Windows cmd/mklink и падали на Linux. API-тесты не запускались.

Создание ссылки заменено на fs.symlinkSync: junction для Windows, directory symlink для POSIX. Отказ менять чужую ссылку и проверка realpath сохранены; пропуски тестов не добавлены. После исправления14Windows-тестов прошли. Подтверждение Linux и новый полный итог ожидаются. Это исправление CI-пакета аудита, не новая находка в production.
