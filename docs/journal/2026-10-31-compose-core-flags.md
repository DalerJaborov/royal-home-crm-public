# 31.10.2026 — флаги ядра бота доходят до контейнеров

**Что.** В `docker-compose.prod.yml` (якорь `crm-env`, общий для api и worker) добавлены `CUSTOMER_AGENT_LEGACY_CUTOVER` (по умолчанию `off`) и `CUSTOMER_AGENT_SAY_MODE` (по умолчанию пусто = тень).
**Почему.** Прод передаёт переменные в контейнеры поимённо; без этих строк значение в `.env.production` не попадало бы в процесс, и перевод клиентов старого бота (PR #82, решение владельца 31.10) нельзя было бы включить.
**Чем проверено.** `docker compose config` на шаблоне; код читает `=== "on"` / `=== "live"`, пустое и `off` — выключено.
**Дальше.** Владелец разрешил включить перевод: `CUSTOMER_AGENT_LEGACY_CUTOVER=on` в `.env.production` и пересоздание api/worker.
