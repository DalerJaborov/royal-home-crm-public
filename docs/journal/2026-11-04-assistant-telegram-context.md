# Контекст рабочих групп Шабнам

В зарегистрированной рабочей группе хранение контекста включается отдельно. Обычные сообщения активных привязанных сотрудников сохраняются на семь дней с номером сообщения, временем и темой. Телефоны, адреса электронной почты и ссылки скрываются. Для вложений сохраняется тип файла.

Повтор доставки не создаёт новую запись. Исправление сообщения обновляет текущую версию и само по себе не вызывает ответ. Выборка по номеру сообщения или коду объекта ограничена исходной группой, темой и временем. Выключение хранения закрывает выборку сразу, а отключение группы удаляет её записи.

Новые и уже зарегистрированные группы начинают с выключенным хранением. Выкат миграции не импортирует старую переписку.
