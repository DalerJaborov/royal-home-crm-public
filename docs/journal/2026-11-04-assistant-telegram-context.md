# Контекст рабочих групп Шабнам

В зарегистрированной рабочей группе хранение контекста включается отдельно. Обычные сообщения активных привязанных сотрудников сохраняются на семь дней с номером сообщения, временем и темой. Телефоны, адреса электронной почты и ссылки скрываются. Для вложений сохраняется тип файла.

Повтор доставки не создаёт новую запись. Исправление сообщения обновляет текущую версию и само по себе не вызывает ответ. Выборка по номеру сообщения или коду объекта ограничена исходной группой, темой и временем. Выключение хранения закрывает выборку сразу, а отключение группы удаляет её записи.

Новые и уже зарегистрированные группы начинают с выключенным хранением. Выкат миграции не импортирует старую переписку.

Короткое продолжение про цену, фото или срок использует номер из текущей беседы того же сотрудника в той же теме в течение восьми минут. Цены и сроки запрашиваются заново. Вопрос «что уже писали» в группе с включённой памятью ищет сообщения по номеру объекта или ответу на сообщение. Этот режим только читает данные.

Шабнам использует простые таджикские фразы в приветствиях, коротких ответах и карточках цены. Голос подхватывает лёгкую интонацию для дружеских реплик. Словари произношения подключаются по отдельной паре идентификатора и версии для каждого языка.

Первый набор общих правил описывает монтаж, смену цены, замену постов и показ дома. У каждого правила указан источник. Индекс общих знаний получает фиксированный запрос по теме процедуры.
