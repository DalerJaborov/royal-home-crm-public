# 14.11.2026 — Большие отчёты в PDF в стиле Royal Home

Просьба владельца: «для больших отчетов директору и всем у кого есть доступ например
чтобы большой отчет там по деньгами или что то подобное может отправить в пдф красиво
оформленный в стиле роял хом».

## Что сделано
- **Два PDF-отчёта**: «Финансовый отчёт» за месяц (право `finance.view`) и «Отчёт по
  команде и заявкам» за период (право `reports.view`; деньги — только с `finance.view`).
  Договор один на сервер и экраны: `packages/shared/src/reportPdf.ts`.
- **Цифры не считаются заново.** Финансы — тот же `buildExpenseSummary`, что у экрана
  «Финансы», плюс прогноз комиссии (только для текущего месяца). Воронка, агенты и
  источники вынесены из `routes/reports.ts` в `lib/teamReports.ts` без изменения логики;
  экран и PDF зовут одни функции.
- **Оформление** (`apps/api/src/lib/reportPdf/`): синяя обложка с логотипом компании,
  шапка и подвал на каждой странице, «Страница N из M», время по Душанбе, плитки с
  главными цифрами и «±N % к прошлому месяцу» (для идущего месяца сравнение не
  печатается), графики, таблицы с повтором шапки и итогами. Шрифт Onest (TTF, OFL,
  таджикские буквы проверены), акцент `#1d5fe0`.
- **Движок**: `@react-pdf/renderer` — чистый JS, без Chromium в образе. Одновременно
  собирается не больше 2 файлов (третьему — «PDF уже готовится», 429), потолок 30 с;
  ошибки — `logSystemError`. Строки таблиц ограничены (выплаты 200, агенты 300).
- **Доставка**: `GET /api/v1/report-pdf/:kind` — файл; `POST /api/v1/report-pdf/:kind/telegram`
  — только в свой Telegram сотрудника (`Agent.telegramChatId`), получателя в запросе нет.
  Каждая выгрузка — `REPORT_PDF_EXPORT` в журнале действий. Акционер («только смотрит»)
  может прислать себе PDF — это не меняет данных.
- **Кнопки** «Скачать PDF» и «PDF в Telegram» (`components/ReportPdfActions.tsx`) — на
  «Финансах» (обе оболочки) и «Отчётах», ПК и телефон; без права кнопок нет.
- **Раз в месяц директору**: тумблер «Финансовый отчёт в PDF раз в месяц» (Настройки →
  Система), по умолчанию выключен. Крон `finance-pdf-monthly` 1–3 числа в 09:10 по
  Душанбе: месяц захватывается атомарно (`financePdfMonthlyLastSent`), повтора нет; если
  файл не собрался — месяц отпускается, следующий день повторит.
- Миграция `20261114150000_finance_pdf_monthly` (две колонки в Settings).

## Грабли
- `npm install … react@^19.3.0 -w apps/api` поднял корневой `react` до 19.3.1 при
  `react-dom` 19.3.0 — веб падал белым экраном («Incompatible React versions»). В
  `apps/api/package.json` react закреплён точно `19.3.0`, lock пересобран от main.
- Путь Windows `D:\…` к картинке движок PDF принимает за URL — логотипы отдаются байтами.
- В Onest нет ▲▼ — знак изменения пишется «+/−».
- Подписи на графике (`Svg Text`) не наследуют шрифт страницы — `fontFamily` явно.
