# 17.11.2026 — Шабнам: расходы списком и по фото — одна карточка, а не «поговорила и не сделала»

- Что изменилось:
  - Одно место слов просьбы о расходах — `apps/api/src/ai/assistant/expenseIntent.ts` (расход/харҷ/хароҷот/xarajat, «ворид/сабт кун», «мана акс», «повтори карточку»; границы слова по `wordBoundary.ts`). Подпись к фото/файлу считается просьбой о расходах, если слово «расход» стоит где угодно, а не только в начале (`assistantExpenseReceipt.ts`).
  - Фото или файл с подписью своими словами больше не «только пересказ»: подпись идёт ядру, текст файла — цитатой в границах недоверенного содержимого (`wrapUntrusted`), ход сохраняется в историю (`assistantBot.ts`). Пересланное — по-прежнему только пересказ.
  - Список текстом («статья сумма» по строкам, «за прошлый месяц», «моҳи гузашта», «октябр» без года) разбирается кодом в одну карточку `add_expenses` (`telegram/assistantExpenseTextList.ts`); есть неразобранная строка с цифрами — решает модель. Месяц из подписи фото/альбома достаётся строкам без месяца.
  - Фото без слов у того, кто ведёт расходы, помнится 30 минут; «мана акс, ворид кун» следом — одна пачка из них. «Внеси расходы» без данных — одна фраза, чего не хватает, и следующее фото/файл без подписи принимается как расходы (10 минут). «Ворид кун», «повтори карточку» — карточка за сутки снова (`telegram/assistantExpenseFollowup.ts`).
  - Карточка пачки расходов ждёт час, а не 10 минут (`ttlMs` исполнителя в брокере, `ADD_EXPENSES_TTL_MS`); остальные карточки — как были. «Записать» на истёкшей — «ничего не записала» на языке карточки и кнопка «Показать снова» (новое действие с теми же строками и теми же ключами строк).
  - Промпт и описание `add_expenses`: таджикские примеры, правило месяцев, «нет данных — одна фраза». `SYSTEM_PROMPT_VERSION` = `2026-11-17.1-expense-lists-tajik`.
- Почему: журнал прода 10–11.11 — пять просьб директора внести расходы прошлого месяца списком и фото, ноль вызовов инструментов, две карточки `add_expenses` истекли. По коду: подпись «ҳамин хароҷотҳоро…» не проходила шаблон (только начало строки, не знал «хароҷот», «ворид»), фото с такой подписью пересказывалось без истории, фото без подписи забывалось после 👀, разговор живёт 15 минут, карточка — 10.
- Защиты не тронуты: права `finance.view` + `finance.manage` (брокер и `getExpenseDirector`), запись только кнопкой, ключи строк и защита от двойного расхода (#181) — те же; повтор карточки не запишет пачку второй раз.
- Чем проверено: не запускалось (в копии нет `node_modules`), проверит сборщик: `npm run build:api`, `cd apps/api && npx vitest run tests/assistant-expense-followup.test.ts tests/assistant-expense-batch.test.ts tests/assistant-expense-receipt.test.ts tests/assistant-telegram.test.ts tests/assistant-actions-broker.test.ts`, затем `npm run map && npm run map:check`, `npm run precheck`.
- Что осталось: одиночный чек (`TelegramExpenseDraft`, кнопки `ef:`) по-прежнему ждёт 10 минут; проактивной правки карточки при истечении (без нажатия) нет — сборщик действий только гасит статус; Golden Set живых фраз директора на стенде модели не прогонялся.
