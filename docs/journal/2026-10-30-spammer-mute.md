# 30.10.2026 — метка «спамер» и ответы без «не открылось» (пачка P7)

Строится поверх `fix/core-share-spam-30-10` (foreign_share, спам-словарь).

## Что сделано
- `ai/customerSpamMute.ts` (чистые правила) и `lib/customerSpamMuteStore.ts`. Спам-ход = чужая публикация без вопроса
  (foreign_share + noise) или слова SPAM из `customerDmAbuseKind`, без слов интереса. Два таких хода за 7 дней ->
  `leadDraft.spamMute.mutedUntil = now + 30 дней`. Хранится в существующем JSON `BotConversation.leadDraft`
  (одна атомарная jsonb-операция), миграции нет.
- `customerDmAgentTurn.ts`: до скачивания медиа, восприятия и модели — если метка действует и в тексте нет интереса
  (недвижимость ru/tg, цена, адрес, продам/куплю, номер ОБ-…, телефон, наш бренд) — тихий HELD `spam_muted_no_reply`
  (вход уже записан для оператора). Интерес снимает метку. После хода спам считается в счётчик (идемпотентно по eventKey).
- Тексты: убраны все фразы о сбое («не открылось», «недоступно», «не удалось», «кушода нашуд», «дастрас нест»,
  «временный сбой», «ссылку открыть не получилось», «часть файлов не удалось открыть», «речь не удалось разобрать»).
  Теперь вопрос по делу «Что вас интересует: покупка или продажа недвижимости?» / «Шуморо чӣ лозим: харид ё фурӯши манзил?»
  (аренды у нас нет — по поручению владельца, слов про аренду нет). Чужая ссылка не упоминается. Повтор того же вопроса
  (последняя реплика бота — только он) = молчание `attachment_question_repeat_no_reply`.
- Одноразовое фото (`ephemeral`, новый вид вложения в ingress-схеме и нормализации): при объекте в фокусе или клиенте-продавце —
  «Пришлите, пожалуйста, обычным фото…», иначе вопрос по делу.
- Файлы метки добавлены в coreHash реестра ревизии (`customerAgentRegistration.ts`) — нужна регистрация новой ревизии при выкате.

## Проверено
Новые тесты `customer-spammer-mute-30-10.test.ts` (59), интеграция в `customer-dm-agent-turn-postgres.test.ts` (40, включая
«метка после двух ходов, третий без модели, снятие на «нархаш чанд?»»), корпус dm-share 22/22 и media 20/20 (scripted),
сторож запрещённых слов по всем строкам рендерера и вложений.

## Осталось / решения
- Отдельная колонка вместо `leadDraft.spamMute` была бы чище; старый движок пишет `leadDraft` целиком в нескольких местах
  (conversation.ts) — метка сохраняется, пока он делает spread.
- Восприятие медиа для чужого шера и так не запускается (публикация не найдена -> нет частей); для замьюченных отключено.
