# 29.10.2026 — продажа сама снимает ролик объекта из соцсетей

## Что изменилось
- Новый `apps/api/src/lib/propertySoldSocial.ts` → `retireSocialAfterSale`. Зовётся из
  `closeWorkAfterLeavingSale` (`lib/propertyLeftSale.ts`) только при `sold`, то есть на всех
  путях продажи: ручной статус, закрытие сделки, ночная сверка.
- Снимает основной ролик тем же `removeFromSocial`, что и кнопка «Убрать из соцсетей»:
  Instagram, Facebook, YouTube, Threads.
- Telegram не даёт боту удалять сообщения старше 48 часов («message can't be deleted»). Такому
  посту подпись переписывается на «✅ ПРОДАНО …», в основном канале и в дополнительных чатах.
- То, что убирается только руками (TikTok — API удаления нет; Instagram без маркера удаления),
  уходит хозяину объекта (`propertyOwnerAgentId`) уведомлением со ссылкой на пост.
- Снятый с продажи (`withdrawn`) и бронь ролик не трогают: такие объекты часто возвращаются.

## Почему
Владелец: при продаже или смене цены всё должно обновляться само, без входа в каждую сеть.
До этой правки продажа гасила фото-посты и повторы, а основной ролик висел. Удаление из
Instagram/YouTube при этом не работало вовсе: маркер удаления Instagram умер 12–15.10 (личный
вход Facebook), ключ YouTube был без `youtube.force-ssl`. Оба заменены 29.10 (маркер — системный
пользователь Meta `royalhome-crm`, без срока). Удаление из Instagram проверено живым тестовым
постом: снят кодом CRM за 5,6 с.

## Чем проверено
- `apps/api/tests/property-sold-social.test.ts` — 7 тестов: ничего не опубликовано; Telegram
  старше 48 ч → подпись «ПРОДАНО»; другой отказ Telegram → подпись не трогаем; TikTok →
  уведомление хозяину; идёт публикация → ничего не делаем, причина в журнале.

## Дальше: одна точка для всех реакций на рынок
`retireSocialAfterSale` — место для следующих реакций на продажу. Реакции на смену цены — в
`syncPublishedPriceChange` (`lib/publishedListingSync.ts`). Туда же подключать:
1. Пауза рекламы на посте проданного объекта и перенос рекламы на новый ролик (`ads_management`
   уже выдан маркеру; рекламные кабинеты сейчас отключены из-за оплаты).
2. Мгновенное обновление каталога Meta (`catalog_management`) вместо ожидания фида.
3. Цена снижена → короткий ролик «Цена снижена» по шаблону из того же исходника, новая
   публикация, старый пост снимается (если на нём нет рекламы), коды старых постов
   сохраняются для бота.
4. История «Продано» — пока остаётся ручной кнопкой (решение владельца в `instagramStories.ts`).
