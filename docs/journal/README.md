# Записи журнала

Одна правка — один файл: `ГГГГ-ММ-ДД-коротко-о-чём.md` (латиница или кириллица,
без пробелов). Отдельные файлы, а не строка в общий конец: десятки веток идут
параллельно, и общий конец конфликтовал бы при каждом слиянии.

Проверки не пропускают правку, которая меняет код (`apps/*/src`, `packages/*/src`,
схему базы, `scripts/`, `ops/`, `.github/workflows/`), но не добавляет
сюда запись. Запись правда не нужна — метка «журнал-не-нужен» на правке.

Образец — простыми словами, для человека, который продолжит работу:

```markdown
# 23.09.2026 — Светофор не уводит живых клиентов в «Потерянные» (#797)

- Что изменилось: …
- Почему: … (кто просил, в каком треде или по какой жалобе)
- Чем проверено: … (тесты, команда, кадр)
- Что осталось: … (или «ничего»)
```

Если правка принимает решение владельца или вводит общее правило — дописать его
ещё и в [docs/JOURNAL.md](../JOURNAL.md), раздел «Решения».
