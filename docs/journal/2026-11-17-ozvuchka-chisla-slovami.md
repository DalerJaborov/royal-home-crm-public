# 17.11.2026 — Озвучка: числа всегда словами, и по-русски тоже

Владелец 17.11 дословно: «Цифры и все такие всегда пишутся буквами потому что ии не справляется».

- **Что изменилось.** Раньше словами говорился только таджикский, русский шёл цифрами. Теперь словами оба языка, одним ядром:
  - слова шаблона по-русски (`packages/shared/src/propertyNarration.ts`): {комнаты}, {площадь}, {этаж} — «три», {этаж_пор} — «пятый», {этажей} — «из девяти» (родительный), {цена} — «восемьдесят пять тысяч долларов», {сотки} — «одна сотка», «двенадцать соток»;
  - свободный текст («Озвучь текст», правка агента) по-русски: новый `russianSpeechNumbers` (пара к `tajikSpeechNumbers`): целые числа, «86 м²», «5%». Дата, дробь, номер не трогаются: текст уходит как есть, человек слышит и правит;
  - голосовой ответ Шабнам по-русски (`telegram/assistantReply.ts`): как у таджикского — числа словами, «$2 000» — «две тысячи долларов»; не вышло (дата) — голос не шлётся, остаётся текст;
  - сторож шаблона: цифры запрещены и в русском тексте (только у новых и изменённых, старые живые шаблоны не мешают).
- **Падеж** у свободного текста не согласуется («в 3 комнатах» → «в три комнатах»); у слов шаблона он верный.
- **Последствие.** Русские версии, сделанные раньше, при смене цены уже не самоодобряются (их текст был с цифрами, новый словами) и идут на прослушивание человеку. Русских шаблонов в работе почти нет.
- **Чем проверено.** `narration-templates-by-type` и `narration-text-rules` 46/46 (новые: русский шаблон словами, свободный русский текст, дата остаётся); `NarrationSettingsPanel` 6/6; tsc api и web 0. Тесты с базой (`assistant-reply.unit`, `narration-auto-flow`; ожидания обновлены) здесь не запускались: нет базы, их гонит ship.

## Правки по проверке диспетчера (17.11, оба языка)
- **Телефон** (7–12 цифр подряд, с «+992», пробелами, дефисами, скобками) читается по группам, как диктуют: «девяносто, ноль двенадцать, тридцать четыре, пятьдесят шесть» / «навад, сифр дувоздаҳ…», а не «девятьсот миллионов». Не номер: тысячи через пробел, сумма с валютой («120000000 сомони», «$…»), даты. Общий модуль `packages/shared/src/speechNumberShared.ts`, слова даёт каждый язык.
- **Этаж и «из N»**: «на четырнадцатом этаже», «с двадцать первого этажа», «четырнадцатый этаж из двадцати»; по-таджикски «ошёнаи чордаҳум аз бист» (как в разговорнике).
- **Дроби**: площадь до целого («117,85 м²» → «сто восемнадцать»), сумма от ста — до целого вниз (дирамы и центы не называем); мелкая дробная сумма и даты остаются цифрами: голос не шлётся, ответ текстом. Дат в шаблонах нет: сторож не пускает туда цифры.
- **Чем проверено.** На стенде с базой: озвучка и голос Шабнам — 16 файлов, 479 тестов зелёные (narration-*, free-narration, assistant-reply/voice/voice-replay/telegram/group-*, staff-notice-one-door); обновлены ожидания трёх старых тестов (дробная площадь теперь звучит, русская сумма словами, ответ с датой — текстом). tsc api и web 0; фронт 380 файлов, 2355 тестов зелёные (обновлены ожидания мастера: русская площадь словами, подсказка «числа звучат словами»).
