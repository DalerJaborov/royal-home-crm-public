# 26.11.2026 — «Повторить» отправку фото/видео клиенту больше не теряется (охота на баги сервера)

- Что изменилось: `retryOutgoingMediaJob` (lib/outgoingMediaJobs.ts) ставит задание очереди со своим
  ключом на каждый повтор (`outgoing-media:<id>:retry:<uuid>`), а не с общим `outgoing-media:<id>`.
- Почему: статус FAILED пишется посреди обработчика (`failDefinitely`), а задание очереди остаётся
  RUNNING, пока уходит пуш сотруднику; ключ повтора живёт до DONE (jobs/runner.ts). Экран уже
  показывает «Повторить», и нажатие в эти секунды очередь считала дублем: `enqueueBackgroundJob`
  отвечал `enqueued: true`, но строки не заводил. Отправка висела «Сжимаем…» (QUEUED) навсегда, а
  сотрудник думал, что файл уходит. Двойной отправки клиенту правка не открывает: повтор защищён
  переходом FAILED → QUEUED, исполнителя к клиенту пускает захват QUEUED → PREPARING → SENDING.
- Класс: «доменный статус стал конечным внутри обработчика, а пользователь ставит задание с тем же
  ключом, пока обработчик ещё не вернулся». Геокодер этот случай уже закрывает (бросает и повторяет по
  новому адресу); среди маршрутов с повтором по кнопке нашёлся только этот.
- Чем проверено: новый тест в `apps/api/tests/outgoing-media-jobs.test.ts` (падал без правки:
  0 ждущих заданий вместо 1), весь файл — 31 из 31.
- Что осталось: ничего.

## Вторая находка той же охоты — дата «закрыт с …» в проверке Instagram

- Что изменилось: суточная проверка аккаунтов Instagram (lib/integrationHealth.ts) пишет дату отметки
  «Meta закрыла доступ / не принимает ключ с …» по Душанбе (`dushanbeDateString`), а не срезом UTC.
- Почему: отметка, поставленная ночью по местному времени (до 05:00), показывалась руководству
  вчерашним днём. Строка появилась в #432 позавчера.
- Чем проверено: тест в `apps/api/tests/instagram-company-key.test.ts` (отметка 25.11 20:30 UTC
  должна читаться «с 2026-11-26»; падал без правки), файл 31 из 31 дважды на чистой базе.
- Что осталось: тот же срез `toISOString().slice(0, 10)` по моменту времени живёт ещё в старом коде
  (подпись дубля и курса в карточке расходов Шабнам, `instagramWebhookSubscription`,
  `backfillJobApplications`) — показ людям, не деньги; отдельной правкой со сторожем, если владелец захочет.
