# Current recruitment catalog and customer context

Public job openings are separate from private candidate applications. Authorized
staff can maintain Russian and Tajik titles and conditions, open or close a
position, and bind Instagram publications or campaign keywords in the existing
Vacancies section. Updates use actual staff authentication, elevation, optimistic
revisions, a transactional audit and unique publication/keyword mappings.

The customer agent reads live openings through the existing guarded public-read
and encrypted delivery-evidence path. Conditions are checked again before send;
old advertisements do not prove recruitment remains open. A customer inquiry
keeps its explicit job topic and selected role, including a mapped campaign
keyword or publication. An explicit later housing request can change the topic.
No application or HR decision is claimed merely because a catalog read succeeded.

The customer mutation journal now saves the genuine current candidate input
to its own inquiry/position application and issues a versioned resource receipt.
It does not link an old client by phone, require a phone to save materials,
score personal attributes, make hiring decisions or request a callback.
Closing a position blocks new writes before creating a journal action.

The existing bounded media downloader also preserves candidate files in the
existing private store. Exact current user ledger entries and the application
retain their references. The HR section can open only the files on the selected
application; authentication, section permission and NOT_CANDIDATE restrictions
are preserved. Model-provided file names and URLs are not write arguments.

Editable starting templates keep the onsite SMM/videographer role separate
from the real-estate agent's commission terms. Office data comes from the
canonical company source. Templates alone never open recruitment.

Targeted PostgreSQL checks cover the signed admission/journal/receipt path,
duplicate execution, closing during intake, HR file access and actual video
bytes through the media adapter and accepted outbox fixture. External model
responses are controlled fixtures, not a quality benchmark. API compilation,
web build and source maps passed during development; a complete exact cloud
release and independent production adoption remain required.
The existing CV download endpoint remains explicit alongside the separate
portfolio endpoint; the legacy screen regression guard passes unchanged.
Existing rollout percentage, provider budgets and voice behavior are unchanged.
No emergency handover, invented salary, automated eligibility scoring or
cross-channel identity merge is introduced.
