# 16.11.2026 — один мозг, шаг 1: ответ словами модели, проверка сервером

Источник: просьба владельца («Почему умному боту запрещено своими словами говорить?… деревянный таджик»), план
`reports/one-brain-plan-2026-11-16.md` (вне репозитория). Ветка поверх #206 + #205.

## Что сделано
1. Поле `answer` в решении модели (reply/clarify/propose): весь ответ клиенту. Снимается до строгого разбора, как `say`.
2. `ai/customerAgentAnswer.ts` — чистая проверка «всё или ничего» против шаблонного ответа того же решения и доказательств:
   числа и валюта, № объекта, телефон, адрес, классы утверждений (наличие, комиссия, аренда, зона, юр. чистота, ремонт…),
   места и имена, обещания по квитанциям, один вопрос той же темы, просьба номера, язык, повтор, эхо, приветствие, тон
   («писал выше», «дар боло», квитанции, «лутфан/мутахассис/амвол», «ты/ту», тире). Отказ → шаблон без изменений.
3. Рендер (`customerAgentAnswerVerdict`) повторяет проверку — печать доставки даёт тот же текст.
4. Правила для модели — `serverSurface.answerGuidance` (DM, ru и tg), системный промпт не тронут (хэш = V2.toPrompt).
5. Рубильник прежний: `CUSTOMER_AGENT_SAY_MODE` (тень по умолчанию). Трасса `answerStatus/answerDropReason`,
   счётчики `answer_used` / `answer_dropped_<причина>`.
