# 23.11.2026 — «Бот пишет своими словами»: проверка ответа модели по итогам прогона на живых диалогах

- **Почему.** PLAN этап 1.4: рубильник `Settings.botOwnWords` включается только после прогона на живых диалогах. Прогон
  23.11 (47 переписок прода за 12 дней, 101 ход, тестовый ключ Gemini, модель прода `gemini-3.1-flash-lite`, без базы и без
  отправки; выгрузка только на чтение, номера заменены, файлы вне git): из 75 ответов модели, прошедших проверку, 5 плохих
  (6,7%) — проверка их пропустила. Ещё 4 годных ответа проверка отбросила зря.

## Что изменилось (`apps/api/src/ai/operator/compose.ts`, только проверка и промпт слоя)

1. **Вопрос из готовой фразы обязателен** (`question_dropped`): «Понятно, в таком случае мы не сможем вам помочь» вместо
   «Вы хотите купить или продать?» — шаг терялся.
2. **Условие предложения звонка сохраняется** (`condition`): готовая фраза с «если хотите / при желании / агар хоҳед» —
   в ответе должно остаться условие («если», «может», «при необходимости», «метавонад»…). Иначе «Агент занг зада…» —
   обещание звонка без номера и без заявки (Instagram).
3. **Отказ, которого нет в готовой фразе** (`refusal`): «не сможем помочь», «к сожалению», «наметавонем»… Отказ аренде из
   готовой фразы («кор намекунем») по-прежнему можно.
4. **Женский род о себе** (`persona`): «Поняла вас», «рада»… — у готовых фраз голос мужской.
5. **Длина по SPEC**: не больше двух предложений по существу (до двух слов — «Спасибо!», «Ваалейкум ассалом.» — не в счёт),
   или не длиннее готовой фразы, если она длиннее. Было «больше трёх».
6. **Дословный повтор своей прошлой реплики в переписке** (`repeat`): `checkComposedReply` получает прошлые реплики бота из
   `recent`. Одинаковый ответ РАЗНЫМ клиентам (8 раз «Благодарю за информацию…» на фото) не меняли: каждый клиент видит его
   один раз, а случайность в ответ — новый риск без пользы.
7. **Основы слов — группами понятий, а не первыми пятью буквами**: «нархи» при «нарх» в образце, «показать» при «покажет»
   больше не отбрасываются; основы записаны в сложенном алфавите (прежние «биёр», «хаққ», «баъд», «ваъда» не совпадали
   ни с чем); новые действия агента «меомӯзад», «тафтиш», «санҷ», «ёфта», «изучит», «проверит»; «пришлите / отправьте»
   (просьба к клиенту) — не обещание «пришлём».
8. **«бо Шумо», «Вас» с большой буквы — не имя** (ложное срабатывание `name`).
9. Промпт слоя: сохранять вопрос, условие и просьбу номера, не отказывать, не упоминать аренду, не говорить о себе в женском роде.
10. После второго живого прогона (с правками 1–9) — ещё три вида утечки, тоже закрыты:
    **просьба номера обязательна** (`phone_ask_dropped`: «Если хотите, он позвонит» вместо «Напишите номер» в Instagram),
    **аренда без аренды в образце** (`topic`: «продать этот дом или сдать в аренду?»), **приезд агента** («омада мегирад»).

Рубильник `botOwnWords` не трогали — ВЫКЛ. Живого пути и решения шага (`decide.ts`, `understand.ts`, `phrases.ts`) правка не
касается.

## Чем проверено

- `tests/bot-ownwords-guard-23-11.test.ts` (13): восемь плохих и четыре ложно отброшенных ответа обоих прогонов дословно +
  отказ, женский род, длина, повтор. На старой проверке плохие проходили — новая их ловит.
- `tests/bot-human-replies-20-11.test.ts`, `bot-operator-phrases`, `bot-operator-decide` — зелёные (107).
- Прогон 1 (до правки), те же ответы модели перепроверены новой проверкой без вызовов модели: из 87 ответов модель — 74
  (было 75), готовая фраза — 13; все 5 плохих отброшены, 4 ложно отброшенных теперь проходят («скоро» вместо «свяжется»
  отбрасывается по-прежнему намеренно: это новый срок). Плохих среди принятых — 0 (оценка вручную).
- Прогон 2 (живой, новые ответы модели, 189 вызовов): 88 ответов, после окончательной проверки модель — 72, готовая фраза —
  16; плохих среди принятых — 0 (оценка вручную), остались мелочи: «обязательно свяжется», «пагоҳ соати 10:00» вместо «аз
  соати 10:00», «если хотите, позвонит» при уже принятой заявке. Ответ своими словами — около 0,75 с, худшие 10% — 1,1 с.

## Что осталось

- Проверка словарная: каждый живой прогон находил новый вид утечки (первый — 4 вида, второй — ещё 3). Перед включением
  рубильника — прогон на ДРУГОЙ свежей выборке (на этой проверка уже «подогнана»); судья по SPEC (модель) не сделан.
- Голосовые, переписки с участием сотрудника и сама отправка в прогон не входили.
- Попутно (не в этой правке, `decide.ts` в работе у другой ветки): «Ок» / «Спасибо» после заявки трижды дали «Ваша заявка у
  агента…», а по журналу 20.11 — тишина или «пожалуйста».
