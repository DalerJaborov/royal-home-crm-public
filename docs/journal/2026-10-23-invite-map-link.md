# 23.10.2026 — Ссылка на карту офиса в приглашении всегда

## Почему
Живая проверка на номере владельца (анкета «ТЕСТ Директор», 23.10 02:14 Душанбе): SMS ушла
без ссылки на карту. Правка #30 подставляла ссылку по умолчанию только при пустом адресе в
Настройках, а на проде адрес задан («…улица Бухоро 49, 2 этаж, Bukhoro Tower…»).

`lib/recruitmentCommunications.ts`: `officeMapUrl` и `contact-options.office.mapUrl` — всегда
`vacancyOfficeMapUrl()` (поиск Google Maps по адресу офиса Бухоро 49). Офис один, адрес из
Настроек — тот же офис с ориентирами. Сотрудник по-прежнему может вписать свою ссылку.

## Чем проверено
`recruitment-communications-postgres`, `-rules`, `-content` на своей базе — 34/34.

остаётся русским (поля для таджикского адреса в Настройках нет).
