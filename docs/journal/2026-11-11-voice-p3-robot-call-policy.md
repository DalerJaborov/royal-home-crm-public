## Доработка после ревью architect (11.11.2026, второй коммит)

- Частота считает только состоявшиеся разговоры (`robotSessionCountsAsConversation`): есть реплики
  собеседника («Клиент: …» в расшифровке), не автоответчик (слово причины или слова собеседника),
  не «взял не тот», не наш сбой (немая линия, голос не поднялся, процесс перезапустился) — наш сбой
  в счёт, только если собеседник сказал ≥ 3 реплик. Идущая сессия (≤ 30 мин) — в счёт. ОЦЕНКА:
  признак держится на расшифровке поставщика; у молчаливого собеседника она пуста, и такой звонок
  частоту не тратит. Правило «наш сбой» — одно место (`isRobotCallOurFailure`), его зовёт и приглашение.
- Окончательный отказ двери (стоп, «не беспокойте», чёрный список) больше не «станция не приняла
  набор»: приглашение — SKIPPED `do_not_call`/`blacklisted` + уведомление HR без журнала ошибок;
  опрос и проверка продавца — SKIPPED причиной; рекрутинг — REJECTED с причиной словами. Результат
  моста несёт `policyCode` и `retryAt`.
- «Не беспокойте» кандидата без карточки: сценарный набор передаёт двери `conversationId`
  (анкеты или её обращения) и `contactProfileId`; приглашение и рекрутинг передают.
- `retryAt` двери идёт в следующую попытку: опрос (`scheduledFor`), проверка продавца, приглашение
  (`putBack`), рекрутинг — новое поле `RecruitmentCommunication.retryAfter`, очередь берёт только
  созревшие (10 отложенных больше не загораживают новых кандидатов).
- Решение по умолчанию (владелец решит позже): руководитель снимает «не беспокойте» переписки ТОЛЬКО
  для робота тем же тумблером — новая модель `RobotCallAllow` (кто, когда; журнал действий
  `ROBOT_CALL_OPT_OUT_ALLOWED`/`_REVOKED`); `optedOutAt` для рассылок не трогается; включение
  тумблера отзывает разрешение.
- Решение по умолчанию: приглашение на собеседование с назначенным временем (`purpose:
  "interview_invite"`, и в рекрутинге INVITE со временем) суточный предел не держит, недельный — держит.
- Мелочи: текст недельного отказа — с числом из Настроек; 0 и меньше в пределах частоты = значение по
  умолчанию (не «без предела» — опечатка не должна снимать защиту); сторож архитектуры ловит
  `export const originate… =`, набор вне функции набора с дверью и прямой `fetch …/ari/channels` вне
  `ariClient.ts`; тумблер в шторке «Ещё» на телефоне шторку не закрывает; предварительная проверка
  сценариев больше не ходит в AMI (чёрный список спрашивает только дверь; исключение — новый источник
  проверки продавца, где сбой станции намеренно закрывает звонок).
- Миграция `20261111140000_robot_call_policy_followup` (аддитивная).
- Хвост: `alignToCallHours`/`isWithinPostShowingCallHours` (файл ветки prompt-gaps) праздников по-прежнему
  не знают; на деле это сглажено `retryAt` — отказ «праздник» переносит запись на начало ближайшего окна.
