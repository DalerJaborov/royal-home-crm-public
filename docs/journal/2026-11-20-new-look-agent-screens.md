# 20.11.2026 — «Новый вид»: экраны агента (пачка D1)

План — `D:/CRM/docs/design/oblik-2026-11-17/audit-20-11/PLAN.md`, раздел D1; разбор —
`critic-agent-newbie.md` и `critic-uiux.md` там же. Кадры до/после ПК 1440, 390 и 320 —
`D:/CRM/docs/design/oblik-2026-11-17/agent-screens/` (`before-*`, `after-*`).

- **Что изменилось:**
  - Карточка объекта (новый вид): сразу под фото и ценой — вкладки «Обзор / Фото и видео /
    История…»; «Кто ведёт», ролик, «Решить сейчас», сделка, заявки и озвучка — внутри «Обзора».
    В главном блоке рядом с ценой — продавец и «Позвонить» (как отдал сервер: полный номер
    директору, маской тому, кто ведёт; кому закрыт — блока нет). Номер одним видом: «№19» в
    заголовках и списке, «ОБ-000019» мелко для поиска. Агенту этап «На монтаже» показан словами
    «Готовим видео» (`stageLabelFor`, остальным ролям прежнее слово).
  - Карточка клиента (новый вид): номер первым фактом под именем; «Следующий шаг» сразу под
    кнопками звонка на телефоне и ПК (раньше — в самом низу «Обзора»); бледной «Написать» без
    переписки нет; пустая плашка «Краткая сводка ещё не подготовлена» не показывается.
  - Строка клиента: имя без склейки с запросом (`displayName` давал «Имя · ищет …»), до двух
    строк; одна дата с глаголом — «срок …» / «просрочено · …» или «связывались …».
  - Каталог объектов (новый вид): до первого объекта — заголовок и ОДИН ряд «поиск + Фильтры (n)».
    Стадии, «Мои / Все», «Без видео», задержка подготовки, вид, «На карте», «Изменения на сайте» —
    в шторке. В шторку добавлена цена «от / до» в сомони (сервер давно сравнивает в своей
    валюте каждого объекта, подпись «цену пока не сужаем» устарела). Поиск находит по имени района.
  - Мастер «Новый объект»: «Удалить черновик» убран из шапки рядом с «Сохранить и выйти» — внизу
    формы, красным, через то же окно подтверждения. «Форма в 4 шага» в шторке «+» → число из
    `WIZARD_STEPS` (мастер пишет «Шаг 1 из 5»).
  - Главная агента: в «Позвонить сейчас» у строки своя трубка (соседка ссылки, не внутри),
    «срок первого звонка прошёл» → «срок вышел, позвоните сейчас».
  - Фото объекта — одна дверь `components/property/PropertyPhoto.tsx`: ссылки по очереди,
    затем «Фото недоступно» / «Нет фото», коробка 4:3 и не шире 480 px. Переведены галерея,
    каталог, подбор (там был голый `<img>` на ~1000×570), мини-карточки, история показов в
    карточке клиента, карта, архив, чипы рекламы. Сторож — `PropertyPhoto.test.tsx`.
  - Жаргон: «Время сообщения неизвестно» больше не печатается (одно правило `lib/messageTime.ts`
    вместо трёх копий); «Верно / Неверно» под ответом бота подписаны «Оцените ответ бота»;
    из пуша сотруднику о входе с нового устройства убран IP (в журнале входов и у директора он есть).
- **Почему:** пачка D1 плана «одна идеальная оболочка» (владелец 20.11): агент-новичок должен
  понимать, что на экране и зачем нажимать.
- **Чем проверено:** `test:web` (новые тесты: PropertyPhoto + сторож, строка клиента, FAB, мастер,
  главная агента, чат); API `property-search-by-district.test.ts` (ломался без правки — проверено);
  e2e `new-look-agent-screens.spec.ts` (звонок из карточки, район + цена, мастер на 320 и 1440 —
  тест поймал, что «Удалить черновик» сперва уехал под нижнюю панель мастера, исправлено);
  кадры до/после.
- **Что осталось:** «свайп строки», «Между встречами» и налезающие кнопки «Позвонить: Со… /
  Открыть карточку» живут в старой главной агента на телефоне (`MobileAgentHome`), её снимает
  пачка B (одна оболочка) — не трогал, чтобы не конфликтовать. Карточку объекта с продавцом
  глазами смотрел только на объекте, где агент не ведёт объект (у сида Мадины своих нет).
