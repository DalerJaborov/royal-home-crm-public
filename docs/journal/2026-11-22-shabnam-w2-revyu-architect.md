# 22.11.2026 — Шабнам, волна 2: правки по ревью architect

Ревью дифа `fe12ea4d` нашло один блокер и четыре важных. Каждая находка закрыта в коде и тестом
`apps/api/tests/shabnam-w2-review-fixes.test.ts` (без правки тест красный — проверено откатом `src`).

- **Блокер: дубль расходов.** После «Записано» фраза «дуруст ворид кун» собирала новую карточку из прошлого
  списка с ключом от НЫНЕШНЕГО сообщения — те же суммы писались второй раз. Теперь: (1) уже исполненная за час
  карточка с теми же статьями и суммами — ответ «уже записаны», новой карточки нет; (2) карточка из списка прошлого
  сообщения получает ключ по содержимому списка (`list:<хэш>`), повторное «запиши» упирается в записанное.
- **Чат стирался без вопроса.** «Убери голосовые ответы», «удали сообщение для Нозы» стирали все свои сообщения за 48 ч.
  Теперь «всё» — только по явной фразе («удали всё», «весь чат», «всю переписку») без сужения («голосовые», «для …»);
  «последнее» или одно «сообщение» — только последнее; остальное — вопрос «Что убрать?», ничего не удаляется.
- **Перехват чужих просьб.** «Вот фото» без слова «расход» и без глагола записи больше не расходы. «Да, запиши» возвращает
  карточку только если она последнее действие помощницы и не старше часа; список из прошлого сообщения принимается,
  если там слово «расход» или не меньше двух строк «статья сумма» («объект 123 цена 5000» — модели).
- **Память фото стиралась.** `saveHistory` писал payload заново и терял `expenseMemory` и правку строки. Теперь запись
  сливается с живым состоянием в транзакции с замком строки (`telegram/assistantDialogState.ts`), её же использует
  запоминание фото: фото, пришедшие во время долгого хода модели, не пропадают.
- **Предел попыток 45 → не больше 15.** Каждая попытка — платный вызов. Формула: шаги + четверть шагов (не меньше трёх),
  потолок `ATTEMPT_CAP_CEILING = 15` (девять прежних плюс повторы после 503 и запасная модель).
- **Мелочи.** Честная остановка не показывает человеку тексты «для модели» (имена инструментов, «вызови…», параметры);
  короткие имена в дательном («Нозе» ← Ноза) находят сотрудника.
- **Миграций и новых рубильников нет.**
