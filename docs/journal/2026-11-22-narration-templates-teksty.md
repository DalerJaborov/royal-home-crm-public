# Живые тексты озвучки 21.11.2026: список для владельца

Статус: ждут «да» владельца. Таджикские и русские фразы ниже взяты из файла `apps/api/prisma/pending-data/20261121_narration_templates_live.sql` слово в слово. 22.11 (ревью #363) из них убрана этажность дома, остальное не менялось.

Как читать: `{слово}` подставляется из карточки объекта; текст в `[квадратных скобках]` звучит, только если все слова внутри есть.

## Слова, которые стали доступны

- `{объект}`: что продаётся (хонаи чорҳуҷрагӣ, ҳавлӣ, қитъаи замин, ҷои тиҷоратӣ / четырёхкомнатная квартира, частный дом, земельный участок, коммерческое помещение).
- `{сколько_комнат}`: «шаш ҳуҷра» / «шесть комнат». `{метраж}`: площадь с единицей. `{сотки}` у дома: участок дома; половина сотки: «ва ним» / «с половиной».
- Включаются рубильником «Живые слова в текстах озвучки» (Настройки → Озвучка). Выкат миграции включает его сам, вместе с текстами.
