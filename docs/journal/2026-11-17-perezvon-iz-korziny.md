# 17.11.2026: перезвон клиента из Корзины тому, кто ему звонил («разбор удалённого»)

**Просьба владельца.** Доделать перезвон по двум ревью `architect` (16.11): клиент из Корзины, перезвонив в течение 72 часов, попадает к РОПу, который ему звонил, но так, чтобы живая телефония не пострадала.

## Что сделано
- **Короткий звонок и запасной путь** (`inboundRouting.ts`): звонивший получает звонок не дольше 15 с (`min(incomingRouteRingSeconds, 15)`; «0 = без ограничения» тоже 25) и `fallback: "queue"`, то есть станция сама отдаёт звонок операторам. Автоответчика, платной расшифровки и тревоги «карточка в Корзине» больше нет. Без ожидания и парковки: занят/не в сети — сразу оператору.
- **Отказ = путь незнакомого номера** (`incomingCalls.ts`): занят, заморожен, нет аппарата, неактивен, нет права — звонок идёт в режимы KPI-очереди/дежурного и к оператору, как раньше. На проде режим `assigned_then_forward`, `incomingRouteToAssignedAgent` включён, `incomingRouteRingSeconds` = 40 (прочитано 17.11, только чтение).
- **Живой владелец номера важнее**: если у номера есть живая карточка (в т.ч. запасной номер), звонок идёт её агенту. Это же исправлено для обычных звонков: `findClientByPhoneDigits` при точном совпадении отдавал удалённую карточку, и звонок живого клиента уходил оператору.
- **Право проверяется в момент звонка** (`agentMayCallArchived`: работает, не заморожен, три права). Окно 72 часа — константа `ARCHIVE_REVIEW_CALLBACK_WINDOW_HOURS`, ищутся только ИСХОДЯЩИЕ звонки разбора: запись самого перезвона окно не продлевает. Если у номера несколько удалённых карточек, смотрятся все.
- **Запись «клиент перезвонил»** в хронологию удалённой карточки (`archiveReview: true`, автор — звонивший) только если ответил именно он: по внутреннему номеру — он сам; номер не назван (мобильный) — мост встал в пределах его 15 с. Оператор после запасного пути, робот, короткий «автоответчик телефона» записи не дают. Звук разговора привязывается через `interactionId` (слышно по `calls.hearRecording`), строка журнала входящих помечается разобранной (`known_client`), чтобы не висела «без разбора» и не создала живой дубль.
- **Пропущенный перезвон**: пуш только звонившему, без номера, на `/archive`; руководителям ложного «клиента нет в базе» нет; замороженным не шлём.

`tests/inbound-routing.test.ts` (54, перевод звонившему, 15 с при 150/0/10 в настройках, `fallback queue`, заморожен/без права/занят/не в сети без ожидания и парковки), новый `tests/incoming-archive-callback.test.ts` (11: ответил звонивший, ответил оператор, поздний мост, права, заморозка, 72 часа, цепочка записей, живой дубль, пуш). Соседние телефонные файлы зелёные.

## Не проверено
Живой звонок на станции (чеклист у владельца), поведение мобильного звонившего: признак «ответил он» там по времени (15 с + 3), а не по номеру. Если звонивший не взял, а перевод удался, звонок идёт в очередь 1000 мимо KPI/дежурного (как у своих клиентов до этого).

## Ревью architect (17.11) и что исправлено
- Звонок звонившему не дольше **15 с** (было 25): у очереди 1000 нет срока ожидания, сеть клиента сбрасывает через 30–60 с.
- Вне часов приёма перезвон звонившему не переводится: пуш ночью не уходит, клиент потерялся бы молча.
- При перезвоне **не заводится** живая заглушка «Входящий …» (раньше при номере в запасных/WhatsApp появлялся живой дубль удалённой карточки).
- Окно «ответил именно он» считается от фактического времени его звонка, а не от жёстких 28 с.
- «Ответил» автоответчик мобильного звонившего (номер не назван, разговор короче 15 с) не считается разговором: записи нет, звонок пропущенный, звонивший получает пуш.
- **Не сделано, нужно «да» владельца:** запасной путь «queue» всё равно не проходит общие правила станции (ночь, консультант, дежурный): для этого нужно новое значение в диалплане, возвращающее звонок в `royalhome-inbound` к метке `crmfree`. Пока закрыто часами приёма и коротким звонком. Низкие находки: признак «запись перезвона» держится на тексте заметки; при `redirect_failed` перезвон не идёт в KPI/дежурного.

## Рубильник (17.11.2026, по требованию диспетчера)
Перезвон клиента из Корзины звонившему включается настройкой `Settings.incomingArchiveCallbackEnabled`
(Настройки → Телефония, под «Звонок известного клиента — сразу его агенту»). По умолчанию ВЫКЛЮЧЕН: выкат ничего не меняет в
маршруте живых звонков. Выключено — такой звонок идёт оператору, как у незнакомого номера. Миграция аддитивная.
Проверено: `incoming-archive-callback` 13 тестов (в т. ч. «рубильник выключен»), `inbound-routing` 54, tsc api чистый.
