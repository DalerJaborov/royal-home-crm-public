# 24.11.2026 — Шабнам: служебные теги не доходят до сотрудников

Скриншоты владельца: в списке объектов видны сырые `<client_content kind="crm_note">…</client_content>` (границы «недоверенного текста», которыми поля CRM, например район, оборачивает `safeField`; модель переписывала их в ответ).
Правка: `sanitizeAssistantReply` (одна дверь всех ответов Telegram) снимает границы; `unwrapUntrusted` теперь знает вид `crm_note` (в регулярке не было `_`, поэтому он вообще не снимался).
Проверено: `assistant-reply.unit` (новый тест на эти теги), 385 тестов вокруг `untrustedContent`, tsc api.
Остальное из разбора 24.11 (память группы, ответы без обращения, ориентиры в голосе) не входит, см. память handoff-shabnam-group-memory-silence-24-11.
