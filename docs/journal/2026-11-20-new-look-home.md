## Правки по ревью PR #320 (20.11.2026)

- Ядро больше не тянет TodayRoyal в свой кусок сборки: `greetingFor`, `useMinuteNow`,
  `channelBrand` — в `components/look/home/time.ts`; тест не даёт файлам ядра
  импортировать `pages/TodayRoyal`.
- **Долг (одно правило в двух местах):** pages/TodayRoyal.tsx держит свои копии этих
  трёх функций (его правит другая ветка). При переводе TodayRoyal на ядро — импорт из
  `time.ts`, копии удалить.
- «Просрочено» (монтажёр, маркетинг) и «Эскалации» (менеджер): чёрная срочная плитка
  только при значении > 0, при 0 — обычная (как прежнее critical={> 0}).
- ПК: колонки закреплены (`ry-col-a` слева, `ry-col-b` справа, плотная укладка) — пропавший
  блок не перекидывает соседей на чужую сторону; графики команды по очереди в обе колонки.
- Монтажёр на ПК: весь пришедший список и одно нажатие «Показать ещё» = следующая
  страница (как EditorDashboard); на телефоне — прежнее «пять, раскрыть, догрузить».
