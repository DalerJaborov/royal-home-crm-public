# 11.11.2026 — переключатель сбора объявлений доходит до контейнеров

**Что изменилось.** В `docker-compose.prod.yml` (якорь `crm-env`, его берут api и worker) добавлена
`MARKET_CRAWL_ENABLED: "${MARKET_CRAWL_ENABLED:-0}"`.

**Почему.** Окружение контейнеров задаётся поимённым списком, поэтому строка в `.env.production`
одна, без проброса, в контейнер не попадала. На проде каталог `MarketListing` был пуст: 0 записей
до пробного сбора 11.11. Пробный ручной сбор 11.11 прошёл: Somon 593 (10 страниц из 153), Paydo 40.
Значит, экран «Рынок: цены» и подбор «С площадок» (#138) были без данных.

**Чем проверено.** `docker compose -f docker-compose.prod.yml config` подставляет переменную в api и worker
(по умолчанию 0). Кода приложения правка не меняет.

**Что осталось.** После выкатки — строка `MARKET_CRAWL_ENABLED=1` в `.env.production` (с копией файла),
пересоздать api и worker, проверить. Paydo редко указывает район (8 из 40) — угадывать район по тексту.
