# 14.11.2026 — «Состояние функций»: один экран про скрытые рубильники

## Зачем
Аудит скрытых механизмов (`docs/audit-hidden-mechanisms-14-11.md`, раздел D, пункты 9–11): функции молча выключены или идут
«только для проверки», а в интерфейсе об этом нет ни слова (сторож пауз бота, фото бота при включённом тумблере, озвучка,
контроль продавцов и др.). Директор узнавал об этом от клиентов или из кода.

## Что сделано
- `packages/shared/src/functionStatus.ts` — ОДИН реестр: ключ, название простыми словами, группа, имена переменных
  окружения (`env`), вкладка Настроек, фоновые задачи, источники ошибок + схема ответа (zod) и `canViewFunctionStatus`
  (DIRECTOR/ADMIN).
- `apps/api/src/lib/functionStatus.ts` — расчёт состояния (работает / только проверка / выключено + причина + «внимание»).
  Чистая часть `evaluateFunctions` без базы. Где у функции есть боевая проверка (`customerAgentSayMode`,
  `mediaExecutionMode`, `customerPropertyMediaExecutionMode`, `newOwnerProbeMode`, …) — зовётся именно она. Значения
  переменных наружу не идут (тест с «подсадными» значениями).
- Последний запуск фоновых задач берётся из существующей таблицы `CronHeartbeat` (её пишет `scheduleTracked`) — новой
  таблицы и миграции НЕ понадобилось. Здоровье: в порядке / упала / давно не запускалась / ни разу (по расписанию выражения).
- `GET /api/v1/function-status` (`routes/functionStatus.ts`): 401 без входа, 403 всем, кроме директора и администратора;
  ответ проходит ту же zod-схему.
- Сторож `npm run audit:functions` (`scripts/audit-function-registry.mjs`, шаг `precheck`, тесты в `test:scripts`):
  `process.env.X`/`env.X`/`process.env["X"]` и `mediaExecutionMode("KIND")` с именем на `_LIVE|_MODE|_EXECUTION_MODE|
  _EXECUTION|_ENABLED` без записи в реестре — красный; запись про исчезнувшую переменную — тоже. Проверено внесением
  поломки (`PROBE_FAKE_LIVE` → код 1, убрал → 0).
- Экран `/settings/functions` (`pages/settings/FunctionStatus.tsx`): один адаптивный экран, группы, фильтр, цветные плашки,
  «почему», имя переменной мелко, ссылка на нужную вкладку Настроек, список ВСЕХ фоновых задач с последним запуском.
  Вход — карточка в Настройки → Данные и система (директор/администратор).

## Покрыто
Сторож пауз бота, режим say, фото бота, голос/файл-гид бота, «только заявки», карточка объекта в боте, заявка по объекту
хозяину, робот и потолки минут, умный поиск Шабнам, справочный поиск (мёртвый тумблер), озвучка, отчёты собственникам,
метаданные публикаций, контроль продавцов и кандидатов, проверка собственников, ручные исправления, окно тревог
руководству, пауза Telegram по порталам, сбор Somon/Paydo, запасной ключ Gemini, запись хода бота.
