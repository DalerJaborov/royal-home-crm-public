# 14.11.2026 — OpenAI выключен целиком одним рубильником

- Решение владельца (дословно): «Опен ии полностью выключи нам не нужны обложки больше от него.
  И уведомления пусть не идут мушовирц от опен ии после выключения».
- Что изменилось:
  - `Settings.openaiEnabled` (миграция `20261114180000_openai_off`, по умолчанию `false`):
    после выката OpenAI выключен без ручной правки базы.
  - `ai/openaiClient.ts`: `isOpenAiEnabled()`; `resolveOpenAiKey()` при выключенном рубильнике
    возвращает `null` — одна дверь, через неё ходят обложки, перерисовка фото, выбор фото и
    картинки к роликам (`socialVideoAi.ts`). Код OpenAI не удалён.
  - `lib/video/coverOpenAi.ts`: при выключенном OpenAI обложка только нашим шаблоном, без
    перерисовки фото, даже если в Настройках выбран ChatGPT или кнопка пробы просит OPENAI;
    фото для шаблона — первое в галерее (модель не спрашиваем) — ошибок «ChatGPT не справился» больше нет.
  - `lib/paymentReminders.ts` (`billingFailures`): старые ошибки «кончились деньги OpenAI» не
    попадают в напоминания Мушовир об оплате, пока OpenAI выключен.
  - `lib/missionControlGaps.ts`: пульт не показывает «у OpenAI кончились деньги».
  - Настройки → Каналы → Обложки: тумблер «OpenAI (ChatGPT): Включён / Выключен»
    (`PUT /settings/cover-templates/openai` поле `openaiEnabled`, step-up, запись в аудит).
- Чем проверено: `openai-switch-off.test.ts` (3: выключен — ключа нет, шаблон без перерисовки,
  OpenAI нет в напоминаниях; включён — всё как раньше; значение по умолчанию в схеме false),
  `cover-openai` 55, `cover-openai-overlay` 13 (в них включён рубильник в подготовке) — зелёные на стенде.
- После выката: открытые записи журнала ошибок про OpenAI отметить разобранными (с копией),
  чтобы утренний отчёт их не показывал.
