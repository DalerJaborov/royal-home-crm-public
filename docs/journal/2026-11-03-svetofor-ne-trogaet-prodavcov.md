# Светофор неактивных больше не касается продавцов (03.11.2026)

**Что.** Продавцы не уходят в «Неактивные» и не теряются автоматически: `deactivateClient` отказывает для `SELLER`, автопереход молчаливых (`silentClientAutoDeactivate`) и тик светофора (`runInactiveTrafficLightTick`) выбирают только `BUYER`.

**Почему.** Владелец: продавец с объектом у нас становился «потерянным»; после восстановления моста у агентов (Ноза: 71→41 продавец) половина клиентов пряталась за «Неактивными». Данные восстановлены вручную отдельно (все неактивные возвращены в работу в мостовой базе).

**Проверено.** `agent-stand`, тесты: silent-client-auto-deactivate, inactive-traffic-light{,-tick,-lost}, no-answer-traffic-light, client-transfer-deactivate, conducted-showing-gate, lead-cooldown-entry-only, client-work-status-has-newer-contact. Два теста переписаны под новое правило (продавец не уходит).

**Осталось.** Правила светофора для покупателей не менялись; владелец просил пересмотреть. Защитные проверки «объект в работе» для продавцов теперь мёртвый код в silent/tick — убрать отдельной правкой.
