# 25.11.2026 — Шабнам в рабочих группах: отвечает без обращения, новичкам — привязка по номеру

Жалобы владельца 24.11: «молчит, пока не напишешь "Шабнам"», «новички пишут, она не отвечает», «как без памяти». Строится поверх #416 (автопамять групп).

ФАКТ (код): неназванное сообщение в группе проходило только узкие детекторы (цена/статус по номеру ОБ, «найди/покажи» + объект, команда цены/перемонтажа); остальное тихо `return false`. Отправитель без привязки Telegram к CRM (`senderOf` = null) невидим: ни ответа, ни подсказки.

Правка:
- `unaddressedHelpQuestion` (`assistantGroupParticipation.ts`): ясный вопрос = вопросительная форма («как добавить…», «где в CRM…», «есть …?», «найдите…», «нужна…», таджикские «чӣ тавр», «… ҳаст?») И рабочий предмет (вариант, комнаты, новостройка, CRM, карточка, заявка). Молчит на болтовню, обращение к человеку («Фируза, …», @ник), ссылки, многострочные, «не отвечай»; ответ на сообщение человека отсекает вызывающий. Идёт тем же путём «только чтение» с кулдауном 12 с и «помолчи».
- Рубильник `shabnamGroupUnaddressedEnabled` (Настройки → «Автоматика ИИ» → «ИИ решает за агента», ВКЛ, миграция `20261125090000`). ВЫКЛ — отвечает только позвавшим; окно уже начатого разговора остаётся.
- Новичок (`assistantGroupNewcomer.ts`): один раз на Telegram-аккаунт (таблица `AssistantTelegramLinkOffer`) короткое сообщение ru+tg с кнопкой `t.me/<бот>?start=staff`; на /start — тоже один раз; позвал по имени — всегда (вместо «Я вас не знаю»). Одна точка: обёртка `handleAssistantGroupMessage` после всего разбора.
- Привязка по номеру (`lib/telegramAgentLink.ts`): `/start staff` в личке → нативная кнопка «Поделиться номером телефона», окно 30 мин → свой контакт (`contact.user_id` = отправитель) → номер ровно у одного действующего сотрудника (`findActiveStaffByPhone`, то же сравнение хвостов, что у staffPhoneGuard) → привязка `telegramUserId` + `telegramChatId`, след в журнале (`source: telegram-phone`) и пуш сотруднику. Не привязывает: чужую визитку, номер у двоих, учётку с другим Telegram, вне окна (контакт идёт клиентским путём как раньше).
- `/assistant_memory on|off` (директор/админ): off ставит `contextOptOutAt` и сразу стирает сохранённое; автопамять #416 такую группу обратно не включает.

## Правка по независимому ревью (25.11.2026)

Ревью: части 1, 2, 4 годны; часть 3 (привязка по номеру) блокирована. ФАКТ: посылка «доверие как у входа по СМС» неверна — контакт Telegram доказывает только, что на номер когда-то завели аккаунт (номер мог перейти к другому человеку), а СМС доказывает SIM; привязанный чат получает код входа и льготы директора без кода (`stepUpExemptRole`).

- Рубильник `telegramPhoneLinkEnabled` «Привязка Telegram по номеру», **по умолчанию ВЫКЛ** (`AUTOMATION_SWITCH_DEFAULT_OFF`, колонка `DEFAULT false`, та же миграция — она ещё не на main). ВЫКЛ: новичку в группе путь через профиль CRM (кнопка — страница профиля, если адрес CRM https), без `?start=staff`; `/start staff` и контакт в старом окне номер не берут.
- При ВКЛ: DIRECTOR и ADMIN по номеру не привязываются никогда; остальным — код на `Agent.phone` через `issueLoginCode` (назначение `telegram-link`: СМС, пуш только если СМС некуда; свой текст «код привязки Telegram»), шесть цифр в личке за 5 минут (`tryConfirmStaffLinkCode` → `verifyLoginCode`). Без верного кода привязки нет.
- Поиск учётки — точные записи `staffPhoneLookupForms` (не хвост из девяти цифр); `findActiveStaffByPhone` удалён.
- Захват учётки — только если и `telegramUserId`, и `telegramChatId` свободны (или те же).
- Ложные срабатывания групп: «нужна/ищу» — только про варианты и только вопросом; «можно ли» — только с «в CRM»; «оё», «… есть?» — только про варианты; приветствие («Салом, …») перед вопросом не мешает.
- Срок хранения `AssistantTelegramLinkOffer` — 90 дней (`cleanupTelegramLinkOffers` в кроне уборки контекста групп).
- `/assistant_memory off`: гонку «сообщение сохранено в ту же секунду» уже закрывает запись под `FOR SHARE` с условием `contextEnabledAt = enabledAt` в `captureAssistantTelegramContext` и порядок «сначала выключить, потом стереть» (ФАКТ по коду); правки не потребовалось.
- Экран «Автоматика ИИ»: умолчание берётся из общего правила (`isAutomationSwitchOn`), а не `?? true`.

Не сделано / риски: тексты новичку ждут «да» владельца; ответ модели на «как сделать в CRM» не проверен живьём (у помощницы может не быть справки по экранам — тогда ответ будет общим); пример «Ул. Джалола Икроми…» с 👍 — это, вероятно, ответ на вопрос Шабнам (реакция модели), не разобран по журналу прода (НЕТ ДАННЫХ); привязка по номеру = новый путь входа, нужен взгляд `architect`.
