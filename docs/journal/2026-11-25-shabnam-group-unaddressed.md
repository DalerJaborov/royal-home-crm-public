# 25.11.2026 — Шабнам в рабочих группах: отвечает без обращения, новичкам — привязка по номеру

Жалобы владельца 24.11: «молчит, пока не напишешь "Шабнам"», «новички пишут, она не отвечает», «как без памяти». Строится поверх #416 (автопамять групп).

ФАКТ (код): неназванное сообщение в группе проходило только узкие детекторы (цена/статус по номеру ОБ, «найди/покажи» + объект, команда цены/перемонтажа); остальное тихо `return false`. Отправитель без привязки Telegram к CRM (`senderOf` = null) невидим: ни ответа, ни подсказки.

Правка:
- `unaddressedHelpQuestion` (`assistantGroupParticipation.ts`): ясный вопрос = вопросительная форма («как добавить…», «где в CRM…», «есть …?», «найдите…», «нужна…», таджикские «чӣ тавр», «… ҳаст?») И рабочий предмет (вариант, комнаты, новостройка, CRM, карточка, заявка). Молчит на болтовню, обращение к человеку («Фируза, …», @ник), ссылки, многострочные, «не отвечай»; ответ на сообщение человека отсекает вызывающий. Идёт тем же путём «только чтение» с кулдауном 12 с и «помолчи».
- Рубильник `shabnamGroupUnaddressedEnabled` (Настройки → «Автоматика ИИ» → «ИИ решает за агента», ВКЛ, миграция `20261125090000`). ВЫКЛ — отвечает только позвавшим; окно уже начатого разговора остаётся.
- Новичок (`assistantGroupNewcomer.ts`): один раз на Telegram-аккаунт (таблица `AssistantTelegramLinkOffer`) короткое сообщение ru+tg с кнопкой `t.me/<бот>?start=staff`; на /start — тоже один раз; позвал по имени — всегда (вместо «Я вас не знаю»). Одна точка: обёртка `handleAssistantGroupMessage` после всего разбора.
- Привязка по номеру (`lib/telegramAgentLink.ts`): `/start staff` в личке → нативная кнопка «Поделиться номером телефона», окно 30 мин → свой контакт (`contact.user_id` = отправитель) → номер ровно у одного действующего сотрудника (`findActiveStaffByPhone`, то же сравнение хвостов, что у staffPhoneGuard) → привязка `telegramUserId` + `telegramChatId`, след в журнале (`source: telegram-phone`) и пуш сотруднику. Не привязывает: чужую визитку, номер у двоих, учётку с другим Telegram, вне окна (контакт идёт клиентским путём как раньше).
- `/assistant_memory on|off` (директор/админ): off ставит `contextOptOutAt` и сразу стирает сохранённое; автопамять #416 такую группу обратно не включает.

Джалола Икроми…», ответ человеку, кулдаун, рубильник, «помолчи»), `shabnam-group-newcomer-24-11.test.ts` (12, на базе стенда), `assistant-group-context` (+1: opt-out держит). `tsc --noEmit` API чистый.

Джалола Икроми…» с 👍 — это, вероятно, ответ на вопрос Шабнам (реакция модели), не разобран по журналу прода (НЕТ ДАННЫХ); привязка по номеру = новый путь входа, нужен взгляд `architect`.
