# 23.11.2026 — Шабнам: «озвучь» голосом открывает озвучку своего текста; честный отказ при обрыве ответа

Жалоба владельца: «ИИ в Шабнам не озвучивает любой мой текст — вдруг мне нужен рекламный, а он не делает». Кадры: голосовое «озвучь…», следом вставленный рекламный текст без слов «Озвучь текст:». Шабнам ответила «присылайте данные по объекту», потом «ИИ отклонил запрос: проверьте ключ и модель Gemini», потом попросила номер объекта и предложила кабинет ElevenLabs.

Причины (по коду `origin/main`):
1. Озвучка свободного текста (`telegram/assistantFreeNarration.ts`, #214) включалась только фразой «Озвучь текст:» с текстом после двоеточия. Короткое «озвучь…» (особенно голосом) и текст следом уходили модели, а модель про озвучку свободного текста ничего не знала и отвечала «только по объектам».
2. Gemini оборвал ход (`finishReason` не `STOP`, `assertCompletedAssistantTurn`), код превращал это в `provider_rejected` с текстом «проверьте ключ и модель». Ключ и модель ни при чём; причина обрыва нигде не писалась.

Что изменено:
- `assistantFreeNarration.ts`: `isBareNarrationAsk` + `startFreeNarrationFromAsk` — короткая просьба «озвучь рекламу…» / «мне нужна озвучка…» / «овоз кун…» (2–14 слов, без ОБ-номера, «ответ», «шаблон», «статус», жалоб) открывает ожидание текста; следующий набранный текст принимается как текст для озвучки (15 минут), дальше кнопки выбора голоса.
- `assistantBot.ts`: вызов этой проверки после разбора диктовки и «повтори голосом».
- `personaStyle.ts`: модель знает про озвучку своего текста и больше не говорит «только для объектов» и не шлёт в ElevenLabs.
- `geminiThinkingPolicy.ts`: в ошибку и журнал пишется `finishReason`/`blockReason`.
- `assistant.ts` (`failureOf`): обрыв хода моделью — код `stream_interrupted` («Ответ оборвался, повторите»), а не `provider_rejected`.

Проверка: `tsc` api чистый; тесты `free-narration-trigger.unit`, `assistant-language-routing.unit`, `ai-assistant-tools-retry` (новые случаи), `assistant-voice-replay.unit`.

Осталось: живая проверка в Telegram (голос «озвучь рекламу», потом текст); если владелец хочет, чтобы Шабнам САМА писала рекламный текст из сырых данных, это отдельная функция.
