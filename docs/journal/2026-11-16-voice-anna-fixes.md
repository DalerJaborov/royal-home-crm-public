## Правки по ревью #204 (`D:/TASKS-2026-11-14/reports/review-204-2026-11-16.md`)

- **В1.** Обращения и поддакивания («ака», «апа», «ҷон», «хуб», «ҳа», «бале», «майлаш», «нест», «ок») — не таджикская
  речь: в счёт твёрдых слов не идут, а фраза только из них (и приветствий) не довод ни за один язык и не копится к двум.
  Твёрдая фраза — ещё и без единого русского слова. «Ака хуб, давайте в Сино», «Мне двушку, ака, бисёр лозим» — не переход.
- **В2.** «Говорите по-таджикски?» (по-русски и по-таджикски: «Тоҷикӣ медонед?», «Бо тоҷикӣ гап мезанед?») код ловит в
  реплике звонящего и сразу переключает звонок на таджикский: служебная пометка «ответь «Ҳа»» + вызов `language_detection`
  у ElevenLabs — распознавание переходит вместе с речью. «Я не говорю по-таджикски», «по-таджикски или по-русски?» — нет.
  С замком «только русский» правила «Ҳа» в промте нет (Н1).
- **С1.** Сторож петли узнаёт таджикские переспросы: «Боз гӯед?», «Боз як маротиба гӯед», «Чӣ гуфтед?», «Дубора гӯед».
- **С2.** «Догадку не записывай»: понятое по догадке (время, покупка/продажа, бюджет, номер) перед записью — вопрос «да/нет».
- **С3.** Рудаки — район в справочнике: миграция `20261116120000_district_rudaki` (одна строка `District`, без границы),
  сид, `BOT_DISTRICT_NAMES` в `packages/shared` (схема ответа бота, перечень робота). Для поиска район Рудаки «за городом»;
  «район Рудаки» — только объекты этого района (по справочнику или словам карточки), а не весь пригород; слова района
  вырезаются из ключа места — проспект Рудаки не находится. Адрес «Сино, пр. Рудаки 45» с сайта и выбор района моделью
  («Рудаки» при одном проспекте в тексте) кодом не попадают в район Рудаки (`districtPickAllowed`, `resolveDistrict`).
- **С4.** Текст зоны из `lib/serviceArea.ts` — новый чат-бот (`customerAgentRenderer`), «только заявки» (`leadOnlyMode`),
  ответ продавцу из другого города (`leadAcceptedReply`, сценарий продавца, комментарии), подпись типа заявки. Сторож — по
  всему `src`, а не по списку файлов. Знания компании нового бота (`AGENCY_FACTS`, схема знаний) НЕ тронуты: иначе ревизия
  ядра требовала бы ручного обновления. Меняются только хеши кода → автообновление ревизии (ОЦЕНКА, на стенде не проверено).
- **С5 не трогал** (Варзоб/Вахдат/Гиссар — продаём готовые объекты за городом или отказываем): ждёт решения владельца.

## Повторное ревью #204

- **Н-1.** «Рудаки район» — признак района только в конце строки («Рудаки, район», «Рудаки (район)»), и никогда, если рядом
  «пр./ул./проспект/кӯчаи Рудаки» или другой район города: «пр. Рудаки, район Сино», «Шохмансур район, Рудаки 30»,
  «ул. Рудаки, районе Фирдавси» — центр города, не «за городом». Слова района из ключа поиска вырезаются только при настоящем
  районе. ФАКТ (прод, только SELECT 16.11): неудалённых объектов со словами «Рудаки/Сомониён» в адресе, ориентире, заголовке
  или описании — 2; ни один не совпадает ни со старым, ни с новым правилом.
- **Н-2.** «Говорите по-таджикски?» — только вопрос второму лицу; «я не могу / мне сложно / плохо умею говорить
  по-таджикски» и «таджикский вариант договора» язык не переключают.
- **Н-3.** Строка District — «Рудаки (район)» (миграция ещё не выкачена): «квартира на Рудаки» не находит района, как раньше.
  Район «Рудаки (район)» от модели принимается только по словам самого человека: голос — последние реплики звонящего
  (`voiceDistrictFromModel` в поиске, «найди объект» и заявке), новый чат-бот — точное имя только с «район» в словах модели,
  иначе разбор места; старый чат-бот — реплики клиента (`conversation.ts`, приём заявки).
- **С5 — решение владельца 16.11.2026, дословно: «Загород не берём, только Душанбе».** Зона — город Душанбе и район Рудаки
  (15.11). Пригороды (Вахдат, Варзоб, Гиссар, дачи) — одна дверь `suburbanProperty.ts`: `propertyOutsideServiceArea` (объект
  не предлагается ни одним ботом и роботом, `propertyMatch.ts`), `queryOutsideServiceArea` (запрос не ищется; робот отвечает,
  где работаем). Правило — в `SERVICE_AREA_SALES_RULE` (справочник обоих ботов и робота). Дача в Варзобе больше не
  исключение в `coverageGuard`. Новый чат-бот: покупателю, который ищет вне зоны («дар Ваҳдат мехарам»), — та же строка и
  предложение посмотреть в Душанбе или районе Рудаки; «живу в Худжанде, хочу купить» — не отказ. Фраза-предложение по-таджикски
  носителем не проверена (?). Подбор агентам в CRM (routes/matching.ts) не тронут.
