# 2026-11-21 — Дашборд директора, экран (ветка feat/director-dashboard-ui)

## Что изменилось
- Новый экран `/director` («Дашборд директора», меню «Деньги», рядом с «Отчётами»), один для директора и РОП.
  Доступ `reports.view`, агенту нет доступа ни в меню, ни по ссылке. Деньги (плитка выручки, план, столбец
  комиссии, суммы источников и сделок) рисуются только когда сервер отдал `seesMoney` — без права их нет в разметке.
- Страница `pages/DirectorDashboard.tsx`, блоки `components/director/DirectorBlocks.tsx`, шторка списка
  `DirectorDrillSheet.tsx`, запросы `hooks/useDirectorDashboard.ts`, чистые функции `lib/directorFormat.ts`
  (сравнение с прошлым периодом, проценты, минуты, сортировка, порядок блоков и период по роли).
- Слой `theme-look-royal-director.css` (метка раздела `director`, только токены), подключён в `index.css`.
- Порядок блоков по роли: директор — план, плитки, воронка, причины, скорость, менеджеры, источники;
  РОП — скорость, менеджеры, воронка, плитки, источники, причины. Период по умолчанию: директор «Месяц», РОП «Неделя».
- Автообновление сводки раз в 90 секунд (`DIRECTOR_REFRESH_MS`), «Обновлено в ЧЧ:ММ» по Душанбе.
- Excel — `GET /reports/director/export.xlsx` с теми же фильтрами; PDF — существующий вид `team` за границы периода.

## Почему
ТЗ владельца (`docs/design/director-dashboard/TZ.txt`), «чтобы директор офигел»: красиво, в едином шаблоне нового вида,
телефон и компьютер. Договор с сервером — `packages/shared/src/directorDashboard.ts` (ветка feat/director-dashboard-api).
