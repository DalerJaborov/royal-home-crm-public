# 17.11.2026 — объявления с площадок под клиентом: действия и телефон агента (2 из 3)

## Что изменилось
- В блоке «С площадок» у каждого объявления три действия: «Написать в WhatsApp» (прежняя кнопка, `MarketWhatsAppButton`), «Показать номер» (новая `MarketShowPhoneButton`; у Paydo — «Номер на сайте», сервер его не достаёт) и ссылка «Объявление».
- Номер берётся одной прежней дверью `POST /market/listing-contact` (общий темп запросов к Somon, 403 для закрытого номера владельца нашего объекта). Дверь теперь принимает необязательные `action` (`PHONE`/`WHATSAPP`) и `clientId` и, когда номер действительно отдан, пишет отметку в новую таблицу `MarketListingContact` (кто, когда, каким действием, для какого клиента; номера там нет).
- Под объявлением видна отметка «уже связывались» (`lib/market/listingContacts.ts`): последняя по `MarketListingContact` или передача продавца поиском собственников (`SomonDelivery`, уже существующий учёт — подключён, второй копии нет). Текст — одно место `marketContactText` в `packages/shared`.
- Блок «С площадок» рисует каждая карточка сама: ПК/чистая оболочка — `ClientDetail.tsx`, телефон агента — `MobileClientCard.tsx`. Действие добавлено в сторож `cardActionParity` (ПК = телефон агента).
- Миграция `20261118020000_market_listing_contact`: только новая таблица с индексами.

## Почему
Замер 17.11: кнопкой номера в подборе покупателя не пользовался никто — в этом блоке её не было (она была только у «нашего объекта на площадках» и динамики рынка). Отметка нужна, чтобы два агента не звонили одному хозяину.

## Чем проверено
- API: `market-buyer-listings` (отметки PHONE/OWNER_LEAD, byMe, без номера), `market-own-match` (запись только при отданном номере, 400 на чужое действие, 403 без отметки), `market-buyer-alerts`, `assistant-market-tools`.
- Web: `MarketBuyerListings.test.tsx` (кнопки, отметка), `MarketWhatsAppButton.test.tsx`, `MobileClientCard.test.tsx`, `cardActionParity.test.ts`, `npm run test:web`; сборка; кадры ПК 1440 и телефон 390 на стенде.

## Что осталось
- Ручная отметка «позвонил» без показа номера (если агент звонил с номера, найденного иначе) — не делали.
