# 18.11.2026 — «Новый вид»: раздел «Чаты» (пачка chats)

- Что изменилось (только у сотрудника с признаком `look: "royal"`; у остальных
  ни пикселя и ни запроса — сторожа ниже):
  - `pages/Messages.tsx`: ветка `royal` (= чистая оболочка + `useRoyalLook()`).
    Шапка «Чаты» с переключателем значками Сообщения / Комментарии / Звонки /
    Телефония (`components/look/chats/RoyalInboxSwitch.tsx`; состав, права и
    счётчики — общий `inboxTabs()` в `SectionTabs.tsx` и `visibleScreenTabs()` в
    `ScreenTabs.tsx`, одна дверь с прежней полосой). Значками — чтобы на 320–390 px
    шапка не вылезала за экран (ошибка макета).
  - Список: один фильтр «Ждут / Мои / Все» (`RoyalInboxFilters.tsx`); редкое —
    «Бот на паузе», канал и аккаунт (прежний `CleanInboxFilters`, раскрыт) — под
    «Ещё», с меткой, пока там что-то выбрано. Строка `RoyalDialogRow.tsx`: аватар
    с меткой канала в родном цвете, имя, одна строка, справа время ожидания
    (>15 мин — внимание, от часа — срочно) или время сообщения; «Просит агента»,
    непрочитанные числом, «бот на паузе · N ч», наш аккаунт — сохранены. Плашки
    «ждёт человека → Взять на себя» и «пауза больше суток → Посмотреть» (в чистой
    оболочке были скрыты) — тихими строками в колонке списка, из того же ответа.
  - Разговор: шапка — кто/канал/состояние бота, справа бот (пауза — то же меню
    вариантов, «Вернуть боту» — тем же кругом), звонок (если есть телефон) и «Ещё»:
    поиск по переписке, данные клиента (панель рядом на ≥1180, на телефоне —
    вместо ленты), карточка клиента. Щит исходящих — строкой под шапкой. Свои
    сообщения — цветом кнопки, бот — светлый пузырь с рамкой. Одна полоса быстрых
    ответов (из коротких ручных ответов этого диалога — правило вынесено из
    телефонного чата в `lib/chatQuickReplies.ts`, телефон зовёт его же). Строка
    ввода: вложение, объект, поле, голос, «отправить» синим кругом; выбор паузы
    после ответа — одной тихой строкой. На телефоне переписка — на весь экран.
  - Слой `theme-look-royal-chats.css` (всё под `:root[data-ui-look="royal"]`,
    без backdrop-filter). Сторож `theme-look-royal.test.ts` теперь проверяет
    ВСЕ файлы `theme-look-royal*.css`, порядок подключения и то, что
    `gen-typeset.mjs` их пропускает (там теперь шаблон, а не одно имя) — другие
    пачки добавляют свой файл без правки сторожа.
- Скорость (замер на стенде, dev-сборка, 20 строк в списке): ввод 9 символов в
  поиск по чатам — перерисовок строк списка 180 в прежнем виде, 0 в новом
  (строки под `memo`, обработчик выбора стабильный); дольше всего событие ввода
  56 мс → 24 мс. Ввод в поле ответа строки не трогал и раньше (0/0). Запросы
  API в новом и прежнем виде совпадают поштучно (29 = 29, тот же состав).
- Чем проверено: `test:web` 390 файлов / 2423 теста; новые `RoyalChats.test.tsx`
  (порог ожидания, пометки строки, фильтр, быстрые ответы) и
  `MessagesRoyal.test.tsx` (все действия оператора на месте, акционер без ввода
  и без бота, общий чат без общей паузы); e2e `new-look-chats.spec.ts` (9 ширин,
  список и открытая переписка без горизонтальной прокрутки, без признака разметки
  нет) — проверен внесённой поломкой; сторож слоя — тоже. `build:web`, `map`,
  `gen:typeset` без изменений. Кадры — `docs/design/oblik-2026-11-17/code-shots-chats/`
  (вне репозитория).
- Поправки по ревью PR #277 (18.11.2026):
  - Время в строках больше не застывает: минутные часы `useMinuteClock` (пауза
    при скрытой вкладке, в прежнем виде не тикают) передаются строкам пропом `now`.
  - Красная/янтарная метка ожидания — только пока ожидание меньше суток или бот
    на паузе; давно брошенный разговор — обычная дата спокойным цветом (`rowWaiting`).
  - «Вернуть боту»: на ПК — значок со словами, на телефоне — «Вернуть боту?» Да/Нет.
    Пауза бота — без вопроса, как раньше.
  - «Ещё» в фильтрах закрывается нажатием мимо, Escape и после выбора; срезы
    переключаются стрелками, в Tab-порядке одна кнопка. Общее число — «Все N».
  - Слово канала в пузыре — только если в ленте больше одного канала (для
    экранного чтеца остаётся). Выбор канала ответа прячется, когда канал один и уже
    выбран. Код канал САМ не подставляет (ФАКТ: `selectedReplySource` стартует
    пустым и выбирается только руками) — поэтому до выбора поле видно, а при
    нескольких каналах видно всегда, иначе нельзя сменить канал.
  - Метка канала больше не снимает фон с `.chip` в своём пузыре (смысловые
    метки не перекрашиваются). Окна в портале («Подбор», «Связать с клиентом»,
    просмотр фото) слой не трогает вовсе: всё под `.ry-chats`, `:has()` нет.
- Что осталось (следующие правки, не делались намеренно): виртуализация длинного
  списка и подгрузка истории частями; вынести поле ответа в свой компонент
  (сейчас каждый символ перерисовывает шапку и панели разговора, ~24–32 мс на
  символ в dev); «Ждут» по умолчанию — меняет запрос, нужно «да» владельца;
  аватар ведущего агента в строке — список его не присылает (нужно поле в API).
