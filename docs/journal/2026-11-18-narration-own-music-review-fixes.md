- Что изменилось:
  - чистая картинка ролика монтажёра: первый перемонтаж своей музыкой сохраняет картинку вышедшего ролика (без звука,
    копией) мастером с отметкой `videoMasterSource = "MUSIC_BASE"`; каждый следующий перемонтаж строится из неё, а не
    из прошлого результата CRM. Плашка с ценой и субтитры больше не ложатся поверх прежних, а файл монтажёра не
    пропадает после первой подмены (`lib/narrationMusic.ts::buildPictureBase`, `lib/narrationAutoFlow.ts`);
  - своя музыка не справилась (нет файла трека, ffmpeg) — объект уходит монтажёру прежним возвратом
    (`sendNarrationToMontajer`), чтобы новая цена всё равно попала в ролик;

    (`narration-overlay-failed`, `lib/narrationMix.ts`);
  - своя музыка или текст на ролике — в тике `narration-auto-flow` перемонтируется не больше одного объекта
    (перекодирование картинки, предел задачи 170 с);
  - момент включения своей музыки (`ownMusicRemixSince`) ставит сервер при сохранении настроек; сама CRM
    перемонтирует только озвучки, одобренные после него — без волны перевыпуска старых роликов; с экрана поле не
    принимается; без момента своя музыка не берёт ничего;
  - мастер машины (`MACHINE`) не используется ни для перемикса, ни в подсказках Шабнам;
  - подпись рубильника текста на ролике больше не обещает «монтажёру цену не вписывать»: CRM монтажёру об этом
    не пишет.
