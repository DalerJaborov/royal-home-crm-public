# 27.11.2026 — «Звонок роботом» и «Не звонить роботом» убраны из карточки клиента (рубильник)

- **Почему.** Владелец прислал скриншот меню «Ещё» карточки клиента: «удали это, я вроде бы просил, он висит все еще».
  Строки: «Звонок роботом» (руководителю, с 28.09) и тумблер «Не звонить роботом» (П3, 11.11).
- **Что сделано.**
  - Рубильник `clientCardRobotRowsEnabled` в реестре `packages/shared/src/automationSwitches.ts`, группа «ИИ решает за агента»,
    ВЫКЛ по умолчанию (`AUTOMATION_SWITCH_DEFAULT_OFF`, колонка `DEFAULT false`, миграция `20261128090000_client_card_robot_rows_switch`).
    Булев отдаётся и сотрудникам (`toStaffSettings`) — тумблер видел агент.
  - `apps/web/src/pages/ClientDetail.tsx`: обе строки (и «Звонить вопреки просьбе клиента») показываются только при
    рубильнике ВКЛ и живом голосе; запрос `GET /clients/:id/robot-call-stop` при ВЫКЛ не уходит. Меню одно на ПК и телефоне —
    других мест с этими строками нет (поиск по `apps/web/src`).
  - Сервер не тронут: `RobotCallStop` (поставленные отметки, просьбы клиента) действует на опрос после показа, проверку продавца,
    приглашения; роуты `POST /clients/:id/live-voice-call` и `/robot-call-stop` остаются (вернуть строки — включить рубильник).
- **Сторож.** `apps/web/src/clientCardTidy.guard.test.ts` — строки робота только за рубильником; `automation-switches.test.ts` — список ВЫКЛ.
