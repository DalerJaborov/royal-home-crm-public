# 14.11.2026 — Озвучка: простой экран агента, техника в Настройках CRM, музыка не мешает голосу

- Что изменилось:
  - Карточка объекта (`PropertyNarrationManager.tsx` + общий `NarrationComposer.tsx`, тот же
    блок в конце мастера `NarrationChoice.tsx`): агент видит только «1 Голос» (язык + плитки с
    прослушиванием) → «2 Текст» по шаблону с цифрами объекта словами (варианты кнопками,
    «↻ Другой вариант» по кругу, правка руками, «Вернуть текст шаблона») → одна кнопка
    «Озвучить» → статус (готовится / послушайте и одобрите / одобрено / устарело / не
    получилось). Выбранный вариант залит, невыбранные — светлые (`pill ghost`); «Без
    озвучки» — спокойная кнопка, не главная.
  - Вся техника (модель, голоса, образцы, рубильники, пределы, шаблоны, словарь) — в
    Настройках → Каналы → «Озвучка роликов» (`settings/NarrationSettingsPanel.tsx`,
    GET /properties/narration-settings отдаёт расход, образцы, готовность). Директор и
    админ правят, маркетинг видит. «Автоозвучка: включена, ждёт ключ», пока нет ключа.
  - Новый объект получает следующий шаблон по кругу (`nextNarrationTemplateId`,
    `narrationAutoFlow.ts::startNarrationForNewProperty`).
  - Сведение голоса с музыкой (`lib/narrationMix.ts`, `NARRATION_MIX`): голос выравнивается
    до −16 LUFS (loudnorm), приглушение глубже и плавнее (threshold 0,015, ratio 20,
    attack 10 мс, release 800 мс), на выходе ограничитель `alimiter=limit=0.95:level=0`.
  - Агент видит, если новая озвучка не легла на уже вышедший ролик: `mix.problem`
    (`VOICE_LONGER` — ролик ушёл монтажёру удлинить под голос; `FAILED` — в соцсетях пока
    прежний ролик). Раньше это знали только журнал ошибок и руководство.
  - Плашки-предупреждения и серые подсказки озвучки — на токенах темы (`--warn-bg`,
    `--muted`): в тёмной теме была светлая плашка с невидимым текстом (было и до этой правки).
- Почему: просьба владельца 14.11 — «всю техническую часть убрать в настройки CRM… выбрать
  голос, текст по шаблону, где меняются цифры, несколько шаблонов, кнопка, прослушать и
  одобрить»; и вопрос «сменили цену или скидку — на старый ролик без монтажёра новая
  озвучка, музыка не должна мешать голосу».
- Замер звука (настоящий ffmpeg 9, окна 100 мс; музыка −11 LUFS, голос −17 LUFS):

  | | было | стало |
  |---|---|---|
  | голос громче музыки под ним, в среднем | 8,5 дБ | 18,4 дБ |
  | худшие 10 % речи | −1 дБ (музыка вровень) | 10,5 дБ |
  | голос тише на 9 дБ (другой mp3) | музыка ГРОМЧЕ голоса на 7,8 дБ | выход тот же −14,9 LUFS |
  | музыка в паузах между фразами | поднималась до −17 дБ | держится ниже (−27,5) |
  | музыка после голоса | −14,9 | −16,1 (почти как в ролике) |

  Пик готового ролика −3,9 dBFS, перегруза нет.
- Как проверено: `test:web` 2219/2219; api `narration-*` + `video-handoff*` 313/313 (новый
  сторож «музыка не мешает голосу» на настоящем ffmpeg краснеет на старых настройках —
  проверено); новый `NarrationSettingsPanel.test.tsx`; кадры ПК/телефон/тёмная тема на стенде.
- Известное: `narration-voice-samples` на машине разработчика падает 404, если папка видео
  лежит под путём с точкой (`C:\Users\…\.claude\…`): express `sendFile` не отдаёт файлы из
  «скрытых» папок. На сервере путь без точки; с `PROPERTY_VIDEO_DIR` вне такой папки тест зелёный.
- Не проверено: кадр конца мастера (тот же `NarrationComposer`, покрыт тестом), звук на
  слух владельцем на настоящей озвучке ElevenLabs и настоящей музыке ролика.
- Ревью architect (14.11), исправлено до выката:
  - устаревшая или упавшая версия больше не подставляет свой текст в форму: там прежняя цена
    словами, а сервер текст не сверяет — агент мог озвучить и одобрить старую цену;
  - плеер привязан к версии: прослушка из «Истории аудио» не подменяет запись в «послушайте и одобрите»;
  - UNKNOWN и зависшая генерация — статус «результат уточняет руководство» без формы
    (сервер всё равно ответил бы 409), карточка больше не опрашивает сервер вечно.
  - Оставлено решением владельца/следующей правкой: точный итог возврата монтажёру при
    VOICE_LONGER (сейчас текст карточки не учитывает OFF/IN_MONTAGE/REFUSED), язык версии
    без шаблона, раздел «Озвучка» в поиске по Настройкам, показанный в мастере вариант
    шаблона может разойтись с выданным сервером при параллельном создании.
