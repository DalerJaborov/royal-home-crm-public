# 03.11.2026 — Помощник в группе: ответ на чужое сообщение и окно диалога

- Что изменилось (`telegram/assistantBot.ts`): (1) упоминание бота ОТВЕТОМ на чужое сообщение — его текст/подпись становятся содержанием просьбы («Сообщение от <имя>: «…»»), права и кнопка «Подтвердить» — вызвавшего, в карточке строка «По сообщению <имя>»; медиа исходного сообщения не читается (только текст/подпись). (2) Окно диалога: после обработанного обращения бот ~8 минут (`GROUP_DIALOG_WINDOW_MS`, одна константа) читает следующие сообщения ТОГО ЖЕ человека в этом чате без упоминания; окна раздельные (ключ чат+человек, в памяти процесса — рестарт окна закрывает); внутри окна отвечает только на похожее на просьбу (предфильтр `looksLikeBotRequest`: код объекта, число, глаголы), болтовню молча пропускает без реакций; закрывается по времени, по «стоп/спасибо/отмена/хватит» и после 3 подряд сообщений не к боту. Ответ на сообщение бота — обращение, как раньше. Окно открывается только когда обращение дошло до обработки (группа подключена, сотрудник привязан).
- Почему: решение владельца (03.11.2026) по режиму группы.
- Чем проверено: `tests/assistant-telegram.test.ts` (42): окно открыто/закрыто по времени, чужой человек внутри окна, болтовня, «спасибо», два человека — раздельные окна, ответ на чужое с подтверждением только вызвавшим.
- Что осталось: чтобы бот видел обычные сообщения группы без упоминания, он должен быть админом группы или с выключенным privacy mode (BotFather → /setprivacy → Disable); без этого окно не сработает (бот увидит только команды/упоминания/ответы ему).
