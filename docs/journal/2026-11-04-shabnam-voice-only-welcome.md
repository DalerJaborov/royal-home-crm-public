# 04.11.2026 — Шабнам приветствует группу только голосом

- При подключении группы и при вступлении коллег Шабнам отправляет по одному голосовому на русском и таджикском, без текста и без текстовой замены при недоступности голоса.
- В подключённой рабочей группе распознаются короткие голосовые привязанных сотрудников. Имя помощницы в начале записи работает как обращение; без имени допускаются только ясные запросы на чтение. Пересланные записи не включают этот режим.
- В группе подтверждение цены показывает номер объекта и сумму до и после. После нажатия итог заменяет карточку, без отдельного служебного сообщения.
