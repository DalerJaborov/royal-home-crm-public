# 23.11.2026 — «Настройки звонков — сломан» была ложной тревогой

**Что видел владелец.** «Интеграции → Телефония»: «Настройки звонков — сломан» (нужно «очередь»,
«40 с», «хотя бы один оператор») и «Очередь приёма: доступность — сломан».

**Решение владельца 23.11.2026** (дословно): «теперь звонки должны 10 секунд идти на
+992•••••1515 (2020) если не отвечают сразу директору»; затем: «уже есть работает».

**Что стоит на проде (ФАКТ, чтение 23.11.2026).** Настройки CRM: приём «прямо на аппарат» 2020,
10 с, «если не ответили» = переадресация + автоответчик, номер переадресации = телефон
действующего директора (сверено запросом, номер не печатался), робот на входящих выключен.
Станция (AstDB `ROYALHOME/failover`): `target=2020`, `seconds=10`, `action=both`, номер
директора `+992•••••0555`; аппарат 2020 (Grandstream WP810) зарегистрирован. Схема работает.

**Почему горело.** Сторож `telephonyBaseline.ts` держал эталон 21-24.09.2026 (очередь, 40 с,
оператор приёма) и не знал о решении 18.11.2026 («незнакомые — только на 2020»). Проверка
доступности очереди в `stationHealth.ts` судила очередь, в которую при приёме на аппарат
станция звонки не ведёт (в ней один неактивный оператор на паузе).

**Что изменилось.**
- `telephonyBaseline.ts`: эталон — аппарат 2020 и 10 с; новое правило «Не ответили на
  аппарате — директору» (тревога, если действие не переадресация, номер пуст, номер не
  директора или неотвеченный звонок перехватывает робот); «Аппарат приёма» = 2020;
  «Операторы приёма» судятся только когда приём идёт через очередь. Сверка вынесена в чистую
  `evaluateSettingsBaseline` (тест без базы).
- `stationHealth.ts`: при приёме на аппарат «Очередь приёма: доступность» = «не проверяется»
  (`queueNotUsedCheck`), а не «сломан».
- Тест `telephony-baseline.test.ts`: первый случай — ровно прод-значения 23.11 (на старом
  эталоне падает: проверено подменой обратно на очередь/40 с — 5 падений).

**Проверено.** Чистые случаи сторожа 15/15 (vitest с алиасом shared на исходники: общий
node_modules устарел); tsc по изменённым файлам — только старые ошибки устаревшего shared.
Случаи с базой (операторы, старые снимки) и `queueNotUsedCheck` локально не запускались
(multer в общем node_modules старый) — их прогонит `npm run ship`.

**Осталось.** Ночью (22:00–10:00) аппарат 2020 не звонит: ночное правило «сразу автоответчик».
К аппарату 2020 станция добавляет мобильное плечо сотрудника, за которым числится 2020
(звонит одновременно с аппаратом). Очередь 1000 остаётся запасным путём перевода по коду
объекта и агентского пути без вердикта — в ней сейчас нет живых операторов.
