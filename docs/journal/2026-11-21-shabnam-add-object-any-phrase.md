# 21.11.2026 — Шабнам: «добавь объект» любыми словами

**Жалоба владельца:** «Бот мушовир Шабнам почему не может добавить объект говорит. Мы же дали доступ вроде бы».
Затем: «Да сделай. Исправь, чтобы любые похожие все можно было использовать».

## Причина (по коду)

Права ни при чём: мастер отказывает только СБ и ролям «только просмотр». Мастер объекта в Telegram
(`telegram/assistantPropertyDraft.ts`) открывала только регулярка по началу ТЕКСТА сообщения. Всё
прочее уходило в общий ответ модели, у которой не было инструмента создать объект, — и помощница
честно отвечала «не могу добавить объект». Мимо регулярки проходили:

1. голосовое «добавь объект» — мастер проверял текст до расшифровки;
2. обращение и вежливость — «Шабнам, добавь объект», «Пожалуйста, внеси квартиру»;
3. вопрос и другие глаголы — «можешь добавить объект?», «запиши квартиру», «оформи объект»;
4. просьба в общей группе — мастер живёт только в личке.

## Что изменилось

- `assistantPropertyDraft.ts`: срез обращения («Шабнам,», приветствие) и «пожалуйста / лутфан» в любом
  месте фразы; шире глаголы (можешь, помоги, хотела, запиши, занеси, оформи, «ещё один», «объявление»,
  «мумкин … илова кунед»). Экспорт `isPropertyDraftStartText`.
- `assistantBot.ts`: голосовое после расшифровки проверяется тем же разбором и открывает мастер.
- Новый инструмент помощницы `start_property_draft` (`ai/assistant/tools/startPropertyDraftTool.ts`):
  модель на ЛЮБУЮ формулировку открывает мастер тем же входом, что `/new_property` (права, рубильник,
  черновик — одни). Из группы и из CRM карточка приходит в личку Telegram. Объект этим не создаётся —
  только черновик, поэтому уровень A. Данные, уже названные сотрудником, идут в `details`.
- `telegram/propertyDraftOpener.ts` — посредник: прямой импорт мастера из инструмента замыкал круг
  `ai/assistant.ts → tools → мастер → ai/assistant.ts` (сторож `audit:deps:gate`).
