# 2026-11-14 · Рынок: район объявления из текста, адреса и места

**Проблема.** У Paydo.tj район есть в заголовке карточки («Душанбе | Сино») лишь у ~30% активных объявлений (замер прода 14.11: 4 730 из 15 532), у Somon.tj 67%. Остальные выпадали из сегментов «район × комнаты» и из подбора.

**Что нашли (разведка, образец 320 живых объявлений Paydo, только чтение публичного API).**
- В списке API лежит `description_fields[].text` — текст описания продавца. Парсер его не читал. В образце у 227 из 293 объявлений без района в нём есть «Район: Шохмансур», «Ноҳия: И Сомони» и подобное (77%).
- Координаты есть у 68 из 293 пустых (23%), адрес — у 12 (4%). В заголовке после типа дома стоит ориентир («Кароболо», «Саховат», «Дом печать»).
- Старый вывод по координатам брал «ближайший центр района до 6 км» — это догадка.

**Что сделано.**
- `lib/market/districtInference.ts` — `resolveDistrict`, лестница: район источника → координаты в полигон района (`districtByPoint`, без «ближайшего центра») → подписанное поле в тексте («район/ноҳия/р-н/н.») → улица из справочника улиц → целый фрагмент адреса = название района → место из `FOLK_PLACES` в заголовке/адресе. Спор двух районов на одной ступени = null. Голого «Сино» в свободном тексте нет («Ибни Сино», «проспект Сино» — улицы).
- `paydoParser`: `description` из `description_fields` (в базу не пишется). `marketStore.saveListings`: район выводится лестницей; уже записанный район не перебивается выведенным.
- Удалён `districtResolver.ts` (+ его тест): его «ближайший центр» заменила честная лестница.
- `apps/api/scripts/backfill-market-districts.ts` — дозаполнение существующих строк: dry-run по умолчанию, `--apply --force` для записи, до/после доля, копия меняемых строк в temp перед записью, `--source=`. Описание в базе не хранится, поэтому «подписанное поле» дозаполнится при очередном обходе Paydo, скрипт берёт координаты/адрес/заголовок.
- Тесты: `tests/market-district-inference.test.ts`.

**Не делали.** Somon: `detectDistrictInText` ищет «сино» подстрокой — «Ибни Сино» даст ложный Сино (старое поведение, не трогал). Прод не запускали.
