# 2026-10-31 — помощник П3, группа «чтение» (уровень A)

Ветка `feat/assistant-p3-read-31-10`. Документ-источник: `docs/design/internal-assistant-architecture-2026-10-31.md` §3.

## Что сделано
Пять инструментов чтения в `ai/assistant/tools/` (список — `readTools.ts`), у каждого в описании «когда звать / когда НЕ звать», ссылки `href` (`/clients/<shortId>`, `/properties/<shortId>`):
- `find_clients` — слова (ФИО, адрес, «заметки», желаемый район), агент по имени, район, статус, источник, «горячие», до 20.
- `find_property` — номер («ОБ-000088», «88»), id, ссылка Instagram (по коду поста, в т.ч. фото-посты), адрес/название; до 5; проданные и снятые находятся со статусом; Somon — честное «в карточке не хранится».
- `get_client_card`, `get_property_card` — карточка целиком. Клиент — через `presentClient` (маски телефона/источника, как GET /clients/:id).
- `list_my_tasks` — задачи и показы актора за день Душанбе + просроченные.

## Общие модули (REST и помощник зовут одно)
- `lib/clientSearchWhere.ts` — вынесено из `routes/clients/list.ts` без смены поведения: текстовый поиск, срез агента (покупатели/продавцы), скрытие карточек с заявкой на удаление, простые фильтры, `clientIdsWithUnreadReply`. Права приходят флагами, не `req`.
- `lib/propertyRefLookup.ts` — разбор «ссылки на объект».
- `lib/agentNameLookup.ts` — байт-в-байт копия файла из ветки `feat/assistant-p3-owner-31-10` (общий поиск сотрудника по имени); при сведении совпадёт без конфликта.
- `tools/safeField.ts` — копия `safeField` из `assistant.ts` (там не экспортируется, а файл не наш); при сведении `assistant.ts` может импортировать её.
- Миграция `20261031141500_client_address_notes_trgm` — GIN trgm на `Client.address` и `Client.requirementsNotes` (+ объявление в schema.prisma, `migrate diff` пуст).

## Права (как в REST)
- Рядовой агент в `find_clients`: только свои, ПРИНЯТЫЕ, покупатели/продавцы; непринятые лиды исключены совсем (не маскируются, как в `search_clients`, — иначе фильтр по адресу/району работал бы подсказкой по закрытому содержимому); чужого агента фильтром не задать.
- Корзина скрыта везде; висящая заявка на удаление прячет клиента у агента без `clients.delete` и объект у её автора без `properties.delete`.
- Поиск по телефону — только при `clients.viewPhone`, по нику — при `clients.viewOrigin` (как в списке).
- Контакт собственника — `stripOwnerContact` (та же функция, что REST).
- Данные клиентов — в `<client_content>` через `safeField`; телефон — `clientPhoneFor`.

## Что осталось / риски
- Карточка клиента строже REST: агент не открывает чужого клиента «по своей сделке / бывший владелец» (как `get_client_history`).
- `list_my_tasks` не добавляет `COUNTED_SHOWING_WHERE`: `TASK_WHERE` уже требует `nextAction`, а отменённый показ его теряет.
- `find_clients` на пустом результате с `q` пробует триграммы по ФИО (как список), поэтому на цифровом запросе может вернуть «похожие по написанию» — помечено `note`.
- Не тронут `assistant.ts`: старый `search_clients` и его локальный `safeField` остались.
