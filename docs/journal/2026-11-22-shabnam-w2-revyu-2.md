# 22.11.2026 — Шабнам, волна 2: правки по повторному ревью

Повторное ревью ветки `claude/shabnam-wave2-17-11` (PR #386) нашло два блокера и три важных. Каждое закрыто
в коде и тестом, который без правки красный (проверено: `src` откатан к 71456221, новые тесты — 16 красных).

- **Блокер: список навсегда «уже записан».** Ключ карточки из списка в прошлом сообщении был отпечатком ТЕКСТА
  (`list:<хэш>`) и уходил в постоянный уникальный `Expense.requestKey`: тот же список завтра (аренда, интернет)
  не записался бы никогда. Теперь ключ — номер исходного сообщения `tg:<чат>:<сообщение>` (тот же, что у хода
  модели); номер пишется в состояние разговора вместе с историей (`lastUserTurn`, сверка по отпечатку текста).
  Нет номера (старая история) — отпечаток + день по Душанбе (`dushanbeDateString`).
- **Блокер: запись состояния разговора мимо двери.** Правка строки карточки (`rememberFix`/`clearFix`) собирала
  payload заново и стирала фото, «внеси расходы» и вопрос про файл; вопрос «Это расходы?» и ответ на него,
  «удали всё» писали прочитанное раньше без замка. Теперь все записи состояния помощницы — через
  `telegram/assistantDialogState.ts` (`withAssistantDialog` / `mergeAssistantDialog` / `patchLiveAssistantDialog` /
  `clearAssistantDialog`): слияние полей под замком строки. Первая запись в пустой чат: сначала
  `INSERT … ON CONFLICT DO NOTHING` (замок на несуществующую строку ничего не запирал — параллельные писатели
  затирали друг друга), лишняя заготовка убирается. Сторож `apps/api/tests/assistant-dialog-state-one-door.test.ts`:
  точное число прямых записей по файлам (свои виды разговора — модерация, монтажёр, мастер объекта — вписаны с
  причиной), файлы помощницы — ноль.
- **Подсказки «удали последнее / удали всё / охиринро нест кун / ҳамаашро нест кун»** из вопроса «Что убрать?» не
  распознавались. Слова «всё/последнее» принимаются, только когда кроме глагола и этого слова в реплике ничего нет:
  «убери всё лишнее из описания» чат не стирает.
- **«Внеси расходы» после записанной карточки** теперь всегда запоминает намерение (фото следом — расходы);
  «уже записаны» — только если исполненная карточка последнее действие помощницы, иначе «пришлите список».
- **«Такси 20» второй раз за час** больше не глотается прошлой карточкой: «уже записано» — только карточка из того же
  исходного сообщения или последняя карточка с тем же набором строк целиком (не подмножество).
- Миграций и новых рубильников нет.
