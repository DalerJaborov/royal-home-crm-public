# 2026-11-21 — ИИ-разбор рекламы и утренний брифинг не отдают деньги компании без finance.view

## Что было
- `lib/ads/adInsights.ts` клал в подсказку модели «прибыль N с.» по проданным объектам и текст
  про среднюю комиссию, кэш разбора был один на всех. Раздел открыт MARKETING / marketing.access
  без finance.view, и разбор, построенный для директора, сутки отдавался маркетологу.
- Тот же класс в `lib/morningBriefing.ts`: брифинг (`dashboard.analytics`, есть у MANAGER без
  finance.view) содержал «Комиссия с начала месяца» и в тексте, и в числах, кэш один на всех.

## Что сделано
- `buildAdInsights(month, force, { seesCompanyMoney })`: два варианта (с деньгами и без), два кэша
  по признаку права; без права ни прибыли, ни слов про комиссию в подсказке нет вообще.
  Роут `/ads/insights` передаёт `permissions.has("finance.view")` (как `/ads/report`, #336).
- Брифинг: два кэша (`money`/`plain`), `commissionMonth` в общей схеме стал `nullable`,
  без права — null в числах, строки про комиссию нет в подсказке и в запасном тексте.
- Уже было правильно (проверено): `marketingInsights.ts` (два кэша), «Вопрос к данным»
  (`buildAskContext(seesMoney)`), ассистент (`canViewFinance`), секции пульта (ключ кэша с seesMoney).

## Чем проверено
- Новый `tests/ads-insights-money.test.ts` (перехват промпта; директор / маркетолог / оба порядка кэша);
  `tests/morning-briefing.test.ts` дополнен (руководитель без finance.view).
- Поломка нарочно: `money = true` и общий ключ кэша — тесты краснеют.

## Осталось
- Push-сводка 08:00 (`cron.ts`) содержит комиссию: уходит по списку получателей, не через общий кэш; не менялось.
