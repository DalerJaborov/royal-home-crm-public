# 2026-11-04 — прямая загрузка Facebook Reels

При публикации готового ролика Meta вернула HTTP 422 на этапе загрузки по ссылке: `403 Restricted by robots.txt`. CRM отдавала полный исходный MP4 по подписанному URL; Meta приняла тот же файл прямой загрузкой и подтвердила `upload_complete`. Диагностика не вызывала публикацию.

Для Reels CRM теперь отправляет файл с диска по документированному бинарному протоколу Meta. Сохраняются отдельные этапы создания, загрузки и публикации, правила безопасного повтора и защита от дублей. Доступ к файлам CRM не меняется.

Регрессионный тест проверяет байты файла и заголовки запроса загрузки, а существующие тесты — повторы до соединения и обработку потерянного ответа.
