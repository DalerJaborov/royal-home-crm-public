# 2026-11-21 Дашборд директора на главной

Решение владельца: «Дашборд же должен на главной отображаться».

- Главная «/» у DIRECTOR, ADMIN и HEAD_OF_SALES с правом `reports.view` = полоса «Требует внимания сейчас» (ждут ответа, пропущенные звонки, ждут принятия; только ненулевое, иначе «Срочного нет») и под ней дашборд (`pages/DirectorDashboard.tsx`, режим `embedded`, h2 «Показатели компании»). Правило выбора одно: `lib/homeDashboard.ts`.
- Старые блоки главной директора и РОП (деньги, команда, графики, решения) с главной не выводятся (остались в реестре для руководителя без `reports.view`). «Без контакта» и «просрочено» в полосу не ставили: они уже в «Скорости ответа» дашборда.
- Пункт «Дашборд директора» убран из меню «Отчёты»; `/director` у этих ролей перенаправляет на «/».
- «Оформление → Главная» (HomeBlocksSettings) для этих ролей скрыто; у остальных не тронуто.
- Тесты: `dashboardHome.test.tsx` (выбор главной по роли), правки `HomeBlocksSettings.test.tsx`, `tileTone.test.ts`; e2e `new-look-director-dashboard`, `new-look-leader-home`, `new-look-home-core` (@smoke, 390 и 1440).
