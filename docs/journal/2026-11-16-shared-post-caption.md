# 16.11.2026 — Бот узнаёт объект из пересланного поста и отвечает на «а видео есть?» (доработано по ревью 17.11)

- **Что изменилось.**
  - Номер «Объект №N» с картинок клиента доходит до ответа и тогда, когда ход с картинкой отложен ради следующего сообщения. Подпись поста, которую передаёт Meta, сохраняется как служебные данные и тоже даёт номер.
  - По ревью #225 номер из подписи или с картинки берётся, только если рядом есть наша метка: имя компании или страницы из CRM либо телефон компании или агента из CRM. Поля, которые там напечатаны (комнаты, площадь, район), сверяются с карточкой.
  - «Видео есть?» решается только по словам самого клиента и только про объект из этой же пачки сообщений. Ответ по CRM: рилс, иначе готовый ролик карточки, иначе «видео пришлёт агент» с сигналом агенту. Вопрос о цене или адресе в той же фразе получает ответ вместе с видео. «Видео не нужно», «видел» и любой другой вопрос уходят модели.
  - Голая фраза «Хами хонара видеоша дорен» теперь определяется как таджикская.
- **Почему.** Чат Instagram 16.11, 21:29–21:30: на вопрос про объект №178 бот ответил «какой объект?». Ревью #225 нашло, что первая версия могла уверенно назвать не тот объект: служебная пометка «[вложение: video]», старый фокус, номер с чужого поста.
- **Чем проверено.** `tests/customer-shared-post-caption-16-11.test.ts` (48) и `tests/customer-shared-post-16-11-postgres.test.ts` — каждый сценарий ревью. Плюс связанные наборы, tsc, аудиты, map:check.

  - Таджикская строка «…-ро агенти мо ба шумо мефиристад» не сверена с разговорником.
  - Нет рубильника «отвечать на "видео есть?" из CRM».
  - После #205 провести видео-строку через его защиту от повторов.
