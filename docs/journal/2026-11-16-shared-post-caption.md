# 16.11.2026 — Бот узнаёт объект из пересланного поста и отвечает на «а видео есть?»

- Что изменилось: (1) подпись пересланной публикации (`payload.title` у Meta) с «Объект №N» стала ссылкой на объект той же публикации: если публикации нет в нашем реестре (свой аккаунт агента, репост), объект находится по номеру; если реестр и подпись спорят — «неясно», бот не выбирает сам. (2) Номер «Объект №N», прочитанный на картинке (скриншот поста), теперь доходит до ответа и тогда, когда ход с картинкой отложен ради следующего сообщения клиента (`loadDeferredCustomerMediaEvidence` → `enrichCustomerAgentDeferredMediaFocus`). Одна дверь для «картинка → номер объекта»: `customerPropertyEvidenceFromMedia`. (3) «Видео этой квартиры есть?» про определённый объект отвечает сервер по CRM: ссылка на опубликованный рилс, иначе «видео пришлёт агент» и сигнал агенту через `signalStaffFollowUp`.
- Почему: живой чат Instagram 16.11, 21:29–21:30. Клиент прислал наш пост объекта №178 двумя картинками (Meta отдала тип `image`, без подписи и номера публикации) и спросил «Хами хонара видеоша дорен». Оба хода с картинками отложены ради следующего сообщения до того, как сработало распознавание номера; у вопроса своих ссылок нет — бот спросил «какой объект?».
- Чем проверено: `tests/customer-shared-post-caption-16-11.test.ts` (форма вебхука 16.11, подписи, резолвер, видео), `tests/customer-shared-post-16-11-postgres.test.ts` (настоящая база: приветствие, две картинки, вопрос → ответ про объект; без видео — сигнал агенту; позднее названный объект не перебивается). С выключенной правкой тест на базе красный. Связанные наборы тестов зелёные, типы, audit:deps:gate, map:check.
- Что осталось: таджикская строка «Видеои объекти №N-ро агенти мо ба шумо мефиристад.» не из проверенного разговорника — сверить; цена в подписи поста №178 (601 250 с.) не совпадает с ценой в CRM (820 000 TJS) — решить владельцу; короткое «Хами хонара видеоша дорен» само по себе определяется как русский (язык решает приветствие раньше).
