# Ролик после монтажа: только хозяину, автопубликация без ответа (15.11.2026)

Решения владельца: ролик и напоминания получает только хозяин объекта, админу и руководству в Telegram не слать; не ответил — ролик публикуется сам.

## Что изменено
- `telegram/clipReviewBot.ts::notifyClipReview`: при включённом `clipOwnerApproveEnabled` ролик уходит ТОЛЬКО хозяину (раньше хозяину + всем с `clipReviewTelegram`). Нет Telegram у хозяина — никому; решить можно в карточке CRM, закроет таймер.
- `lib/clipReview.ts::runClipReviewStaleTick` и `remindClipReview`: при 0 часов напоминание «ждёт 3 ч» идёт только хозяину (с его кнопками), без руководства и `montageNotificationRecipients`.
- Автопубликация уже была (PR #142, `runClipOwnerAutoPublishTick` -> `approveClip(..., "auto")`, одна дверь с ручным «да», ночь 00-07 по Душанбе не публикует). Добавлено: 0 часов = «не публиковать сам» (`clipOwnerDueOrNull`, `isClipOwnerMode` в `lib/clipOwnerDue.ts`; в Настройках пункт «Не публиковать сам»); хозяину одно короткое сообщение «опубликован сам» (`tellOwnerAutoPublished`), только если ролик ему приходил.
- Признак «решает хозяин» больше не только `clipOwnerDueAt`: ещё и «рубильник вкл + 0 часов» (рассылка, напоминания, кнопка в карточке CRM).

## Не менялось
Ролик до включения рубильника (срока нет) остаётся за руководством; кнопки в CRM у модераторов остаются; старые кнопки руководства в Telegram по-прежнему работают.
