# 16.11.2026 — замок опасных прав РОП и маркетинга, номера только директору

## Решение владельца (дословно, 16.11)
«убирай опасные права у РОП и маркетинга, номера не видит роп и вообще никто не видит
номера телефонов кроме директора самого».

## Что изменилось
- **Номера.** `clients.viewPhone` и `properties.viewOwners` помечены `directorOnly`:
  выдаются только DIRECTOR, личной галочкой не выдаются никому (даже ADMIN), из всех
  пресетов убраны. Маска и «Позвонить» через АТС работают как раньше; свой объект
  сотрудник видит целиком (правило `stripOwnerContact`).
- **РОП (пресет).** Убраны `properties.editForeign` (цену чужого объекта — заявкой),
  `calls.hearRecording` (звук звонков; расшифровки остались).
- **Маркетинг (пресет).** Убраны `properties.export`, `calls.transcripts`,
  `calls.hearRecording`. Фото/видео/описание ведёт как раньше.
- **Сделки** (`lib/dealWrites.ts`, `routes/dealDocuments.ts`): свою сделку не закрывает,
  не аннулирует и не чистит её документы тот, у кого нет `finance.manage` (РОП);
  переоценка закрытой сделки и отметка «комиссия выплачена» — только `finance.manage`.
- **Шабнам** (`deletePropertyTool.ts`): чужой объект удаляется только с `properties.delete`
  (раньше хватало `editForeign` — дыра Д1).
- **Каналы и реклама:** подключить/отключить кабинет Meta, TikTok, Threads, Google,
  Яндекс — только `finance.manage` (`requireChannelAdmin`); боевой режим автопродвижения
  роликов — тоже.
- **Объекты:** маркетинг и монтажёр не меняют цену, валюту, цену продажи и контакт
  собственника чужого объекта (`routes/properties/crud.ts`).

## Что осталось
- Повторное подтверждение входа (step-up) на подключение каналов — сейчас только роль.
- Права рекламы и публикации в соцсетях всё ещё проверяются по названию роли
  (`marketingRole.ts`, `adsAccess.ts`), не галочками.
- Завести клиента через API маркетингом (М14), пауза очереди монтажа монтажёром.
- Личные галочки конкретных людей на проде могли быть выданы сверх пресета: после выката
  `directorOnly` их вычёркивает сам, остальное смотреть на экране «щит сотрудника».
