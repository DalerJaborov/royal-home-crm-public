# 27.11.2026 — WhatsApp на обоих номерах: приветствие, обратный звонок, команды

- Что изменилось:
  - **Приветствие** (`messengers/whatsappServiceEvents.ts`). Событие Meta `request_welcome` (человек впервые открыл
    чат и ничего не написал) теперь получает одно сообщение от бренда своего номера («Арван» или «Royal Home»):
    по-таджикски и по-русски, один вопрос «купить или продать». Ни переписки, ни заявки, ни пуша агентам, хода
    ядра нет. Переписка с человеком на этом номере уже есть — молчим. Повтор доставки — без второго приветствия
    (замок по wamid, канал `WHATSAPP_SERVICE` в `ProcessedMessage`). Аварийная кнопка `CUSTOMER_AGENT_CHANNEL_OFF`
    глушит и его.
  - **Обратный звонок**. `interactive.call_permission_reply` с `response=accept` и `response_source=user_action`
    заводит просьбу о звонке (`CallbackRequest`, та же дверь `routeMessengerCallbackRequest`/`recordCallbackRequest`):
    у клиента есть агент — пуш ему и запись в истории карточки; агента нет — очередь CRM и пуш тем, кто работает с
    сообщениями. В тексте просьбы бренд и номер линии: «в WhatsApp «Арван» (+992 87 791 4444) разрешил нам позвонить».
    `automatic` (разрешение за сам факт звонка клиента; сам звонок CRM видит со стороны станции) и `reject` — одна
    строка в журнале. Повтор — одна просьба (замок по wamid + одна открытая просьба на человека).
    `routeMessengerCallbackRequest` принимает `conversationId: null` и `phone`.
  - **Команды** (`messengers/whatsappCommands.ts`): `/харидан`, `/фурӯхтан`, `/агент`, `/суроға` (по-таджикски, поправка
    владельца). Разбор вебхука (`meta.ts::parseIncoming`) переводит команду в слова человека («Мехоҳам хона харам»…),
    и дальше обычный ход ядра. Написания без таджикских букв, латиницей и по-русски (`/купить`, `/адрес`) тоже понятны.
    `/агент` даёт фразу, которую ядро узнаёт как просьбу живого человека. Адрес у обоих брендов один — Бухоро 49,
    2 этаж. Список для Meta берётся из того же файла (`whatsappCommandsForMeta`), подсказки — `WHATSAPP_PROMPTS`
    (только две таджикские, поправка владельца).
  - **Рубильники** (по умолчанию ВКЛ, `off` выключает): `WHATSAPP_WELCOME`, `WHATSAPP_CALLBACK_REQUESTS`,
    `WHATSAPP_COMMANDS`; переданы в контейнер через `docker-compose.prod.yml` (сторож `env-reaches-container`).
  - **Шлюз**: `graph-call.mjs`/`wa-calling.sh` — операции `callback-on`/`callback-off` (с `--number=`); `enable` больше
    не выключает `callback_permission_status` (раньше повторный enable молча гасил обратные звонки).
- Почему: просьба владельца 27.11.2026 — обратные звонки, приветствие и команды на обоих номерах; события Meta о
  разрешении звонить и о первом открытии чата CRM раньше только отсеивала, и они терялись.
- Источники (ФАКТ): developers.facebook.com — calling/user-call-permissions (поля call_permission_reply), calling/call-settings
  (callback_permission_status), phone-numbers/conversational-components и справочник Conversational Automation API
  (commands ≤ 30, имя ≤ 32, подсказка ≤ 256, enable_welcome_message). Форма `request_welcome` в нынешней документации
  не описана — по прежней версии и по уже работающему отсеву.
- Чем проверено: `tests/whatsapp-welcome-callback-commands.test.ts` (15: команды, лимиты Meta, тексты без «—»,
  разбор, вебхук целиком на номере с брендом «Арван»: одно приветствие, повтор без второго, молчание при живой
  переписке, рубильники, одна просьба на повтор и второе разрешение, просьба на карточку агента с пушем и записью
  в истории, automatic/reject без просьбы), `tests/whatsapp-call-webhook.test.ts` (13) — зелёные; `tsc` api чистый.
- Что осталось: живая проверка с телефона на обоих номерах; ответ ядра на `/суроға` у «Арвана» (адрес из фактов
  агентства) живьём не проверен; позвонить клиенту через WhatsApp CRM не умеет (исходящие звонки WhatsApp не
  построены) — агент перезванивает с обычного телефона.
