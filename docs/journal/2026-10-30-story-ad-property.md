# 2026-10-30 — ответ на нашу сторис и клик по рекламе знают объект (пачка P1)

Что: `meta.ts` читает `reply_to.story.id` (`replyToStoryId`); evidence сторис = `{media, story, <id>}`, CDN-url больше не даёт `untrusted_origin`, когда id есть. `PropertyStoryPost.mediaId` находит объект. Клик по рекламе без сообщения (`referralOnly`) запоминается и при приёме CORE (`customerIngressNormalize`) подмешивается как ad-evidence следующему сообщению того же peer за ≤10 мин, если у сообщения нет своей ссылки/рекламы; итог фиксируется на MID (повторная доставка даёт то же), webhook гасит память после первого CORE-сообщения. Причина `ad_unmapped` («По этой рекламе объект не определился») вместо «по ссылке или номеру».
Почему: живые случаи Instagram 30.10 (сторис ОБ-000082, ОБ-000150, реклама).
Проверено: build api (0), `customer-story-ad-evidence`, `customer-story-ad-postgres`, смежные тесты, атака `--model scripted --category media` 25/25 (+5 сценариев со `storyReply`).
