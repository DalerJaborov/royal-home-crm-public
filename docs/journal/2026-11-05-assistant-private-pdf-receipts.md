# 05.11.2026 — Расход по одному PDF-чеку

- Директор может отправить в привязанную личку один PDF-чек с подписью «Чек» или «Расход». Шабнам показывает сумму и назначение и записывает расход после одного подтверждения.
- Принимается одна страница без пароля размером до 2 МБ. Сумма должна читаться на странице. После записи исходный PDF доступен среди закрытых вложений расхода.
- Проверены отрисовка PDF, права директора, повторные подтверждения и сохранение оригинала. Таблицы с несколькими расходами требуют отдельного импорта.
