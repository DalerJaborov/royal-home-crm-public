# Отчёты: дата целиком на узком экране

На мобильном экране поле даты в clean Reports сжималось до 145 px: при шрифте 16 px и внутренних отступах обрезался год рядом с календарём. Mobile flex-basis увеличен со 140 до 180 px, чтобы поля переносились раньше; размер шрифта и desktop-правила сохранены.

Проверка: исходный дефект воспроизведён на 390 px. Временное CSS-правило на реальной странице проверено визуально на 360/390/430/819/1440 px: обе даты целиком, шрифт 16 px, горизонтального overflow страницы нет; desktop остаётся прежним. Временное правило удалено, viewport восстановлен, вкладка закрыта. Это браузерная эмуляция, не физические телефоны; данные и production CSS не менялись. Источники используют отдельный layout и этим селектором не затронуты. Сборку общего релиза выполняет владелец PR; отдельный полный precheck ради одной CSS-строки не запускался.
