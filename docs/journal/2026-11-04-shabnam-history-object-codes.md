# Номера объектов в истории рабочих групп

Шабнам одинаково распознаёт номер объекта при сохранении сообщения и поиске по истории. Формы вроде «ОБ-123», «ОБ 123» и «ОБ №123» теперь ведут к одним и тем же новым записям. Поиск поддерживает весь диапазон номеров из CRM. Правила, по которым команда изменения создаёт карточку подтверждения, остаются прежними.

Записи, сохранённые до исправления без номера в поисковом индексе, автоматически не переиндексируются. Их по-прежнему можно найти по точному ответу на исходное сообщение.
