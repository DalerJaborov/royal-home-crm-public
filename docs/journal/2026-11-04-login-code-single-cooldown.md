# 04.11.2026 — Один код входа и один таймер повторной отправки

- Причина: запасная доставка пуш-кода и отдельная кнопка Telegram могли прислать разные коды в пределах минуты. Ограничение действовало отдельно по каналам, а интерфейс считал наступление таймера подтверждением доставки СМС и неверно читал данные ответа 429. При открытии `/login` действующая сессия также не проверялась.
- Изменение: выдача кода резервируется под блокировкой строки сотрудника до вызова провайдера. Общая пауза 60 секунд распространяется на все каналы; неудача всех провайдеров освобождает резерв. Автоматическая доставка использует исходный код, проверяет срок, подтверждение, погашение и наличие более нового кода перед каждой попыткой. Ответ учитывает уже потраченное время доставки.
- Интерфейс: один спокойный таймер отключает обе кнопки повторной отправки, включая подтверждение личности. Канал не угадывается по времени. Форма кода получила ровные отступы, читаемые ошибки без декоративной красной точки и мобильные размеры элементов. `/login` перенаправляет существующую сессию домой; при перезагрузке сначала проверяет refresh-cookie. Временный сбой сети/502/503 сохраняет сессию и показывает повтор восстановления, а не запрос нового кода; подтверждённый 401 возвращает форму входа. Новый вход сохраняет предложение привязать passkey.
- Проверка: 32 API-теста на отдельной PostgreSQL с синтетическими данными; параллельная выдача, смена канала, отказ доставки и повтор, задержка провайдера, устаревший fallback, истечение и погашение. 40 frontend-тестов проверяют первый экран сессии, actual refresh/store при 502/503, восстановление после сбоя и настоящий 401, тексты канала и серверные сроки 429. API build, focused frontend ESLint, Vite bundle и dependency gate прошли. CUA-проверка на локальных API-фикстурах: повторное нажатие, общий таймер 429, восстановление/истечение/ошибка refresh, размеры 360–430 и desktop 1440; это эмуляция, не физические телефоны и не реальная отправка кода.
- Осталось: обязательные полные cloud checks, обычный release и проверка установленной версии. Уже начатую отправку внешнему провайдеру нельзя отозвать; перед следующей попыткой устаревший код отбрасывается. Реальные СМС, Telegram и push в ходе регрессий не отправлялись.
