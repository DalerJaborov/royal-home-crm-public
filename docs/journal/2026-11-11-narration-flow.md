## Дополнение 11.11.2026 — цену говорим, звук в вышедшем ролике, кончились кредиты

- Решение владельца: «Да, говорить цену». Слово шаблона `{цена}`: по-таджикски словами
  (`ҳаштоду панҷ ҳазор доллар`, `сомонӣ`), по-русски цифрами со склонением (`2 доллара`,
  `сомони`), без цены — «бо мувофиқа» / «договорная» (таджикскую форму проверить носителем).
  Цена теперь входит в факты озвучки: смена цены → новая версия (пауза 3 мин сливает правки) →
  агенту на одобрение. Запрет цены в тексте снят. Миграция `20261111150000_narration_price`
  дописывает `{цена}` в стартовые шаблоны ТОЛЬКО если их текст не правили (проверено на базе:
  правленый и свой шаблон владельца остались как были).
  Побочный эффект: у уже сохранённых версий старый хэш фактов — они станут «устаревшими» (сейчас
  это только PREVIEW-данные).
- «Заменить только звук»: после одобрения новой озвучки, если ролик уже вышел, а прошлая версия
  реально ушла монтажёру (SENT), объект возвращается монтажёру существующим `sendBackToMontajer`
  с новой причиной `NARRATION_CHANGED` («заменить только звук, монтаж прежний», не брак монтажёра)
  и `removeFromSocial: "on-new-video"` — старые посты снимет публикация нового ролика (тот же путь,
  что у перемонтажа по цене). Только самая новая одобренная версия, только при LIVE, не когда
  объект уже у монтажёра. Одобрение агента = согласие (решение владельца), поэтому зовётся сам
  возврат, а не обёртка кнопки «после публикации — руководству».
- Кончились кредиты ElevenLabs (`quota_exceeded`): код `PROVIDER_QUOTA_EXCEEDED`, денег не
  списано. Автоозвучка не теряет версию: она снова ждёт (раз в час одна проверка), одна запись
  `logSystemError`, агенту ничего; в Настройках озвучки — «Кредиты ElevenLabs закончились».
  Кнопка маркетинга отвечает 402 понятным текстом.
