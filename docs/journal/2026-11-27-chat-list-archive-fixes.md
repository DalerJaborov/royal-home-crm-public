# 27.11.2026 — Список чатов: «Архив» вниз, вечная загрузка архива, ручной архив, фото в шапке

- Что изменилось:
  1. «Архив · N» ушёл с верха списка: тихая строка в конце списка «Все» и пункт «Архив» в меню фильтров (кнопка с ползунками). Внутри архива шапка «Архив · N» осталась как кнопка «назад».
  2. Архив вечно показывал «Загружаем диалоги» и «Архив · 0». Причина (по коду, не воспроизведена на живой базе): список «Чатов» перезапрашивался волной живых событий каждые 5 секунд с обрывом идущего запроса (`invalidateQueries` по умолчанию делает `cancelRefetch: true`). Длинный запрос архива на живой базе при потоке входящих не успевал вернуться никогда, данных нет, число берётся из пустого ответа, отсюда «0». Теперь волна не обрывает идущий запрос (`cancelRefetch: false`, `lib/liveEvents.ts`); число в шапке держит последнее известное; через 8 секунд ожидания показывается «Список грузится дольше обычного» и «Повторить»; пустой архив пишет «Архив пуст».
  3. Ручной архив: свайп влево по строке на телефоне («В архив», в архиве «Вернуть»), «…» и правый щелчок на компьютере. API `POST /conversations/archive-mark` ({id, action: archive|restore}; id как в списке: `client:…`, `tg_…`, `td_…` или id диалога). Колонки `archiveMark`/`archiveMarkAt` на трёх таблицах переписок (миграция `20261127090000_chat_archive_manual`, только ADD COLUMN). Отметка действует, пока нет нового входящего (`archiveMarkAt >= lastMessageAt`): новое сообщение само возвращает чат. «Вернуть» (RESTORED) не даёт правилу «30 дней тишины» убрать чат обратно. Рубильник `chatArchiveEnabled` по-прежнему выключает всё, включая ручную отметку.
  4. Шапка открытой переписки показывает ту же миниатюру собеседника, что и список (`avatarUrl`, `avatarSeed` в ответах `/conversations/:id` и `/conversations/groups/:groupId`).
