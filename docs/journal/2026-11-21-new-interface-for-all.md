# 21.11.2026 — Новый интерфейс и «Новый вид» всем, блок «Новый интерфейс CRM» убран

- Решение владельца (дословно): «Удали это и включи просто новый интерфейс для всех и всё»
  (про блок Настроек «Новый интерфейс CRM»: включение по сотрудникам и ролям и список
  «Новый вид»). Раньше — «да» на «одна оболочка для всех, старую тему удалить» (20.11).
- Что изменилось:
  - Одна точка решения: `UI_SHELL_FOR_EVERYONE = { enabled: true, look: "royal" }` в
    `packages/shared/src/uiShellRollout.ts`. Её отдаёт сервер на `GET /ui-shell` (для вкладок,
    открытых до выката) и берёт клиент без запроса (`apps/web/src/hooks/useCleanShell.ts`).
  - Чистая оболочка и «Новый вид» — всем ролям, на ПК и на телефоне, агентам на телефоне тоже.
    Запроса `/ui-shell` на старте нет: первый кадр сразу новый, без заглушки ожидания.
  - Убраны: блок `UiShellRolloutSection` (вкладка «Агентство» и «Система / Рабочее место»),
    `uiShellDraft`, `ShellAppearanceRecovery`, `hooks/shellDevicePolicy.ts` (запрет оболочки на
    телефоне агента и локальный предпросмотр `?agentMobilePreview=1`), маршруты
    `GET/PUT /api/v1/ui-shell/config`. Поле `Settings.uiShellRollout` в базе не удалено
    (миграции нет), больше не читается и не пишется.
  - Аварийный выход — только адрес `?look=legacy`: прежний интерфейс на ЭТОЙ вкладке до
    закрытия (sessionStorage), `?look=royal` — обратно. Прежние постоянные ключи `rh-look:*`,
    `rh-shell:*`, `rh-look-granted:*` не читаются и стираются при входе — чтобы забытый когда-то
    отказ не держал человека в старом интерфейсе.
- Карта: из карты ушли два пути сервера (`/ui-shell/config`) — убраны намеренно
  (`MAP_GATE_ALLOW_REMOVALS=1`, метка `карта-убрано-намеренно`).
- Чем проверено: сборка shared/api/web; `test:web`; `apps/api/tests/ui-look-royal.test.ts`
  (все роли получают новый интерфейс, `/config` — 404); новый e2e
  `tests/e2e/agent-phone-every-screen.spec.ts` — агент на 390 px (chromium) и WebKit iPhone
  проходит главную, все пункты своего меню, карточки клиента и объекта, мастер объекта:
  новая оболочка, без экрана ошибки, без ошибок консоли, без вылета по ширине.
- Риск: серверного аварийного рубильника «выключить всем» больше нет — откат только
  выкатом прежнего кода или личным `?look=legacy`.
- Что осталось (следующей правкой): удалить прежний телефонный интерфейс агента
  (`components/mobile/*`, `components/home/mh/*`, `useLegacyAgentMobile`) вместе с `?look=legacy`;
  убрать подмены `/ui-shell` из `new-look-*.spec.ts` (теперь они ничего не делают);
  страница входа на новом устройстве всё ещё в прежнем виде (флаг устройства ставится после входа);
  кадры агента на 390.
