# Защита зависимости архивирования

Обновлена только вложенная minimatch у readdir-glob до 11.0.1: исправление GHSA-g3hv-75wg-m249 без несовместимого понижения archiver. Архивы CRM продолжают создаваться через потоки файлов. Добавлена проверка реального ZIP с рекурсивным поиском, исключениями и содержимым; существующие проверки ошибок потоков сохранены.

Нулевой npm audit для production-зависимостей не означает отсутствие иных уязвимостей. Dev-зависимости оцениваются отдельно.
