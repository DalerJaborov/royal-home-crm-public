# 17.11.2026 — Пакет «звонки клиентов из WhatsApp → наша АТС через шлюз» (ничего не включено)

- Что изменилось:
  - `ops/whatsapp-gateway/` — шлюз: Asterisk 22 из пакетов Debian (sid, прибит к снимку архива 15.11.2026 и
    точной версии), отдельный `docker-compose.yml` в сети хоста (иначе docker обходит ufw), TLS 5061 с
    сертификатом Let's Encrypt, конечная точка Meta по примеру Meta для Asterisk (SDES, `rewrite_contact=no`,
    без таймеров сессии, опознание по `X-FB-External-Domain`, digest-пароль Meta из файла), плечо к станции
    SIP/UDP по VPN 10.9.0.1 → 10.9.0.2:5062, только a-law. Номер звонящего: только цифры, `+992…` → 9 цифр
    (как от городского транка), BSUID не пропускается. Режим `early`: шлюз сразу снимает трубку у WhatsApp и
    играет гудки, пока станция ищет человека (Meta ждёт ~30–60 с, станция агенту звонит до 150 с).
  - Скрипты `bin/` (все с `set -euo pipefail` и `--dry-run`): установка, сертификат (DNS-01 Cloudflare,
    продление с перезапуском только без звонков), файрвол по сетям Meta (whois AS32934, свёртка, сверка с
    адресами из документации, три попытки whois), пароль SIP Meta сразу в файл 600, включение/выключение
    звонков со скрытой кнопкой, проверка готовности (`can_receive_call_sip`) с тревогой только при смене
    состояния, расписание, одно проверочное сообщение с кнопкой звонка владельцу. Все запросы к Meta — одна
    дверь `graph-call.mjs` внутри контейнера CRM: ключ берёт загрузчик CRM, наружу он не выходит, пароль в
    выводе настроек скрыт.
  - `ops/asterisk/pjsip.endpoint_custom_post.conf` (станция: конечная точка `whatsapp-gw` на существующем
    транспорте 5062, только с 10.9.0.1) и блок `[from-trunk-whatsapp]` в `ops/asterisk/extensions_custom.conf`
    (имя с `from-trunk` — иначе CRM не видит звонок; дальше `Goto(ext-did,6501414,1)`, как звонок на
    городской номер; метки `RH_SOURCE=whatsapp`, `RH_WA_CALL_ID`).
  - `docs/whatsapp-calling-runbook.md` — 14 операций с точными названиями для «да», копиями, откатом,
    проверкой; что владелец делает сам; ночь и «незнакомый → офисный телефон»; что не хватает CRM.

  публичным сертификатом — АТС за файрволом с самоподписанным так не умеет (разведка
  `D:/TASKS-2026-11-14/reports/whatsapp-calling-2026-11-18.md`).
