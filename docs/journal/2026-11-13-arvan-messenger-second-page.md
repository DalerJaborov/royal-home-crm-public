# 13.11.2026 — Messenger второй Страницы (Arvan estate) и её реклама в расходах

**Что изменилось**
- Настройки → Каналы → «Вечные ключи»: блок «Страницы Facebook ключа компании».
  Список Страниц, выданных системному пользователю royalhome-crm (`GET /settings/meta-eternal/pages`),
  кнопка «Подключить Messenger» (`POST /settings/meta-eternal/pages/:pageId/connect`, с подтверждением входа):
  маркер Страницы берёт сервер у ключа компании (не истекает), заводит MessengerAccount канала FACEBOOK
  без «по умолчанию», копирует имя бренда и промт у Instagram той же Страницы и сразу подписывает
  Страницу на messages + messaging_postbacks (feed не снимается).
- `resolveIncomingAccount`: пока в канале FACEBOOK/WHATSAPP нет строки «по умолчанию», а Settings настроены,
  входящее БЕЗ получателя (старые диалоги с accountId = null, фоновые отправки) идёт маркером из Settings.
  Без этого первая же строка Arvan забрала бы диалоги Royal.home.tj. Незнакомому получателю маркер Settings
  по-прежнему не отдаётся.
- Проверка здоровья маркера Страницы смотрит основную Страницу из Settings, а не вторую.
- Расходы рекламы: «свои» объявления узнаются по любой нашей Странице (Settings + FACEBOOK-аккаунты +
  Страницы наших Instagram), а не только по основной — иначе реклама со Страницы Arvan пряталась бы как чужая.
- Самопроверка «Вечные ключи» не прячет основную Страницу, когда подключена вторая.

**Почему**: просьба владельца 13.11 — бот должен отвечать в Messenger Arvan, расходы кабинета Arvan — в CRM как у всех.
Замер на проде (только чтение): Страница Arvan выдана ключу компании с задачей MESSAGING, но не подписана на
наше приложение (subscribed_apps пуст) — поэтому сообщение директора не дошло. Кабинета Arvan не видят ни
личный ключ рекламы, ни системный пользователь — его надо выдать (клики владельца).

**Проверено**: сборка shared/api/web; тесты `facebook-second-page`, `meta-eternal-tokens`, `messenger-accounts`,
`messenger-settings-accounts`, `ad-spend-matching`, `disabled-account-initiative`, `stuck-conversations`,
`comment-author-settings-page-scope`.

**Осталось**: выкат (ship, «да» владельца); кнопка «Подключить Messenger» на проде; живое сообщение в Messenger
Arvan с профиля БЕЗ роли в приложении Meta; номер кабинета Arvan в Настройки → Реклама после выдачи доступа.
