# Сообщения участников рабочей группы

Для группы с уже включённой памятью появился отдельный переключатель хранения сообщений участников без привязки к CRM. Он выключен по умолчанию и задаётся для конкретной группы. Текст и подписи сохраняются до семи дней с маской контактов. Для вложений сохраняется их тип, а расшифровка по-прежнему требует успешно обработанного голосового от сотрудника. Поиск истории требует привязки и ограничен исходной группой и темой. После выключения записи участников без привязки сразу скрываются и удаляются фоновым заданием.
