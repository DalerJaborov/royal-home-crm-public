# 2026-11-18. Пропущенный входящий звонок не теряется

## Что изменилось
- Рубильник А (`Settings.missedCallSmsEnabled`, по умолчанию ВЫКЛ): неотвеченному звонившему СРАЗУ уходит одна СМС
  на двух языках (таджикский, потом русский) со ссылкой `https://wa.me/992777776001`. Любой неотвеченный входящий, <!-- secret-scan: allow номер WhatsApp компании, не клиента -->
  в любое время суток, в том числе клиент с закреплённым агентом (задача и пуш агенту прежние).
  Код: `lib/telephony/missedCallFollowup.ts::sendMissedCallSms`, вызов в конце `finishIncomingCall` (`void`, не тормозит звонок).
  Отправка через единственную дверь `sendSms` (Payom), причина `MISSED_CALL_WA`, имя отправителя подставляет `payomSend` из `Settings.smsSender`.
- Защиты: не чаще одной СМС на номер за 24 часа (отказ провайдера тоже считается, повтора нет); только мобильный таджикский
  номер (общее правило `isTajikMobileNumber`/`tajikNationalNumber` в `packages/shared/src/tajikPhone.ts`, `toSmsPhone` теперь строится на нём);
  не сотрудник, не номер компании (публичный, WhatsApp компании, `incomingForwardPhone`, номер из ссылки wa.me в тексте), не служебный номер
  (дважды «не по делу»); не писавшему нам в WhatsApp за 24 часа; потолок 100 СМС за сутки против волны автообзвона.
- Рубильник Б (`Settings.missedCallCallbackTaskEnabled`, по умолчанию ВЫКЛ): пропущенный с незнакомого набираемого номера заводит
  карточку (`createCardForUnknownCaller`, та же, что у робота) и дальше работает прежний механизм: общая задача `inbound_missed_callback`
  (`claimAutoTaskSlot`: одна на номер), пуш руководству `notifyMissed`. Закрывается: дозвонился (`closeAutoTasks`), перезвонили
  (`callTracker`), написал в WhatsApp (новый проход `closeMissedCallTasksAnsweredInWhatsapp`, крон `missed-call-task-whatsapp-close`, раз в 2 минуты).
- Починен класс: повторный пропущенный звонок СНИМАЛ уже открытую задачу «перезвонить» (`closeStaleNextActions` исключал только новую запись,
  а `claimAutoTaskSlot` оставлял задачу на старой). Теперь исключаются обе. Касалось и клиентов с агентом.
- Настройки: «Каналы связи», раздел «Входящие», блок внизу (`pages/settings/MissedCallSetting.tsx`): два тумблера и текст СМС. Один экран для ПК и телефона.
- Реестр функций: `missed-call-sms` («включено, отправлено N за 7 дней») и `missed-call-callback-task`.
- Миграция `20261118150000_missed_call_followup`: три колонки Settings с умолчаниями, поведение прода не меняется.
