# 31.10.2026 — помощник CRM: поток токенов (П1, задача 1.6)

Источник: `docs/design/internal-assistant-architecture-2026-10-31.md`, таблица П1, строка 1.6;
интерфейс событий SSE — там же (`token {text}`).

## Что изменилось

- `apps/api/src/ai/geminiStream.ts` (новый) — разбор потока без сети: сборщик SSE
  (`data:`-строки, куски режутся где угодно, CRLF, многострочный `data`) и копилка
  ответа (текстовые дельты наружу, части реплики — в том виде и порядке, как пришли).
- `apps/api/src/ai/geminiClient.ts`:
  - `callGeminiToolsStream` — `:streamGenerateContent?alt=sse`, дельты текста через
    `onToken(delta)`, вызовы инструментов отдаются только после конца потока, результат —
    тот же `GeminiToolTurn`, что у `callGeminiTools`;
  - политика повторов ОДНА: `callGeminiToolsWithRetries` получил параметр «одна попытка»,
    поток идёт через него же (ключ, модели, резервная, предохранитель, паузы, `deadlineAt`,
    `signal`);
  - сбой ДО первого токена — обычный сбой попытки (повтор/резервная); ПОСЛЕ — новый
    `GeminiStreamInterruptedError` (`code: "stream_interrupted"`, `retryable: true`), без повтора;
  - поток, кончившийся без `finishReason`, — обрыв: вызовы из него не исполняются;
  - отмена (срок попытки/диалога, уход клиента) отменяет и ЧТЕНИЕ тела (`reader.cancel`);
  - тело запроса, разбор HTTP-отказа, сборка вызовов и записи «пустой ответ»/«резервная
    модель» вынесены в общие функции (`toolsRequestBody`, `toolsHttpError`, `toolCallsOf`,
    `reportToolTurnOddities`) — обычный и потоковый вызов не держат две копии.
- `geminiTransport.ts` — `geminiStreamUrlFor(model)`.
- `ai/assistant.ts` — `RunAssistantOptions.onToken?(event)`: передан — раунды идут потоком,
  нет — прежний `callGeminiTools`. Первая дельта нового раунда после уже показанного текста
  идёт с `reset: true`. Код отказа `stream_interrupted` в `ASSISTANT_ERROR_MESSAGES`.
  Учёт `AiLog` не тронут (тот же `finally`).
- `routes/ai.ts` — `onToken` → SSE `token`; `done` по-прежнему несёт полный текст.
- `packages/shared/src/assistantCard.ts` — тип `AssistantTokenEvent {text, reset?}`.
- `apps/web/src/lib/assistantStream.ts` — событие `token`: накопление, `reset`, колбэк
  `onToken(textSoFar)`; итог — текст из `done` (если `done` пуст, а токены были — накопленное).

## Почему так

- Факты о формате: [док] ai.google.dev/api/generate-content — тело ответа поток
  `GenerateContentResponse`, примеры с `alt=sse`. [вывод] каждое событие — целый ответ с
  дельтой текста; `finishReason`/`usageMetadata` берутся последние увиденные; подписи
  размышлений возвращаются в историю как пришли (поэтому части не склеиваются).
  [не проверено] на живом Gemini (лимит владельца) и через прокси `GEMINI_PROXY_URL`.
- Если прокси потеряет строку запроса, Google отдаст поток JSON-массивом — разбор понимает
  и его (ответ придёт целиком в конце, но правильный).
- Части-размышления (`thought: true`) человеку не показываются и в текст не идут.
- Проверка в `failureOf` — по `code`, а не `instanceof`: узкие подмены `geminiClient` в
  тестах (`ai-assistant-tools`, `grounded-search`) класса не отдают.

## Чем проверено

- `apps/api/tests/ai-assistant-stream.test.ts` — 11 тестов: куски по 7 байт (посреди JSON
  и посреди кириллической буквы), вызовы инструментов в разных событиях + подписи,
  поток без finishReason, 404 → резервная модель, обрыв до токена → повтор, обрыв после
  токена → `stream_interrupted`/retryable без повтора, отмена по `signal` останавливает
  чтение, `runAssistantDetailed` с `onToken`, без `onToken` — прежний `generateContent`,
  маршрут: `token` до `done`, `done` с полным текстом.
- Сторож проверен поломкой: убран проброс `GeminiStreamInterruptedError`, отмена чтения и
  потоковый `TextDecoder` — 6 из 11 тестов красные; после возврата — 11/11.
- `assistantStream.test.ts` (фронт) — +3 теста: накопление/`reset`/итог из `done`; без
  токенов — из `done`; токены без `done` — обрыв.
- Сборка shared/api/web, `npm run test:web`, смежные `ai-assistant-*`, `gemini-tools-fallback`.

## Что осталось

- Панель (`AssistantPanel.tsx`, `HomeAsk.tsx`) `onToken` пока не передаёт — текст по-прежнему
  появляется по `done`. Показ черновика — задача 4.1 (П4) или отдельная правка интерфейса.
- Живая проверка на реальном Gemini и через прокси-Worker: что он не буферизует поток и
  не теряет `?alt=sse`.
- Маршрут теперь всегда идёт потоком; откат — убрать `onToken` в `routes/ai.ts`.
