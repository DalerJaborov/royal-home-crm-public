# 22.11.2026 — живые слова озвучки за рубильником (выкат без утверждённых текстов)

## Что изменилось
- Новый рубильник `liveWords` в настройках озвучки (Настройки → Озвучка → «Как работает»), по умолчанию ВЫКЛЮЧЕН (нет поля = выкл).
  Выключен: `{объект}`, `{сколько_комнат}`, `{метраж}` пустые, `{сотки}` у дома пусто, половина сотки у участка — метрами;
  то есть озвучка ровно как до PR #363. Включён: слова работают.
- Одно место: `renderNarrationTemplate(template, facts, live)` и `narrationDraftText(config, …)` (читает `config.liveWords`).
  Мастер CRM и карточка берут флаг из `narration-options` / `config` и собирают текст тем же правилом (`resolveNarrationDraft`, `NarrationComposer`);
  проверка шаблона при сохранении тоже идёт с текущим положением рубильника.
- Тексты по-прежнему лежат в `prisma/pending-data` (Prisma их не применяет). Когда файл переедет в `prisma/migrations`, он сам включит
  `liveWords` вместе с заменой текстов: иначе новые тексты зазвучали бы без слов.
- Свод с main (#376: этажность дома не говорим): `{этажность}`, `{этажность_род}`, `{этажей}` всегда пустые, сторож Настроек не принимает их в новых
  текстах; функцию `narrationStoreysWords` убрали. Скобки «[… {этажность}]» в текстах выпадают сами. Тексты не менялись: список фрагментов
  с этажностью — в `2026-11-22-narration-templates-teksty.md`, их стоит убрать при утверждении.

## Почему
Код нужно выкатывать отдельно от текстов (ждут «да» владельца), и при этом озвучка не должна измениться: PR менял `{сотки}` (дом, половина сотки) и список слов.

## Чем проверено
`narration-templates-live-21-11` (в т.ч. «рубильник выкл — как раньше», этажность не звучит, миграция включает рубильник) и `narration-templates-by-type` против базы стенда.

## Что осталось
«Да» владельца на тексты → перенос файла в `prisma/migrations/<метка>_narration_templates_live/` → ship. Живой звук и носитель таджикского не проверены.
