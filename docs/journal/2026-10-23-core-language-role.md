# 23.10.2026 — Клиентский агент: язык диалога и роль клиента (F04, F05)

- Что изменилось:
  - Язык: `detectClientLanguage` вырезает ссылки, e-mail, @ники и телефоны до подсчёта слов (голая ссылка на рилс считалась таджикской, со «/to/» — английской); словарь таджикского пополнен разговорными формами («намефамум», «маош», «кор», «нарх/нархаш», «асалом», «чанпул», «ака/апа», «хуб», «мешид», «мегрифти» и др.); три буквы с однозначно таджикским словом («Кор») больше не «unknown». Новая `resolveCustomerDmLanguage` (customerDmLanguage.ts) заменила прежнюю логику в `customerDmAgentTurn.ts`: явная просьба («я не понимаю русский», «уруси намефамум») побеждает; короткая нейтральная реплика (≤2 слов: привет, спасибо, ок/да/нет, «Рахмат», голая ссылка, @ник) язык диалога не переключает, если есть история; `mixed` без истории решается по большинству слов, а не «по умолчанию русский».
  - Роль: один разбор вместо двух расходящихся регулярок — `ai/customerAgentRole.ts` (нормализация ӯ/у, ҳ/х, ҷ/ч, ӣ/и, қ/к, ғ/г, знаки между словами; границы слов через BW/EW; отрицание «не/намехоҳам» перед каждым совпадением). Его используют `customerAgentIntake` и `customerRecruitmentTopic`. Работа читается раньше покупки и продажи. Продажа: продам/продаю/продаётся, фурӯш-формы, «дорам/доштам» рядом с «хона/ҳавлӣ/квартира/дом/участок». Аренда «сдам/сдать/ба иҷора медиҳам» — в схеме нет роли арендодателя (intake: buyer/seller/unknown; topic: buyer/seller/job/rent), поэтому это seller, а слово «аренда/сдать» сохраняется в `statements` (дословные слова клиента). «Продаются ли / есть ли в продаже» — покупатель. `selectedRecruitmentPosition`: целые слова с окончанием (до +3 букв), минимум 4 символа (кроме SMM), общие слова («работа», «специалист», «вакансия», «кор») вакансию не выбирают, «агентство» не выбирает «агент».
- Почему: пробы 23.10 на origin/main — «Ма уруси намефамум», «Продам квартиру», «Мо хонаи фуруши дорем», «Хочу сдать квартиру» давали unknown; «Продаются квартиры у вас?», «Ман кор меҷӯям», «Ищу домработницу», «Осман мефурӯшад» давали ложную роль; ссылка/«Спасибо»/«Рахмат» переключали язык диалога.
