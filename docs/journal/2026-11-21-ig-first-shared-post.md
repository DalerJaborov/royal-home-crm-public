# 21.11.2026 — Бот: пересланный пост первым сообщением больше не остаётся без ответа

- Симптом (прод, Instagram, 17:55 по Душанбе): новый клиент первым и единственным сообщением переслал публикацию без слов.
  Пауз нет, ошибок нет, через 30 минут ни бот, ни агент не ответили.
- Причина (ФАКТ, чтение прода): билет хода `HELD` с причиной `lead_only_operator_silent` — оператор приёма заявок решил
  молчать. В `ai/operator/decide.ts` пост без слов с признаком «чужой» — тишина сразу. Признак ядро ставило по КАНДИДАТУ
  (`customerForeignShareCandidate`: вложение — пересылка, объект не найден), а не по приговору сервера
  `customerForeignShareSettled` (поиск «такого нет», ссылка CDN Meta, подпись не о жилье и не о нас). Сервер чужим шумом
  этот пост не признал: фильтр спама включён, карточки нет, а отметки спама в разговоре нет (иначе причина была бы
  `spam_filtered_no_reply`). Какое условие не выполнилось (ФАКТ, чтение прода: расшифровка входа в контейнере, наружу — только
  да/нет): подпись пересланного поста (714 знаков) говорит о жилье (`customerSpamInterest` = да); вложение одно, `share`,
  ссылка CDN Meta (`lookaside.fbsbx.com`), слов нет, объект не найден. То есть это не «поиск ещё шёл»: подпись от времени
  не зависит, приговора «чужой шум» нет ни в начале хода, ни у оператора — правка закрывает именно этот случай. Решение владельца 21.11 «спамерам не отвечать» тем самым глушило и посты, которые сервер
  чужими не считал, включая первое сообщение нового клиента.
- Что изменилось:
  - ядро передаёт оператору второй признак `foreignQuiet` — приговор `customerForeignShareSettled` по фокусу после уточнений
    хода (`lib/customerDmAgentTurn.ts`); оператор молчит на пост без слов только по нему (`ai/operator/decide.ts`);
  - пересланный пост без приговора, бот в разговоре ещё ничего не спрашивал, заявки нет — один вопрос «купить или продать?»
    (существующая фраза `ask_role`, язык неизвестен — таджикский, SPEC случай 20), без «Спасибо, получил» и без просьбы
    номера. Повтор подряд — тишина без сигнала, как было;
  - доказанный чужой шум — тишина и на первый пост, как было (в проде его и так раньше останавливает фильтр спама);
  - `docs/bot-operator/SPEC.md` п. 5 и раздел «Вложения» дописаны;
  - гонка (слепое ревью): счётчик вопроса о роли сверялся только с ДОСТАВЛЕННЫМИ ответами (память ядра берёт ACCEPTED);
    второй пост через секунду, пока вопрос на первый в очереди, сбрасывал счётчик в 0 — вопрос ушёл бы дважды. Сверка
    (`ai/operator/index.ts::reconcileAskedRole`) теперь берёт большее из памяти и отправленного/стоящего в очереди
    (`readCustomerLeadOnlySentTexts`: READY, IN_FLIGHT, ACCEPTED; вытесненное и отменённое не считается — ea3fecb5 закрыт).
- Тот же механизм в других каналах: ход ядра один (`runCustomerDmAgentTurn`). В Instagram пересылка поста — проверено на
  проде. В WhatsApp пересылок публикаций нет (признак-кандидат требует пересылку). Facebook (ОЦЕНКА): пересылка поста
  Страницы тоже идёт как `share` по ссылке CDN Meta, значит, тот же путь — живьём не проверено. Старый путь
  (`messengers/conversation.ts::runLeadOnlyOperator`) признака «чужой» не передаёт вовсе — его не касалось.
- Проверено: `tests/bot-first-shared-post-21-11.test.ts` (решение оператора), `tests/bot-operator-core-postgres.test.ts`
  (два новых сценария на настоящем пути ядра: пересланный пост с подписью о жилье — вопрос о роли; доказанный чужой шум при
  выключенном фильтре спама — тишина), обновлены `bot-operator-decide` (случай 20) и `bot-live-dialogs-21-11`. Без правки
  в `decide.ts` новые тесты красные (4 падения), с отключённой передачей `foreignQuiet` в ядре — красный сценарий «чужой шум»,
  со старой сверкой счётчика — красный сценарий гонки (второй пост, пока вопрос в очереди, получал второй вопрос).
- Что осталось: клиенту с прода (диалог 21.11, 17:55) ответ сам не уйдёт — ход уже завершён; ответить руками из переписки.
  За трое суток таких «первых» пересланных постов без ответа — один этот (выборка по билетам `lead_only_operator_silent`).
  Со словами клиента фраза «Это не наше объявление» по-прежнему звучит по кандидату, а не по приговору — отдельный вопрос.
