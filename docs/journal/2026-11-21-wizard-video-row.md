# 2026-11-21 — мастер объекта: строка видео не рвётся по буквам

**Что.** iPhone владельца: в блоке «Видео» мастера имя «IMG_1210.MOV» и «109.4 МБ · Готово» стояли столбиком по букве —
чип «Исходник монтажёру» и «Убрать» не сжимались и съедали строку. Теперь имя — одна строка с многоточием в основе и
видимым расширением («IMG_12…» + «.MOV»), размер и состояние строкой ниже, чип и кнопки (`.act`) целиком уходят на вторую
строку, не сжимая имя. Правка: `StepMedia.tsx` (`VideoRow`, `splitFileName`), `theme-2026-brand.css` (не генерируемый файл).

**Сторож.** `helpers/lookGeometry.ts` — новый вид `letterColumn` (слово 5–24 знака на 3+ строках в любом блоке; прежний
`wordBreak` смотрел только кнопки и вкладки). `squeeze` и `overlap` на старом коде строку тоже ловили. Тест в
`new-look-wizard.spec.ts` («строка видео…»): 320/360/390/430/768/1440, плюс нарочная поломка — сторож обязан её увидеть.
Проверено поломкой: на старом коде тест красный (squeeze, letterColumn «столбиком на 12 строках»).

**Класс.** `.vrow` ещё в окне загрузки (`SaveProgressOverlay`): там нет кнопок рядом с именем, имя переносится
(`overflow-wrap: anywhere`) — не сжимается. Фото в мастере — плитки без имён. Не проверено живьём: строка видео в карточке
объекта (`PropertyVideoManager`, `.row` + `.act` из трёх ссылок) — по коду похожий механизм, нужен объект с видео на стенде.

**Осталось.** Проверить карточку объекта с видео на 320–430; `letterColumn` теперь в GEOMETRY_KINDS — полный прогон
`@geometry-full` может показать другие места с тем же классом.
