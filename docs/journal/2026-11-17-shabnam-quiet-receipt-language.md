# 17.11.2026 — Шабнам: «помолчи» словами модели, подпись к файлу, язык, правила компании, быстрый путь на таджикском

Класс ошибки (аудит «слова решают вместо модели»): список слов решает, а модель обещает без инструмента. Схема лечения как в #170 (`[голос]`): модель ставит аргумент инструмента, код проверяет, регулярка остаётся быстрым путём.

## Что изменилось
1. **«Помолчи»** (`telegram/assistantGroupParticipation.ts`, `ai/assistant/tools/groupQuietTool.ts`, `telegram/assistantBot.ts`). Быстрая регулярка шире: вежливая приставка/суффикс, «хватит (писать/отвечать)», «не пиши сюда», «замолчи», «хомуш/хомўш бош|шав|кун», «ҷавоб надеҳ», «можешь писать». Остальные обороты — инструмент `set_group_quiet(minutes)`: пишет то же поле `AssistantTelegramGroup.proactiveMutedUntil` той же регистрации группы (0 — снова отвечать). Объявляется только на прямое обращение в группе (`actor.groupChat`; не пересылка, не автоответ, не личка). Промт группы: «без вызова не говори "молчу"».
2. **Подпись к фото/файлу** (`telegram/assistantBot.ts::handleAssistantPrivate`, `telegram/assistantAttachedRequest.ts`). Подпись не из списка «чек/расход…» раньше терялась: человеку возвращали только распознанный текст. Теперь подпись идёт обычным ходом помощницы, текст файла приложен недоверенным документом (`wrapUntrusted("document")`). Пересланное с подписью и ошибки разбора — по-прежнему только распознанный текст.
3. **Язык** (`ai/assistant/languageRouting.ts`). Просьбы по-таджикски («Бо русӣ нависед», «Ба забони тоҷикӣ ҷавоб деҳ», «Тоҷикӣ гап зан»), «не понимаю по-русски» (общий разбор клиентского бота). Просьба живёт, пока сотрудник не попросит иначе, в пределах 6 его последних сообщений (раньше — один ход).
4. **Правила компании** (`ai/assistant/knowledge.ts`, промт `ai/assistant.ts`). Тема пилота распознана, но утверждённой ревизии нет — теперь обычный поиск по словам (как у инструмента), а не пустой ответ. В промте: вопрос о правилах — через `search_company_knowledge`, записи нет — так и сказать. Версия промта `2026-11-17.2-company-rules-quiet`.
5. **Быстрый путь по языку** (`ai/assistantFastPath.ts`, вызовы в `telegram/assistantBot.ts`, `routes/ai.ts`). Язык разговора (`assistantLanguage`) вместо жёсткого «ru»: карточка объекта, клиент, «не нашла», выбор из нескольких, справка Корзины.

## Решения и риски
- `set_group_quiet` уровня A сознательно: запись безопасная и сама истекает (до 8 часов), «подтвердить» в группе нечем, как и у регулярки.
- Пункт 4: прежнее «не подменять непроверенной ревизией» заменено меткой: `knowledgeContext` подписывает каждую запись названием, источником и версией.
- Пункт 3: «6 сообщений» — предел памяти просьбы; без предела старая просьба держала бы длинный разговор.
