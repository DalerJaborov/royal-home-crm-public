# 23.11.2026 — «Написать» в карточке клиента открывает обычный чат

Владелец: на телефоне в карточке клиента (ПК-000986) «Написать» открывала шторку-пузырь «Переписка»
(сообщения с «Верно/Неверно», мелкое поле ввода), а не обычный раздел «Чаты».

## Причина
`ClientDetail.tsx` держал две дороги: `MobileClientCard` уже вёл в `/messages?open=client:<id>`, а вторая
полоса кнопок (`cd-act`, ПК-кнопка `pill ghost`, карточка «Переписка», «Ждёт варианты», сигнал
`location.state.openChat`) звали шторку `ClientChatPanel` через `setChat`.

## Сделано
- Все пути «написать клиенту» идут через `openClientChat(clientId)` = переход на `inboxClientConversationHref`
  (общая переписка клиента, переключение канала внутри). Шторка и состояние `chat` из карточки убраны;
  опрос карточки по `pollConversations` больше не нужен.
- «Верно/Неверно» (`BotReplyFeedback`) в настоящем чате уже есть (Messages.tsx, MobileChatView; в новом виде — в «Сведениях о сообщении»), не потеряно.
- Чат: можно выбрать сразу НЕСКОЛЬКО фото/видео (`planOutgoingMediaPick`) — пачка уходит без превью-шага;
  один файл — как раньше (превью + подпись). Правка в `Messages.tsx` и `MobileChatView.tsx` вместе.
- Тесты: `lib/__tests__/writeOpensRealChat.test.ts`.

## Уже работало (не трогал)
Отправка объекта из чата (значок-здание / «Объект из базы» → панель «Подбор», фото+видео+подпись уходят
сервером), фото/видео с прогрессом и частями, голос, быстрые ответы.

## Не сделано / открыто
- Документы (PDF и т.п.): сервер доставляет в чат только фото/видео, файлы потребуют отдельной серии (API + WhatsApp/Telegram).
- Клиент без переписки: кнопка по-прежнему неактивна, первое сообщение — блоком «Написать в WhatsApp первыми» в карточке.
- Компонент `ClientChatPanel` остался в репозитории (на него опираются тесты и `ClientChatCard`), из экрана не вызывается.
