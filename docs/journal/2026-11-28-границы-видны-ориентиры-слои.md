# 28.11.2026 — Границы и кнопки видны; справочник ориентиров по слоям

Владелец: «в настройках бардак, в левом меню не видны границы и кнопки, в артефакте было ровно» и «всё ли работает с ориентирами, почему не база данных просто?».

## A. Границы
- **Причина класса (замер):** рамки карточек, кнопок и полей берут `--rh-ui-ring` (.06) и `--rh-ui-sep` (.08) через `--line-strong`/`--line` в файлах разделов (`theme-look-royal-*.css`). Это 1,1:1 к фону, а «сильная» линия (ring) была слабее обычной (sep). Серые кнопки `.pill.ghost` в «Сотрудниках» к тому же были залиты `--rh-ui-press` без рамки.
- **Исправлено в источнике** (`theme-look-royal.css`, генерируемые файлы не тронуты): sep .13, ring .22 (свет и ночь); рамка полей настроек — `--rh-ui-field-line` (≥ 3:1); у «Ещё» в левом меню кольцо, у пункта — подсветка при наведении; ghost-кнопки «Сотрудников и прав» (`theme-look-royal-team.css`) — карточный фон + кольцо.
- **Сторож:** `apps/web/src/royalBorderContrast.test.ts` — меряет контраст токенов обеих тем (рамка ≥ 1,5:1, ring сильнее sep, поле ≥ 3:1).

## B. Ориентиры
- Это и есть база данных: таблица `Landmark` (`source` «import» — купленный слой ~857, «agent» — заведено сотрудниками; `enabled` — скрытие, купленное удалять нельзя, иначе импорт воскресит; синонимы — `GeoAlias`). Используют: `geoResolve` (бот и подбор понимают место из слов клиента), `folkPlaces`, `propertyMatch`, карта объектов, мастер объекта, помощница.
- Экран стал: вкладки «Наши · N» (по умолчанию) и «Купленный слой · M»; в купленном — «Скрыть мусор (k)» и «Объединить дубли (e)» с подтверждением (право `landmarks.manage`), всё только скрытием; поле синонима свёрнуто за кнопкой «+ синоним».
- API: `layer=own|import` в `GET /landmarks` (без параметра — все, мастер объекта не ломается); `GET /landmarks/summary`; `POST /landmarks/cleanup {mode}`. Правила — `lib/landmarkCleanup.ts` (мусор: < 3 букв; дубли: то же имя с теми же цифрами, не «общее слово», ≤ 700 м; не трогаем записи с упоминаниями клиентов, синонимами, центры города, записи сотрудников; синонимы дублей переезжают на оставленную).
- Тесты: `apps/api/tests/landmark-cleanup.test.ts` (правила, без базы), `landmark-layers.test.ts` (слои, summary, права).
- Не сделано: автоматическая чистка при импорте (`import-geo.ts`) — только по кнопке; страница по 30 («Показать ещё») осталась прежней.
