# 08.11.2026 — Шабнам, пачка 2: второе ревью

Ветка `feat/shabnam-batch2-07-11`, третий коммит поверх `64c3da88`.

- Что изменилось:
  - **Кэш повторов хода** (`ai/assistant.ts`): ответ с `{error}` не кэшируется (временный сбой не
    становится ответом на повтор); после исполненной записи (create_task, reschedule_task, запись
    уровня B) чтения из кэша стираются — «список → создать задачу → список» видит новую задачу.
    Частичный ответ (круг, конец шагов, срыв) называет сделанные записи и ждущие подтверждения
    (`partialAnswer.ts`, пары ru/tg).
  - **Telegram: ход помощницы вне очереди чата.** Выбрано вынести, а не резать группу до 60 с. Долгая
    часть хода идёт в своей очереди на одного человека (`runInAssistantLane`, ключ «чат + человек»):
    порядок ответов одному человеку сохранён, соседи по группе и другие чаты не ждут. Ответ уходит
    наверх как `reply` (`TelegramUpdateAccepted.assistantDeferred`): вебхук его дожидается (дедуп и
    отметка «готово» — как раньше), мягкая остановка ждёт через `trackBackgroundTask`.
    Поллер: апдейт с вынесенным ходом не подтверждается Telegram (offset не уходит за него) и
    отмечается «готово» только после ответа — при перезапуске посреди хода Telegram пришлёт его снова,
    повторный опрос его не обрабатывает второй раз (`assistantInFlight`); пустые повторные опросы —
    с паузой 1 с.
  - **Миграция** `20261107200000` возвращена к прежнему виду; колонки шагов/срока — новая
    `20261108090000_assistant_limits`. Нет колонок (код раньше миграции) — `readAssistantSettings`
    берёт значения по умолчанию и пишет в «Здоровье системы», ответ не падает.
  - **Ложный дом:** `houseAddressCandidate` отсекает до запроса в базу «мкр 91», «Сино 2», «до 600»,
    «3 этаж», «у школы 5»; «квартира у Рудаки 177» → «Рудаки 177».
  - **Удалённые клиенты:** агенту без «Архива» поиск в Корзине по номеру телефона запрещён (в «both» —
    только живые), заметки удалённого клиента скрыты.
  - Мелочи: один разбор ссылки Instagram (`instagramLinkCodes` в `lib/instagramPostLead.ts`) для
    заявки по ссылке, find_property и быстрого пути; сторож каскада видит многострочный `@relation`.
- Почему: второе ревью пачки 2 (блокеров нет) и решение владельца «помощь всегда».
- Чем проверено: `ai-assistant-batch2-review.test.ts` — 27; `assistant-group-natural` (вторая реплика
  группы не ждёт долгий ход, порядок одного человека); поллер в `assistant-telegram.test.ts`
  (offset не уходит за незавершённый ход, повтор не обрабатывается дважды). Сторожа кэша краснеют
  на нарочно сломанном коде.
- Риски / осталось:
  - Вебхук-режим: при перезапуске посреди хода ответ теряется (как и раньше — Telegram получил 200).
    Поллер-режим — восстанавливается.
  - Пока ход одного человека идёт, другие его сообщения в группе (команды модерации и т. п.)
    обрабатываются параллельно — порядок держится только внутри очереди помощницы.
  - `instagramPostCode` по-прежнему требует код от 5 знаков (заявка по ссылке) — намеренно.
