# 21.11.2026 — Плавающие слои, клавиатура, шторки, ленты на телефоне (аудит К06, К07, К08, К20)

- Что изменилось:
  - **К06.** Плашка «Поставьте CRM на экран» больше не висит над нижним меню: это строка в самом экране «Главная»
    (`InstallAppHint`, решение — `lib/installHint.ts`). Показывается один раз на устройстве, с третьего захода, только когда
    установка реально возможна (системный диалог готов либо iPhone-браузер с «На экран „Домой"», не просмотрщик Telegram/Instagram);
    кнопка «Не сейчас» запоминается в настройках. Запас под нижнее меню — одна переменная оболочки `--rh-nav-h` / `--rh-nav-clear`
    (`theme-look-royal.css`); `--ry-nav-clear` в «Клиентах» удалена, панель подбора встала на общую.
  - **К07.** Клавиатура считается в одном месте — `lib/keyboardInset.ts` (`--rh-kb-inset`, `--rh-vv-h`, `data-kb-open` на `<html>`).
    Оболочка (`AppLayout`) подписана всегда на телефоне: при клавиатуре нижнее меню скрыто на любом экране с полем.
    `Rh2Sheet` поднимает подвал над клавиатурой (CSS п. 8 `theme-2026-mobile-shell.css`) и прокручивает поле в фокусе в видимую часть
    (`useRevealFocusedField`). Окно расхода «Деньги» (`.cef-sheet-backdrop`, не из `Rh2Sheet`) поднято тем же отступом.
    В «Проверку экрана» (/ui-check) в пробную шторку добавлено поле — клавиатуру можно проверить на настоящем iPhone.
  - **К08.** У контейнера шторки нет рамки фокуса (у кнопок и полей внутри прежняя). Форма-шторка не ниже 62% экрана (до 520 px),
    подтверждения (`alertdialog`) по содержимому. Из «Назначить показ» и «Записать результат» на карточке клиента убран повтор имени
    клиента (`ClientDetail` не передаёт `selectedClientName`; в `ShowingQuickForm`, где клиента выбирают внутри окна, блок остался).
    Счётчики «Шаг 1 из 2» убраны из «Новой сделки».
  - **К20.** Ряды, которые листаются вбок, гаснут у края и там, где у браузера нет `animation-timeline` (Safari до 26): хук
    `useScrollStripHints` ставит `data-strip-more`, CSS рисует затухание. В список добавлены миниатюры объекта (`ry-gal-thumbs`).
- Почему: аудит владельца 20.11 (`docs/design/oblik-2026-11-17/audit-real-20-11/BUGS.md`, К06–К08, К20), кадры с iPhone.
- Чем проверено: vitest (`keyboardInset`, `keyboardGuard`, `navClearGuard`, `installHint`, `scrollStrip`), `npm run test:web`,
  `audit:look`, e2e WebKit iPhone 13 и chromium 390 (`tests/e2e/look-overlays-keyboard.spec.ts`: три шторки с полем, экран с полем,
  плашка, конец страницы на 320/390/430, рамка фокуса, высота, ленты), кадры до/после в `docs/design/oblik-2026-11-17/overlays-keyboard/`.
- Что осталось:
  - Клавиатура проверена подменой visualViewport (настоящий iPhone Playwright не воспроизводит). Владельцу — открыть /ui-check на iPhone,
    нажать «Открыть пробную шторку», тапнуть в поле: меню должно исчезнуть, «Готово» — встать над клавиатурой.
  - Остальные 80+ шторок `Rh2Sheet` получают поведение автоматически; своё `.cef-sheet-backdrop` — единственная найденная шторка вне `Rh2Sheet`.
  - «Исправить и озвучить» (поле прямо на странице объекта): меню при клавиатуре скрыто глобально, плавающей плашки больше нет;
    проверено общим тестом экрана с полем, а не на самом объекте с озвучкой (в стенде нет такого объекта).
  - Сторожа: `keyboardGuard` (клавиатуру читает только перечисленный набор файлов, своего `bottom:` у шторки быть не должно),
    `navClearGuard` (запас под меню только из `--rh-nav-clear`).

## Правки после ревью #347

- Высота шторки 62% только у форм: `Rh2Sheet` ставит `data-form` при подвале или отправке, правило п. 8.3 требует `[data-form]`; короткие меню остаются по содержимому (сторож в keyboardGuard).
- `readKeyboard`: подъём не обнуляется, если клавиатура признана открытой (`inset: open ? raw : 0`); тест на остаток 56 px.
- `useCleanViewport` берёт «клавиатура открыта» из `readKeyboard`; запасной пересчёт на focusout через 350 мс живёт в `keyboardInset`.
- «Назначить показ» из подбора в чате показывает имя клиента (MatchPanel передаёт `selectedClientName`); `CleanInteractionContext` без мёртвых пропсов; в «Новой сделке» с клиентом поле называется «Другой покупатель».
- Сторож ловит `--rh-kb-inset` и в TSX. `useScrollStripHints`: на изменение DOM пересчитывает только затронутые ряды.
