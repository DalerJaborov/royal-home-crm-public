# 15.11.2026 — Восемь переписок Instagram: бот не пишет «я уже писал выше», считает процент, зовёт агента

Разбор скриншотов владельца (13–15.11) по проду (только чтение). Классы, а не случаи:

- **«Я уже писал выше / повторяю ещё раз».** Прод 08–15.11: 30 таких ответов в 19 переписках, все из рендера ядра
  (`avoidRepeatedReply`). Старые строки выведены из обращения (`RETIRED_*`, остаются только для памяти старых чатов).
  Повтор теперь: ответ на новый вопрос — как есть; то же самое ещё раз — «Конечно.»/«Албатта.» один раз; иначе продавцу —
  вопрос анкеты, остальным — «Инро аниқ агенти мо мегӯяд» + просьба номера (одна дверь `ai/customerAgentStaffFollowUp.ts`).
- **«Спасибо».** Голое «рахмат/спасибо» → «Марҳамат! Саломат бошед!» / «Пожалуйста! Всего доброго.» (tajik-phrasebook).
- **Зона работы.** 13 раз за неделю «Дар шаҳрҳои дигар кор намекунем» ушло продавцам из Душанбе («Хона дар Душанбе аст»).
  Теперь строка зоны — один раз за разговор; «другие города» — только если клиент назвал место вне города (тогда короткое
  «Мутаассифона, мо танҳо дар Душанбе кор мекунем.» без анкеты) или спросил про города. В `coverageGuard` добавлен Қайроққум.
  Рудаки по-прежнему за моделью (и район, и проспект).
- **Процент от суммы.** «2% от 700 000 сколько?» — считает сервер (`customerCommissionAmountLine`): процент продавца из
  закреплённых условий, если их прочитали, иначе — число клиента. Покупателю сумма не считается (для него 0%).
- **Машина в зачёт / обмен** — не ответ про скидку: факты остаются, вопрос анкеты заменяется передачей агенту.
- **Предложение сотрудничества** — «Спасибо, передам руководству» + номер.
- **Пустой поиск** — честная строка и передача агенту вместо «Бюджет?».
- **«Это скажет агент» — правда только если человек узнал.** После такого ответа ход зовёт
  `notifyStaffFollowUpCustomerTurn` (та же дверь `pushStaffAboutChat`, раз в 6 ч на чат). Звонок обещается только при
  известном номере; без номера — просьба номера.
- **Два ответа на одно сообщение** (старый путь, клиент с карточкой): окно склейки текста 0 → 6 с (`ACCEPTED_TEXT_DELAY_MS`).
  Прод: 2 переписки за неделю, промежутки 3,5 и 5 с. Уступка решению 19.08 «принятой заявке — сразу»: +6 с к ответу.

Промпт ядра не менялся: смена промпта требует ручного «Обновить версию бота»; правки только в коде рендера (рендер-хеш,
автообновление). Новый файл добавлен в группу `rendererHash`.

Тесты: `tests/customer-bot-8-chats-15-11.test.ts` (40 проверок: класс-сторож «ни одна живая фиксированная строка не говорит
"выше/повтор"», батарея повторов, спасибо, арифметика, обмен, сотрудничество, зона, пустой поиск, окно склейки);
обновлены ожидания в 5 соседних тестах (старые «уже писал выше» → передача агенту).
