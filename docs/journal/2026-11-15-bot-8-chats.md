# 15.11.2026 — Восемь переписок Instagram: бот не пишет «я уже писал выше», считает комиссию продавца, зовёт агента по делу

Разбор скриншотов владельца (13–15.11) по проду (только чтение) и правки по независимому ревью #201
(`D:/TASKS-2026-11-14/reports/review-201-2026-11-15.md`). Классы, а не случаи:

- **«Я уже писал выше / повторяю ещё раз».** Прод 08–15.11: 30 ответов в 19 переписках, все из рендера ядра. Старые строки
  выведены (`RETIRED_*`, остаются только для памяти старых чатов). Теперь: ответ на новый вопрос — как есть; то же самое
  ещё раз — «Конечно.»/«Бале.» один раз; третий раз на настоящий вопрос — передача агенту. Если клиент НИЧЕГО не спросил
  («фаҳмидам», «Душанбе», фото ещё раз) — следующий вопрос анкеты (продавцу или покупателю) или короткое «Понял.»/«Фаҳмидам.»,
  без передачи и без пуша (ревью С1).
- **«Спасибо».** Голое «рахмат/спасибо» → «Марҳамат! Саломат бошед!» / «Пожалуйста! Всего доброго.».
- **Зона работы.** 13 раз за неделю «Дар шаҳрҳои дигар кор намекунем» ушло продавцам из Душанбе. Строка зоны — один раз;
  «Мутаассифона, мо танҳо дар Душанбе кор мекунем.» — только продавцу, чей объект назван вне зоны («дар Қайроққум»),
  и только если клиент нигде не назвал Душанбе. Покупатель из другого города («аз Хуҷанд, хона мехарам») — наш клиент,
  не отказ (ревью В2). **Район Рудаки — в зоне** (владелец 15.11 дословно: «Да, Рудаки берём»): в `coverageGuard`
  (DUSHANBE) и в правиле продавца старого бота (`leadQualifier.ts`). Добавлен Қайроққум.
- **Комиссия от суммы.** Только комиссия ПРОДАВЦА из закреплённых условий, прочитанных в этом ходе (выбраны моделью или уже
  сказаны в чате); ипотека, скидка, проценты годовых, взнос, роль покупателя или неизвестная — без суммы (ревью В1).
  По-таджикски — только цифрами и знаками («2% × 700 000 = 14 000»): непроверенных носителем слов нет.
- **Обмен машины** — только машина + «принимаете/в зачёт» в одной фразе (до 4 слов) или обмен вместе с машиной/недвижимостью
  (ревью С2). **Сотрудничество** — не перехватывает продавца, покупателя, соискателя (ревью С3).
- **Пустой поиск и «новых вариантов нет»** — «Агент подберёт варианты вручную» + номер; старое «сотрудник позвонит» без номера убрано.
- **Номер — один раз за разговор** (ревью С6): если уже просили, передача без второй просьбы.
- **Обещание агента доходит до ответственного** (ревью С4): `signalStaffFollowUp` → одна дверь `alertClientWaiting`
  (триггер `follow_up`): закреплённому агенту, без агента — руководству (DIRECTOR/ADMIN), а не всем, кто читает чаты.
  Ключ — эта реплика клиента, а не окно 6 ч: каждое новое обещание доходит, одно и то же — один раз.
- **Таджикские строки** — только из tajik-phrasebook без пометки «(?)» (ревью С5): сотрудничество по-таджикски —
  «Ташаккур, дархости шумо қабул шуд.» вместо непроверенного «ба роҳбарият мерасонам».
- **Два ответа на два сообщения подряд** (старый путь Meta и Telegram, клиент с карточкой): окно склейки 6 с за рубильником
  `Settings.botMergeQuickRepeats` («Настройки → Бот»), **по умолчанию ВКЛ** — владелец 15.11 дословно: «Да, 6 секунд можно»
  (отменяет решение 19.08 «сразу» только в части склейки). Выключен — 0 с, как раньше.

Промпт нового ядра не менялся (смена промпта = ручное «Обновить версию бота»); запреты стоят кодом рендера. Новый файл
`ai/customerAgentStaffFollowUp.ts` в группе `rendererHash`.

Тесты: `tests/customer-bot-8-chats-15-11.test.ts` — настоящий текст ответа на каждый класс, сторож «ни одна живая строка не
говорит "выше/повтор"» и «молчания нет», склейка двух сообщений через `debounceAndMerge` с базой (вкл/выкл), сигнал
ответственному (агент / руководство, повтор той же реплики не шлётся, новое обещание шлётся), Рудаки в зоне.
