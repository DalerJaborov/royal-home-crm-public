# 17.11.2026 — «Один мозг»: сторож списка фраз модели (перенос из #180)

## Что изменилось
- Новый тест-сторож `customer-agent-answer-phrase-guard`: каждая фраза модели (`HUMAN_PHRASES`) и каждый её вопрос (`APPROVED_ASKS`) — только на «вы/шумо» (без «ты/ту», «-ӣ», «брат»), без слов другого языка, вопрос — только в слоте вопроса. Новая фраза с такой ошибкой не пройдёт CI.
- Контроль валидатора: «ты/ту», смесь языков и свободный вопрос в словах модели отклоняются.

## Почему только сторож
PR #180 улучшал проверку свободной фразы `say`. В новом ответе модели (#211/#238) модель говорит только целыми фразами из списка и вопросами из одобренного списка, поэтому «вопрос по предложению», «ты/ту» и «смесь языков» там уже держатся устройством проверки. Не хватало проверки самого списка — она и добавлена. Код бота не меняется, версия бота та же.
