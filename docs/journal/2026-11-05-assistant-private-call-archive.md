# 05.11.2026 — Шабнам ищет по прошлым звонкам клиента

- В личном чате сотрудник может спросить, что конкретный клиент говорил о теме в прошлых звонках. Поиск проверяет последние 40 сохранённых расшифровок и возвращает до трёх фрагментов с датами и источниками.
- Для поиска действуют те же права CRM на чтение карточки и звонков. Телефоны в ответах скрыты. Доступ проверяется и для звонка, связанного с клиентом через маршрут.
- Проверено на PostgreSQL с доступными и недоступными сотруднику звонками и на примерах запроса по теме.
