# Bounded model tool argument correction

An invalid argument object for an otherwise declared, currently allowed tool stopped a customer turn immediately. The core now returns a finite argument-validation response to the same model within the original operation, round count, call count and deadline. Invalid calls consume that original budget. No legacy controller, alternative sender, stock customer answer or employee handover is introduced.

The complete call batch still validates before any effect. If one argument object is invalid, no call in that batch executes, including valid writes. Unknown tools, missing declarations/capabilities, public writes, malformed envelopes and reused call IDs remain held. The correction response contains only finite status values, never rejected arguments, fabricated facts or receipts. Ownership and freshness checks still run between rounds.

Local baseline reproduced the immediate hold with zero effects. New regressions cover a corrected public read, whole-batch write suppression, original round/call limits, rejected-call ID reuse, lost ownership and unknown/unavailable tools. Existing core tests remain part of the same targeted run. This is source preparation; official release, production activation and real delivery remain separate gates.

The same missing-context investigation found two parser paths controlled by the old property feature switch: advertising references inside a button postback and publication IDs on later attachments. The authenticated CORE normalizer now explicitly captures those original references independently of that switch. Default legacy parsing retains its prior behavior. This option captures metadata only; original HMAC/frame membership, immutable encrypted sources, FINAL classification, namespace assurance and actual read/write guards remain unchanged. Already stored sources are not rewritten or replayed.

Parser regressions failed before the change, including a real signed pending-envelope/PostgreSQL case. One initial test cleanup used a nonexistent environment helper; its failure was retained, corrected, and the actual missing-reference assertion was reproduced separately. The parser, legacy webhook and trace controls subsequently passed together. No claim is made that an inaccessible ad or an unregistered publication has thereby been identified.
