# 03.11.2026 — Свои объекты: цена сразу, удаление в Корзину (помощник)

- Решение владельца (03.11.2026): «отменить замок» на цену своего опубликованного объекта; удаление своих объектов — «дай все разрешения, но в Корзине всё можно смотреть». Кнопка «Подтвердить» остаётся, «Отменить» после выполнения — тоже.
- Что изменилось:
  1. REST `PATCH /properties/:id`: замок публикации (07.10.2026) больше не держит `price` и `currency` для ведущего/приёмщика/создателя объекта (`lib/propertyAccess.ts::ownsProperty`, `OWNER_OPEN_AFTER_PUBLISH_FIELDS`). Остальные поля, чужие объекты и цена ПРОДАННОГО (только руководству) — как было.
  2. `change_property_price`: для своего объекта (и руководителя с `properties.editForeign`) после «Подтвердить» заявка создаётся и тут же принимается автором тем же исполнителем, что кнопка «Принять» директора (`approvePropertyChangeRequest`: сайт, подписи, посты, журнал) — один путь, не копия. Откат — встречная заявка с прежней ценой, только если цену не меняли после (иначе 409 UNDO_STALE). Чужой объект ассистенту недоступен вовсе (как в REST: заявку подаёт только тот, кто ведёт объект).
  3. Новый `delete_property` (уровень C, кнопка): МЯГКОЕ удаление в Корзину через `lib/trashProperty.ts` (как кнопка и одобрение заявки на удаление), только свой объект или `properties.delete`/`editForeign`; объект со сделкой не удаляется; пишется в журнал (`TRASH`, source assistant). Жёсткого удаления из чата нет.
- Права НЕ менялись: пресет роли «агент» не расширялся (REST `DELETE /properties/:id` не проверяет «свой» и дал бы агенту удалять чужие). Видимость Корзины — как в CRM сейчас.
- Не сделано: (а) в карточке объекта на сайте форма остаётся заблокированной после публикации — цену своего объекта пока меняют через помощника/API, правка экрана отдельно; (б) смена СТАТУСА («снят/резерв/продан») остаётся заявкой «Другое»: прямая смена требует вынести тело PATCH в общую функцию — отдельная пачка; (в) «продан» ставит сделка, как раньше.
- Чем проверено: `ai-assistant-property-tools` (цена сразу, повтор, откат, откат при чужой правке, удаление свой/чужой), `property-own-price-unlock` (REST: цена своего — можно, другие поля — 409, чужой — отказ, проданный — 403), `property-edit-lifecycle`, `property-sold-price-lock`, audit:deps без новых нарушений.
