# 12.11.2026 — Озвучка: монтажёр вклеивает голос сам, «Без озвучки», ролик от СММщика

Решения владельца 12.11.2026 (через координатора), продолжение `2026-11-11-narration-flow.md`.

## Что изменилось

- **A. Монтажёр получает mp3 и сводит сам.** Рубильник «голос накладывает CRM» (`mixByCrm`) теперь
  по умолчанию ВЫКЛЮЧЕН (`narrationMixByCrm` = только `true`). Подпись mp3 монтажёру: «вклейте этот
  голос сами… при сдаче пришлите два файла: готовый ролик и тот же без голоса». Одна строка об озвучке
  в задании на монтаж и перемонтаж — `lib/narrationMontajerNote.ts` (без озвучки / ждёт одобрения /
  задерживается / вклейте). После готового ролика бот ОДИН раз просит тот же ролик без голоса, кнопки
  «🎵 Пришлю без голоса» / «Не сейчас» (`mj:nv`, `mj:nvx`); узнаёт файл по кнопке (час) или подписи
  «без голоса 123». `lib/narrationVoicelessCopy.ts`: длина должна совпасть с готовым (±1,5 с), файл —
  отличаться; мастер хранится с версией озвучки из вышедшего ролика, дальше смену цены делает
  существующий `remixFromMaster`. Не подошёл после кнопки — принимается обычным готовым роликом.
  Без мастера — возврат монтажёру «замените только голос, музыку и монтаж не трогайте» (+ mp3).
  Озвучка длиннее мастера — тот же возврат с «удлините ролик».
- **B. «Без озвучки».** `Property.narrationOff`, одна дверь `lib/narrationOptOut.ts`: мастер CRM
  (галочка в `NarrationChoice`), мастер Шабнам (кнопка «🔇 Без озвучки» в карточке проверки,
  `values.narrationOff` черновика), карточка (`POST /properties/:id/narration/mode`). Ничего не
  генерируется, ждущее снимается, неотправленная передача гаснет, монтажёру строка.
- **C. Озвучка к роликам, уже стоящим в монтаже.** `backfillMontageQueue` — QUEUED и у монтажёра,
  без версий: версия `BACKFILL` на одобрение ВЛАДЕЛЬЦУ (директор, иначе администратор; поправка
  владельца), одобряет только он. Свой рубильник `backfillMontageQueue`, по умолчанию ВЫКЛЮЧЕН и с
  автоозвучкой сам не включается (владелец решит). Идемпотентно, «Без озвучки» пропускает.
  Ролик сдан раньше одобрения и ещё не вышел — возврат «вклейте голос» (`requestNarrationAddVoice`).
- **D. Ролик от СММщика / сотрудника.** `telegram/staffClip.ts` + `StaffClipIntake`: объект по номеру,
  ссылке CRM или сайта, иначе кнопками (последние объекты) или словами (номер, адрес). «Готов к
  выпуску» / «Заменить вышедший» — общая с карточкой дверь `lib/finalVideoIntake.ts` (маршрут CRM
  переведён на неё); «Нужен монтаж» — исходник объекта + существующая очередь (или перемонтаж
  `NEW_FOOTAGE`, не брак монтажёра). Права — `canManagePropertyAs`, не монтажёр, не «только чтение».
  Агенту объекта — уведомление. Дубль по `file_unique_id`. «Не тот объект» — час, откат ровно сделанного.
- **E.** Продан/снят/удалён: `retireNarrationsOfClosedProperties` (из `closeWorkAfterLeavingSale` и
  каждым тиком). Напоминание агенту через 3 ч, ещё через 3 ч — руководителю продаж (иначе директору),
  только 09:00–20:00 по Душанбе, без автоодобрения; владельцу по разовому проходу — одно общее.
  Агент сменился — пишут нынешнему. Кончились кредиты — монтажёру один раз «озвучка задерживается».
- **Голоса и синтез.** Стартовый набор (миграция, только если пусто): 8 голосов владельца с именами
  и полом, модель `eleven_v4`, `voiceSettings` 0.5 / 0.75 / 1.0, 70 слов словаря произношения (у кого
  есть alias или IPA; «проверить носителем» видно в Настройках). `narrationTtsOptions` — одно место
  добавок к запросу: `language_code` tg/ru, `voice_settings` (style и speaker boost в v4 не уходят —
  ФАКТ координатора), словарь только для `eleven_v4`. Синхронизация словаря при сохранении
  (`lib/narrationPronunciation.ts`; пути add-from-rules / set-rules — ОЦЕНКА, архив — PATCH archived).
  Образцы голосов: ключ кэша включает настройки синтеза — правка словаря делает их устаревшими.
  Новая фраза образца. Теги вроде `[excited]` разрешены в шаблонах (не считаются «если есть»).
- **Последний выбор голоса/шаблона** — `Agent.narrationLastChoice`, мастер CRM, карточка и Шабнам
  ставят заранее с подписью «последний раз выбран»; убранный голос — сброс на общий.

## Дополнение 12.11.2026 — правки по независимому ревью

1. Догоняющий проход автоозвучки — только объекты мастера CRM/Шабнам (`Property.createdInCrmWizard`,
   ставит `createProperty`) и очереди монтажа; заявки с сайта на модерации не трогает.
2. Старые версии (снимок фактов без цены, до 11.11) не устаревают от одного поля цены:
   `narrationFactsCurrent` в `lib/propertyNarration.ts` — одно место для всех сравнений (обход,
   одобрение, генерация, план и отправка монтажёру, перемикс, карточка).
3. PREVIEW (`CRM_NARRATION_EXECUTION_MODE` ≠ LIVE): автоозвучка не платит вовсе и не заводит
   строку «передано»; одобренная версия уходит монтажёру после включения LIVE, старая PREVIEW-строка
   досылается.
4. Дневной потолок символов считает итоговый текст (таджикские цифры словами) — `speechChars`.
5. «Нужен монтаж» по объекту с роликом — через `sendPropertyBackToMontajerAs` (права editForeign и
   снятия постов, новый параметр `replaceOnNewVideo`).
6. После видео без объекта Шабнам ловит только номер или ссылку; другой текст идёт обычным путём и
   закрывает ожидание; пересланное видео не трогаем; «Отмена» и в карточке выбора.
7. После «Пришлю без голоса» файл не той длины — вопрос монтажёру кнопками («это без голоса» /
   «это новый готовый ролик»), а не молчаливый приём.
8. Старая ручная озвучка: монтажёру не обещаем mp3 («ведёт маркетинг вручную»).
9. Замок на сведение ролика (`Property.videoMasterMixingAt`, брошенная метка — 15 минут).
10. Обходы фактов и перемикса идут курсором по id — объекты за пределами порции не теряются.
- Рубильник «Ролики от сотрудников через Шабнам» (`Settings.staffClipIntakeEnabled`, по умолчанию
  включён) — Настройки → Каналы, рядом с передачей монтажёру.
- Миграция `20261112120000_narration_review_fixes` (только добавления).
- Проверено: `tests/narration-review-fixes.test.ts` 9 (Postgres + ffmpeg), `narration-auto-flow` 23,
  связанные наборы озвучки и `video-handoff` 145; мутация «старые версии без цены» — тест краснеет.
- Повторное ревью: «Готов к выпуску / Заменить вышедший» от сотрудника — та же проверка, что у
  загрузки в карточке CRM (`publishedActionDeniedReasonAs`: после публикации — руководство);
  метка сведения ставится, только когда сведение нужно (`remixWanted`, updatedAt не трогается);
  «Это новый готовый ролик» принимает файл как готовый даже с подписью «без голоса».
  Тесты: `narration-review-fixes` 11 (+3), мутация «без finalForSure» краснеет.
