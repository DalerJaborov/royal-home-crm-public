# 2026-11-22. Карточка сотрудника «одним взглядом»

## Что сделано
- Новый вид карточки сотрудника (`components/look/team/RoyalAgentCard.tsx`): одна карточка на все ширины, плитки за неделю или месяц, график по дням, замечания «покупатели / продавцы» раздельно; нажатие на плитку открывает список записей.
- API: `GET /api/v1/agents/:id/glance` и `/glance/drill` (`lib/agentGlance.ts`, договор в `packages/shared/src/agentGlance.ts`). Право `team.viewFull`; комиссия только при `finance.view`; номера в именах закрываются как в `/overview`. Цифра плитки и число строк списка берут одно окно и одни условия.
- Тексты шапки и блока «Сейчас» вынесены из страницы в `lib/agentCardText.ts` (старый и новый вид говорят одинаково). Прежний вид страницы остался для выключенного «Нового вида».

## Найдено при доводке
- Список «покупатели / продавцы» падал 500: сортировка `lastContactAt` с `nulls: first`, а поле не пустое (`@default(now())`). Исправлено, закреплено тестом «плитка = список».
- Убран временный переключатель «до/после» (`?agcold`) из страницы.
