# 26.11.2026 — РОП видит продавца и звонит ему на любом объекте

**Жалоба владельца:** под объектами у РОП нет имён продавцов и кнопок «Позвонить»; РОП должна звонить любому и видеть имя хозяина объекта.

**Причина (ФАКТ, код main):** `routes/properties/list.ts` показывал `sellerClient` и маску номера только тому, у кого есть `properties.viewOwners` (директор) или кто ведёт объект (`ownsProperty`). У РОП права нет, объект чужой — собственник скрыт целиком.

**Что изменено:** для роли `HEAD_OF_SALES` продавец показывается на любом объекте (имя, `sellerClient.canOpen`, маска номера). Полный номер по-прежнему только директору (решение 16.11/18.11). Звонок идёт через станцию по карточке продавца: у РОП есть `clients.assign`, `POST /clients/:id/call` её пускает.
Тест: `apps/api/tests/property-seller-visible-to-rop.test.ts` (РОП видит, посторонний агент нет).

**Не сделано / вопросы:** `assignmentWriteDenied` не даёт никому, кроме директора и админа, писать и звонить клиенту с завершённым закреплением — РОП тут тоже упрётся. Решение владельца нужно.
