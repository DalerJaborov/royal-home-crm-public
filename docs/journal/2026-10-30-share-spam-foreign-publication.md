# 2026-10-30 — чужие публикации, «лайк за лайк», адрес офиса без спроса, повтор заготовок вложений

Ветка `fix/core-share-spam-30-10`. Случаи с прода (Instagram DM, новое ядро): клиент шлёт чужой рилс без текста — бот три раза подряд
«Что хотите узнать по этой публикации?»; чужой рилс + «Лайк камент паделится» — «Ташаккур!» и полный адрес офиса; «Blizkiyoooo ❤️» —
вопросы покупателю; фото без текста — «Получил вложение, но его содержимое мне сейчас недоступно».

## Что изменено
- `ai/customerAgentAttachmentInput.ts`: новый вид вложения `foreign_share` (серверный, в модель уходит только как метаданные); строка
  `FOREIGN_SHARE_LINE` (ru/tg); фраза `unknown` заменена на человеческую; список всех заготовок для сторожа повторов.
- Признак «чужая публикация» ставит сервер, не модель: `lib/customerSharedPublication.ts::customerForeignShareCandidate` (вложение —
  только share, и вся улика объекта — этот же share: ни рекламы, ни истории, ни ответа, ни ссылки в тексте) +
  `lib/customerDmAgentTurn.ts` (поиск по нашему каталогу для ЭТОГО события закончился «такого объекта нет», а не временным сбоем).
  Прокинуто через `lib/customerDmCoreContext.ts` (`foreignShareCandidate`).
- `ai/customerAgentCore.ts`: до всякого чтения и до модели — чужой share без вопроса (пусто / только эмодзи / слова «лайк-обмена» /
  1-2 латинских слова без цифр, «?» и приветствия) → первый раз одна короткая строка, повторно — «ответ не нужен»: `held`
  `foreign_share_no_reply` (диалог не останавливается, следующее настоящее сообщение — новый ход). Вопрос по существу
  («ин хона чанд аст?») идёт в модель как раньше. Ветка attachmentOnly теперь рендерится с `verifiedContext`.
- `ai/customerAgentAbuse.ts`: SPAM расширен цепочкой «лайк/камент/поделись/взаимка/like4like» (одиночное «поделитесь номером»
  не спам); `customerDmForeignShareNoise`.
- `ai/customerAgentRenderer.ts`: адрес и часы офиса печатаются, только если клиент спросил об агентстве (где/адрес/офис/часы/услуги);
  иначе ссылка на `company_information` молча отбрасывается (кандидатам на работу остаётся). Заготовки вложений — в сторож повторов.
- Атакующий стенд: вложение `ig_reel_foreign`, категория `dm-share` (15 сценариев).

## Чем проверено
`tests/customer-share-spam-30-10.test.ts` (58 тестов), `npm run build --workspace=apps/api`, смежные тесты ядра, атака
`--model scripted --category dm-share` и `media`.

## Осталось / решения владельца
- Свой рилс, не привязанный ни к одному объекту (рекламный), тоже считается «не нашим»: поиск вернул «нет такого объекта».
- `company_information_unsolicited` в `guardMetrics` не считается: рендерер чистый и вызывается повторно при запечатывании.
- Тексты ответов не менялись в промпте: хеш пары промпта не тронут.
