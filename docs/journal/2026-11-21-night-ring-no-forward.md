# 21.11.2026 — ночное правило «Без дежурного» (ring)

**Просьба владельца.** Если на городской 44 650-14-14 (офисный аппарат 2020) никто не
ответил за 15 секунд — звонок уходит директору на мобильный. Директор отвечает с 10:00
до 22:00. Ночью — «как сейчас»: звонит только 2020, без переадресации.

**Почему понадобился код.** Дневное правило «если не ответили → дежурному» уже было
(`ROYALHOME/failover/action|seconds|phone`). Но ночной режим умел только «как днём»
(то есть переадресация круглые сутки), «сразу дежурному» и «сразу автоответчик».
Варианта «ночью звонит основной аппарат без предела, дежурного не будим» не было.

**Что изменилось.**
- `ops/asterisk/extensions_custom.conf`: ночное значение `ring` уводит звонок в ветку
  `target` с действием `none` (пустой таймаут Dial — звонит, пока не снимут/не положат).
- `routes/settings.ts`, `useSettings.ts`: значение `ring` принимается.
- `ChannelsTab.tsx`: кнопка «Без дежурного» в «Нерабочее время».
- Тест `apps/api/tests/dialplan-night-ring.test.ts`.

**Проверено.** dialplan-night-ring, dialplan-custom-text, inbound-routing — 64/64.

**Осталось (прод, только с «да»).** Залить диалплан на станцию (резерв → копия →
`dialplan reload` → `dialplan show royalhome-inbound`); в Настройках → Каналы связи:
«Если оператор не ответил» = дежурному, 15 с, номер директора; «Нерабочее время» =
«Без дежурного», 22:00–10:00.
