# 2026-11-21 — автообложка «Royal Green» по макету Reels (PSD)

**Что изменилось.** Встроенный шаблон `royal-green` (он же шаблон по умолчанию) перерисован под макет владельца
`Reels (new).psd`: фото сверху, кремовый градиент, зелёная плашка с золотой окантовкой
(тип объекта, вторая строка, площадь), разделитель и пин с районом, три постоянных преимущества, золотая волна.
Квадрат сделан тем же макетом, сдвинутым вверх. Мягкая светлая дымка под знаком и ценой — чтобы текст читался
на любом фото.

**Как.**
- `assets/cover/templates/royal-green.build.mjs` переписан (источник правды); волна, плашка и значки — PNG-слои
  из PSD в `assets/cover/royal-green-parts/` (вшиваются в SVG base64).
- `coverRegistry.ts`: у шаблона новые `photoBox` (фото только в полосе сверху) и `photoCanvas` (кремовый холст);
  новые значения шаблона `kind`, `kindSub`, `kindSolo`, `areaBig`, `areaUnit`, `areaSup`, `placeLine`.
- `coverPoster.ts`: `buildCoverPosterValues` принимает необязательные `type` и `totalFloors`; `renderCustomTemplate`
  кадрирует фото в `photoBox`. Старые вызовы без новых полей работают как раньше (тип выводится по комнатам/соткам).
- Слова: квартира «КВАРТИРАИ / N ХОНАГА»; дом «ҲАВЛИИ / N ОШЁНА» (этажность, иначе комнаты);
  коммерция «ТИҶОРАТӢ» и участок «ЗАМИН» — одной строкой, у участка крупно сотки («сотих»);
  район — «ноҳияи X», без района — «шаҳри Душанбе».
- `coverOpenAi.ts`: `TEMPLATE_COVER_VERSION` = `royal-green-2` (старые обложки по хэшу перерисуются при следующей
  публикации/добре, сами по себе уже опубликованные не меняются).
- Шрифт: в макете Montserrat; в проекте нет Montserrat с таджикскими буквами и метриками, оставлен TT Norms Pro 800/500.

**Проверено.** `build:shared`, `build:api` — чисто. `tests/cover-templates.test.ts` — 39/39 (старые числа плашки
и фона переписаны; добавлены тесты слов плашки по типам, цены в поле, фона и квадрата). `cover-poster` — 33/33.
`cover-openai*` — зелёные по одному; при общем прогоне 7 тестов упали по таймауту 20 с из-за нагрузки машины
(одиночный прогон — 2,5 с, с моими правками и без них одинаково). Кадры: вертикаль и квадрат, 4 типа объектов,
длинная цена, тёмное и светлое фото.
