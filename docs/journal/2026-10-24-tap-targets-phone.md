# 2026-10-24 — зоны нажатия на телефоне ≥44 px (зона F2)

**Что.** Перепись экранов 24.10 нашла кнопки шапки 40px, вкладки 36px, чипы-фильтры 34–36px. Проверка CSS показала: накладки (`::before/::after`) в теме уже были, но недобирали или резались.

**Причины (механизмы).**
1. `inset:-2px` у кнопки с рамкой 1px считается от внутреннего края: `.sh-btn` (40) давала 42, а не 44. То же у `.rh-tabs button`, `.rh-filters button`, `.fchips button`, `.btn.sm.soft`.
2. Накладка внутри ленты `overflow-x:auto` обрезается её рамкой: у `.mh .lane` вертикального запаса не было — нажималась только пилюля 34px.
3. Вкладки раздела `.seg-ai` (`ScreenTabs`, ссылки «Команда», «Список») 36px и без накладки; в чистой оболочке у них уже `min-height:44px`.

**Правка.** Только `apps/web/src/theme-2026-brand.css` (раздел «ЗОНЫ НАЖАТИЯ НА ТЕЛЕФОНЕ»): токен `--tap-pad = min(0px, calc((100% - 44px)/2))` — накладка добирает до 44 по размеру самого элемента; правила под `@media (max-width:819px)`. Запас `.lane` и `.seg-ai` снят с отступов, раскладка не сдвигается. TSX не менялись (`Topbar`, `ProfileMenu`, `LegacyAgentTopbar` уже 44 или с накладкой; добавлена страховка min 44 для «Профиль и выход»).

**Не тронуто.** `.rh-row-link::after` и `a.lk::after`; быстрые ответы чата (`.quick[data-chat-quick]`, 34px с рамкой → 43px; нужен 1px запаса в `theme-2026-mobile-chat.css`, другая зона).

**Проверка.** `gen:typeset`/`audit:typeset`, `build:web`, `test:web` (1869) — код 0; тест-сторож `lib/__tests__/tapTargetsCss.test.ts`; формула проверена в Chromium (40+рамка → 44, 34 → 44, 44 → 44).
