# 20.11.2026 — «Новый вид»: конституция оболочки (пачка C)

- Что изменилось: слои нового вида (`theme-look-royal*.css`, кроме четырёх разделов директора)
  переведены на шкалы из одного места — блок «КОНСТИТУЦИЯ ОБОЛОЧКИ» в `theme-look-royal.css`:
  8 размеров шрифта вместо 19 (+12 clamp), 4 скругления вместо 25, 3 тени вместо 60, цвета только
  токенами, 6 точек перелома вместо 19. Два переключателя вместо шести (`RhSegmented`, `RhTabs`,
  `RhNavTabs` в `components/look/ui.tsx`; прежняя разметка `.seg`/`.seg-ai`/`.ry-ctabs` красится теми же
  токенами), четыре вида кнопки (primary/secondary/ghost/danger, `disabledReason` — причина подписью),
  поля с видимой границей ≥ 3:1, выпадающий список не режет выбранное, строка клиента нажимается
  целиком, «Все» и стрелка сообщения — цель 44 px. Новый сторож `npm run audit:look`
  (`scripts/audit-look.mjs`, шаг `precheck`/CI, база `.look-audit-baseline.json` только убывает) и
  три вида геометрии e2e: `smallText`, `smallTap`, `selectClip`. Разбор — `docs/design/look-constitution.md`.
- Почему: разбор интерфейса 20.11 (critic-uiux, «Конституция оболочки», п. 6, 12, 13, 15) и решение
  владельца «одна идеальная оболочка без багов».
- Чем проверено: `node --test scripts/audit-look.test.mjs` (сторож проверен поломкой: шрифт, скругление,
  цвет, тень, точка перелома, база); `npm run test:web`; `theme-look-royal.test.ts` (шкалы и контраст
  границы поля в обеих темах); e2e `new-look-geometry` @smoke (новые виды проверены нарочной
  поломкой) и `new-look-*` @smoke; кадры до/после 390/1440 свет/тьма — главная, клиенты, объект,
  чат, настройки (`D:/CRM/docs/design/oblik-2026-11-17/constitution/`).
- Что осталось: четыре раздела директора (Отчёты, Реклама, Деньги, Контроль) — в базе исключений до
  влития `feat/look-director-sections`; геометрия конституции на всех 48 экранах — пока без новых
  видов; `RhSelect` (шторка вместо системного списка) и вес шрифта (6 насыщенностей) — следующей пачкой.
