# 12.11.2026 — ship молча выходил с кодом 0 на этапе 9

**Что было.** 11–12.11 ship трижды (#157 и дважды #147) печатал «связь с GitHub оборвалась
(UND_ERR_CONNECT_TIMEOUT), повтор 1 из 4 через 5 с» и завершался с кодом 0 без вливания.
Причина (ОЦЕНКА по коду, подтверждена тестом-моделью): таймеры ожидания — `AbortSignal.timeout`
у чтений и таймеры соединения undici — сняты с якоря (unref). Пока запрос висит на соединении,
у Node не остаётся держащих дел, и процесс завершается с 0 при незавершённом `main()`.

**Что сделано.** `runUntilSettled` в `scripts/ship.mjs`: держащий таймер, пока `main()` не
завершится; выход раньше — всегда код 1 и строка «ship вышел, не дойдя до конца… сверь
git log origin/main». Тест в `scripts/ship.test.mjs` (ждёт на unref-таймере); без держащего
таймера он красный.

**Проверено.** `node --test scripts/ship.test.mjs` 47/47.
