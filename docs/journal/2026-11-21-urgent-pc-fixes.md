# 21.11.2026 — срочные правки ПК: переписка, бюджет 0, объявления за 30 дней

Кадры владельца с живого сайта, новый вид (`data-ui-look="royal"`).

## Что изменилось
- **Боковая переписка не листалась вверх (причина).** Слой списка Virtuoso в `ClientChatPanel` носил класс `.thread`;
  у `.thread` темы `overflow-y:auto; overscroll-behavior:contain`. Колесо мыши над пузырём попадало в этот слой и не
  передавалось настоящему прокручиваемому родителю. Теперь у слоя `overflow: visible; overscrollBehavior: auto`.
- **Нижняя строка:** канал один — выбор канала не рисуется, ответ уходит в него сам; поле ввода `flex: 1 1 0; min-width: 0`
  (раньше «Выберите канал» занимал строку, поле сжималось до «Сн…»). Каналов несколько — выбор на своей строке.
- **Метка канала («WhatsApp») в пузыре и «N канал(а)» в шапке убраны** (решение владельца: «нам не важно, откуда клиент»).
  Только в боковой панели карточки; инбокс (`Messages.tsx`, `MobileChatView.tsx`) не трогали.
- **Бюджет 0 = «не указан».** Одна дверь записи (`db.ts`, `budgetGuard`): 0 / отрицательное в `budgetMin`/`budgetMax`
  (create, update, updateMany, upsert) превращается в null. Чтение: `positiveBudget` в `packages/shared/src/budget.ts`
  (экран «Запрос покупателя», карточка, список, показ; подбор своих объектов `clientPropertyMatching`; обратный
  запрос спроса `matchPolicy.ts`). Подбор с площадок уже считал бюджет >0.
- **Объявления с сайтов — только размещённые за 30 дней** (`MARKET_BUYER_PLACED_MAX_DAYS`): по `publishedAt`, без него
  по `firstSeenAt`. Сервер: `buyerListingsWhere` и `matchesBuyer` (пуши и ассистент тоже). Экран пишет «за последние 30 дней».
  Заодно убрана жёсткая дата `2026-11-01` в тесте (сама бы выпала из окна 01.12).
