# 10.11.2026 — «Не присылай мне такое», единый вид списков, напоминания об оплатах

- Что изменилось:
  - **Одна дверь отключений** `apps/api/src/lib/notificationPrefs.ts`: push CRM
    (`push.ts::isMuted`), тумблеры профиля (`routes/push.ts`) и помощница в
    Telegram читают и пишут одно поле `Agent.pushMuted`. Новые виды в
    `packages/shared/src/push.ts`: `payment` (оплаты подписок), `publication`
    (публикации объектов), `security` — НЕ отключается (`ALWAYS_ON_KINDS` с
    причиной для человека); `lib/staffSecurityNotify.ts` теперь шлёт с видом
    `security`.
  - **Дверь сообщений помощницы по её почину** `apps/api/src/telegram/staffNotice.ts`
    (`sendStaffNotice`): требует вид, не шлёт выключенное, ставит
    «🔕 Не присылать такое», пишет журнал `StaffNotice` (миграция
    `20261110180000_staff_notice`), один повод = одно сообщение. Слова в личке:
    «не присылай мне такое» (ответом на сообщение или в течение 30 минут после),
    «мне это не нужно», «не присылай мне оплаты», «что у меня выключено»,
    «включи обратно …», тадж. «инро нафирист», «ин лозим нест». Через дверь
    переведены: пост «Поделитесь» (`lib/agentSharePost.ts`, вид `publication`),
    предложение объекта коллеге (`telegram/assistantPropertyOffers.ts`, вид `look`;
    выключил — предложение ложится в колокольчик CRM, не теряется).
  - **Модуль списков** `apps/api/src/telegram/assistantList.ts`: заголовок с
    иконкой и числом, 1️⃣…🔟 дальше «11.», код карточки первым жирным, главное
    второй строкой, срок третьей, «💡 Совет», длинное — свёрнутой цитатой,
    страницы ≤ 4000 знаков с продолжением нумерации, ru/tg. На нём: «клиенты
    агента …» (`assistantReadResults.ts`), «что у меня выключено», напоминания
    об оплатах.
  - **Напоминания об оплатах** `apps/api/src/lib/paymentReminders.ts`, задача
    `payment-reminders` в `cron.ts` (каждый час, внутри — только рабочее окно
    Настроек): за 3 дня, в день оплаты, при сбое оплаты известного сервиса (402 /
    billing / insufficient в журнале ошибок за сутки), «⏰ Напомнить завтра» —
    один повтор. Кому — право `finance.view`; «✅ Оплатил» — только с
    `finance.manage`, той же командой `changeRecurringOccurrence`, что
    `POST /expenses/recurring/:id/pay`, с записью в журнал действий. Суммы — в
    сомони по курсу CRM, для карты «На карте должно быть: ~X с. (с запасом 2%)».
    Без Telegram — тот же повод в колокольчик и push CRM. Прежние «Скоро оплата» /
    «Пора оплатить» из `financeAutomation.ts` сняты (два сообщения об одном платеже).
  - **Профиль CRM**: новый блок «Что присылать мне» (ПК, вкладка «Уведомления» в
    чистом профиле, мобильный профиль агента) — больше не спрятан за подпиской
    устройства; безопасность — строкой «Всегда» с причиной.
  - **Сторож** `apps/api/tests/staff-notice-one-door.test.ts`: файл, пишущий в
    Telegram сотрудника мимо двери, — только из списка с причиной; push CRM без
    вида — не больше 107 (число только убывает).
