# 2026-11-02 Рынок: исправления по независимому ревью (обход, хранение, бюджет Somon)

Ветка `feat/market-core`. Правки по 10 находкам ревью, у каждой — регресс-тест.

- **marketStore.saveListings**: обновление не затирает необязательные поля (`sellerPhone`, ремонт, тип дома, координаты, район и т.д.) значением null, если источник их не дал; снимок цены пишется по смене ИСХОДНЫХ `price`/`currency`, а не `priceTjs` (смена курса доллара больше не даёт ложных «снижений»); не изменившиеся объявления не переписываются построчно — одним `updateMany` отмечаются «видели» (пересчёт по новому курсу при этом применяется).
- **Paydo**: `crawlPaydoSection` возвращает `complete` и причину (`page_failed`/`page_limit`/`empty_page`); недельный обход помечает «исчезло» по Paydo только при дочитанных ДО КОНЦА обоих разделах. `runPaydoCrawl.ts`: полнота как у `runCrawl.ts` (все разделы, каждый полный), общий замок `withMarketCrawlLock`.
- **«Исчезло»**: `markDisappeared` по умолчанию — не видели дольше `DISAPPEAR_AFTER_HOURS` (264 ч ≈ 1,5 недельного интервала, то есть мимо двух полных обходов); вызывается только после успешного полного обхода. 404 на странице, на которую ссылалась прошлая, — конец раздела, если свежая предыдущая страница уже не ссылается дальше (рынок сжался).
- **Бюджет Somon** (`sourceBudgetStore`): обход и клик уступают лидам: 25 с тишины после запроса ЛИДОВ (токен слота обхода/клика помечен `bg:` и переживает ответ), обход не берёт слот с 50-й секунды минуты (старт тика лидов). Новый режим `interactive` (кнопка номера «по клику») и `fetchSomonPhoneInteractive(id)` в `lib/somonLeads/phone.ts`. Поведение лидов не менялось.
- **cron**: `market-weekly-crawl` просит предел тика 3,5 ч; `scheduleTracked` больше не обрезает явно заданный `timeoutMs` до 20 минут (умолчание прежнее).
- **monitor**: запись рынка из минутного парсера лидов — без перезаписи неизменённых строк; флаг `MARKET_MONITOR_INGEST=0` выключает её целиком (по умолчанию включено).
- **Тест** `market-full-crawl`: порог 60 % теперь проверяется по-настоящему (`count` отдаёт прежний объём по источнику).
