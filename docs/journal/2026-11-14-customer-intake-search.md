# 14.11.2026 — Клиентский бот: анкета не переспрашивает, поиск не теряет бюджет и район (аудит «регулярка решает вместо ИИ»)

Источник: `D:/CRM/docs/HANDOFF_2026-11-14-shabnam-voice-and-regex-audit.md` («анкета переспрашивает», «поиск теряет бюджет/район»).
Образец схемы: #170 / #172 — модель видит и передаёт структуру, код проверяет, регулярка запасная.

## Почему бот переспрашивал и терял (механизм, найден по коду)

1. **Два разных чтения слов клиента, оба узкие.** Анкета (`customerAgentIntake`) считала бюджет «известным» только после слов
   `бюджет/до/то` + цифра, комнаты только как «3 комнаты», район только из нескольких названий (и «район» как слово считался
   районом). Поиск (`customerAgentSearchIntent`) требовал слово-маркер перед суммой. «5000», «50к», «$50 000», «500 000 сомони»,
   «3 хонагӣ», «82 мкр», «двушку» не узнавались ни там, ни там.
2. **Сброс между ходами.** Роль «покупатель» ставилась только по «хочу купить…»; всё сказанное ДО этого («Сино, 3 хонагӣ, до 60 ҳазор»,
   потом «харидан мехоҳам») отбрасывалось (`start = i`). «Ищу двушку в Сино» роль не ставило вовсе.
3. **Голые ответы.** «3» / «70 000» / «Зарафшон» в ответ на вопрос бота нигде не читались: анкета не знала, какой вопрос был задан.
4. **Поиск не помнил разговор.** Условия брались из одного сообщения (или из «ответа на вопрос» + 2 прошлых реплики): бюджет с 1-го хода
   на 3-м ходу в поиск не попадал.
5. **Сумма без валюты** («до 60 тысяч») молча пропадала, а бот потом снова спрашивал «Какой бюджет?».

## Что сделано

- **Одно чтение**: `ai/customerBuyerNeeds.ts` — слова клиента → `CustomerBuyerNeeds` (тип, комнаты, бюджет min/max + валюта, район /
  место / «любой район»). Формы: «до 50 тысяч долларов», «50к», «$50 000», «500 000 сомони», «40-60к $», «от 40 до 60 тысяч»,
  «то 60 ҳазор доллар», «аз 300 то 450 ҳазор сомонӣ», «3 хонагӣ», «ду ҳуҷрагӣ», «2к», «двушку», «Шоҳмансур/Шохмансур/Фирдавсӣ/в Сине»,
  «82 мкр / 82-й микрорайон», «любой район». Район — через общий `officialDistrictIn` (`lib/searchPlace.ts`), а не копию регулярки.
  Валюту не угадывает; сумма вне разумного диапазона (`CUSTOMER_SEARCH_BUDGET_LIMITS` в shared) отбрасывается.
  Вопрос задан боту → голое «3» / «70 000» / «Сино» читается как ответ (`buyerQuestionAsked`, `askedBefore` в истории).
- **Анкета** (`customerAgentIntake`): `buyerKnown` теперь производная от `buyerNeeds`; до установки роли сказанное не теряется
  (сброс только при смене двух известных ролей); поисковый запрос без «хочу купить» ставит роль покупателя (только из «неизвестно»,
  продавца в покупателя не переворачивает, отрицание не считается).
- **Контракт** (`packages/shared/src/customerAgent.ts`): `intake.buyerNeeds` в сводке для модели (она видит, что названо, и передаёт
  это аргументами `search_public_properties`; правило в `intakeGuidance` и в описании инструмента). Новый вопрос `budget_currency`
  («Эта сумма в долларах или в сомони?» / «Ин маблағ доллар аст ё сомонӣ?» (по живой фразе агентов из `tajik-phrasebook`)): сумма без валюты уточняется один раз, а не
  повторным «Какой бюджет?».
- **Одна функция «что ещё неизвестно»**: `buyerNextQuestion(known)` в `customerBuyerNeeds.ts`; рендер (`customerAgentRenderedQuestion`)
  берёт известное из истории + текущей реплики + карточки объекта (только для того, кто сам сказал, что покупает; цену карточка не даёт).
- **Поиск**: `customerSearchIntent/Continuation` читают тем же чтением; `customerSearchIntentWithKnownNeeds` дополняет поиск тем,
  что покупатель назвал на прошлых ходах (текущая реплика побеждает: поправка). В `customerDmAgentTurn.ts` подключено.
  Бюджет без валюты поиск не сужает (как и раньше), но «голый» запрос без условий по-прежнему не поиск.
- **Контроль кодом для аргументов модели**: схема `search_public_properties` теперь отвергает бюджет вне диапазона валюты
  (USD 1 000…50 000 000, TJS 5 000…500 000 000); район проверяет и нормализует сервер (`searchPolicy`, уже было).
- Сводка (`lib/customerAgentVerifiedContext.ts`): к каждой реплике клиента прикладывается ответ бота на предыдущую (`askedBefore`).
- Новый файл добавлен в хеш-группы ядра и рендера (`customerAgentRegistration.ts`): правка читателя меняет версию бота.
