# 11.11.2026 — Бывшие сотрудники скрыты из всех списков CRM

- Что изменилось: одно правило `packages/shared/src/formerStaff.ts` — любой
  СПИСОК сотрудников по умолчанию без `isActive = false`. Справочник
  `GET /agents` (`listStaffDirectory`) больше не отдаёт бывших, а от него
  кормятся все выпадающие выборы на экранах (назначить агента, передать
  клиента/объект, фильтры по агенту в звонках, сделках, активности, расходах,
  зарплате, настройки бота и каналов) — и на компьютере, и на телефоне, — плюс
  помощник в Telegram (`staffReadTools`). «Команда» (`GET /team`,
  `/team/stages`), рейтинг недели (`leaderboard.ts`), месячный отчёт и отчёт о
  проблемах — тоже без бывших. Исключение одно: «место N из M в компании»
  в кабинете агента (`royalScore.ts`) — только число, без имён; его смысл
  держит тест `royal-score-cabinet`, сторож знает это место с причиной.
  Директору (agents.manage) бывшие приходят только по `includeFormer=1`:
  вкладка «Отключённые» в Настройки → Команда (вернуть ошибочно отключённого),
  карточка сотрудника по ссылке из истории, вопрос помощнику «покажи
  отключённых». Без права agents.manage флаг молча игнорируется.
- Данные не тронуты: в истории (кто создал, кто звонил, журнал) имя остаётся.

  вообще… Да давай всех скрой». Отключены 10.11 Нурмухаммад, Комрон, Сади.
