# 27.11.2026 — вёрстка PDF-отчётов: правки по образцам владельца

**Что изменилось** (`apps/api/src/lib/reportPdf/*`, только вёрстка; рассылка и получатели не тронуты):
1. «Динамика» (график + таблица) и «Расходы по статьям» — неразрывные блоки (`Section together`), таблица не рвётся.
2. «Итого» никогда не отрывается от строк: последняя строка и «Итого» идут одним неразрывным куском; шапка короткой таблицы держится с первыми строками.
3. «Откуда приходят клиенты» и прочие короткие разделы — целиком на странице; пустой страницы с шапкой и одной строкой больше нет.
4. «с..»: убрана лишняя точка после суммы (`money()` уже заканчивается на «с.»).
5. Стрелка «→» в шапке колонки заменена словами «Из заявки в сделку»; перенос строки в обложке — отдельными `Text` (символа перевода строки нет в Onest, движок брал Helvetica).
6. Логотип в шапке страниц 20×25 → 38×48 pt.
7. Весь мелкий текст (подсказки, легенды, оси, подвал) — не мельче 9 pt.
8. Идущий месяц: график «Динамика» вместе со своей таблицей.

**Сторож:** `apps/api/tests/report-pdf-layout.test.ts` (+ тестовые данные `tests/helpers/reportPdfSample.tsx`): нет «с..», все символы текста есть в Onest, в PDF нет невшитых шрифтов (BaseFont только Onest*), нет почти пустых страниц (pdftotext, если установлен), в исходниках нет `fontSize` < 9.

**Проверено:** образцы на тестовых данных и кадры — `docs/design/pdf-samples-27-11/v2/`; `pdffonts`: все шрифты вшиты; сборка api, тесты reportPdf.

**Осталось:** в версии за идущий месяц страница «Расходы по статьям» заполнена наполовину (раздел не влезает на стр. 2 целиком, а рвать его не хотим); таблица «Выплаты агентам»/«Команда» из 12 строк может уйти на следующую страницу без повтора шапки.
