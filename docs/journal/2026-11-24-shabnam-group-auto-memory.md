# 24.11.2026 — Шабнам в группах: память включается сама

Жалоба владельца: «в группе она как без памяти, новички пишут, она молчит». ФАКТ (прод, чтение): в рабочей группе (подключена 23.11) `AssistantTelegramGroup.contextEnabledAt` = null, `contextIncludeUnlinked` = false, память 0 строк; в коде эту память не включал никто (включена руками в базе только первая группа, 04.11).
Правка: `captureAssistantTelegramContext` при первом сообщении подключённой группы сам ставит `contextEnabledAt` и `contextIncludeUnlinked=true` (одним атомарным updateMany по `contextEnabledAt: null`). Рубильник `ASSISTANT_GROUP_AUTO_MEMORY` (пусто = включено, 0 выключает), проброшен в `docker-compose.prod.yml`. Память копится с этого момента, задним числом не восстанавливается.
Проверено: assistant-group-context (+2 новых теста: автовключение и рубильник), env-reaches-container, 5 файлов тестов группы на стенде. `assistant-telegram.test.ts` «группа не подключена — молчит» падает и без этой правки (бот 23.11 отвечает подсказкой); не моё, нужен отдельный разбор.
