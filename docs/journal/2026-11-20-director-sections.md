# 20.11.2026 — Разделы директора в новом виде: отчёты, реклама, деньги, контроль (пачка E)

- Что изменилось:
  - **Отчёты.** Воронка была из событий периода по их собственным датам (новые
    карточки, показы, начатые и закрытые сделки) — шаги про разных людей, отсюда
    «Переговоры 4 при Показах 0» и оговорка «может быть больше 100 %». Ошибка была
    в расчёте, а не в подписи. Теперь `GET /reports/funnel` отдаёт ещё `cohort`
    (`lib/teamReports.ts → buildFunnelCohort`): заявки периода и сколько из них
    дошло до шага или дальше к сегодняшнему дню — шаг не больше предыдущего по
    построению. Экран и PDF по команде рисуют воронку из него; плитки итогов
    периода (заявки, показы, сделки, комиссия) остались прежними. Рейтинг по
    агентам — только продающие роли (`SALES_AGENT_ROLES`); кто закрыл сделку в
    периоде (директор сам), остаётся строкой, чтобы сумма сходилась с итогом
    (C17). «Лиды» → «заявки», склонения через `pluralizeRu` («2 заявки»). Новый вид:
    одна строка вкладок (быстрые ссылки второй строкой убраны), «Спрос и
    предложение» свёрнут в одну строку-вопрос.
  - **Реклама** (новый вид). Не подключена — одна строка «не подключена» с кнопкой
    «Подключить», без плиток, списков и выбора периода. Подключена — четыре цифры
    из уже приходящего ответа доски (`totals.leadStats`): потрачено, цена заявки,
    цена сделки, окупаемость; сравнение с прошлым отрезком той же длины — та же
    доска за явные даты (`lib/adsCompare.ts`, `useAdsBoardRange`). «Сегодня /
    обычно / прогноз» — одной строкой. Вкладка «Привязать» → «Без объекта».
  - **Деньги** (новый вид). Над «Расходами», «Выплатами» и прочими — строка «Доход
    компании · Расходы · Прибыль/Убыток» со сравнением с прошлым месяцем
    (`RoyalMoneyStrip`, данные из `/expenses/summary` — сервер отдаёт только с
    `finance.view`). В строке вкладок четыре главных; «Подписки», «Календарь»,
    «Таблица», выгрузки и категории — в «⋯» и на компьютере.
  - **Контроль руководителя.** Нулевые плитки серые (`tileTone` → `ry-tile-calm`),
    срочные по-прежнему красные. В новом виде пустые срезы не рисуются, а
    перечислены одной строкой «Всё спокойно: …»; без сводки (грузится или сбой)
    показываются все — сбой не выглядит спокойствием. Жаргон заменён: «Тишина после
    показа» → «Пропали после показа», «Вечные переговоры» → «Переговоры по кругу»,
    «Отказ при хорошем скоринге» → «Отказались, хотя клиент был хороший», «Серия у
    одного агента» → «Агент теряет клиентов подряд», «Маршруты передач» → «Кто
    кому чаще передаёт клиентов». У строк «Не связывались» и «Пропали после показа»
    — «N дней без контакта».
- Почему: разбор кадров 20.11 (`docs/design/oblik-2026-11-17/audit-20-11/critic-director-rop.md`,
  п. 3–5, 7), план волны 2, пачка E: директору — самое нужное сразу и понятно,
  хорошо это или плохо, без нулевого шума и жаргона.
- Чем проверено: `apps/api/tests/reports-funnel-cohort.test.ts` (когорта 4→3→2→2→1 и
  рейтинг без акционера; сторож проверен поломкой — без фильтра ролей красный) и
  соседние тесты отчётов и PDF; `test:web` целиком (434 файла); новые тесты
  `adsCompare.test.ts`, `AdsDirectorTiles.test.tsx`, дополнены
  `Reports.clean.test.tsx`, `Finance.royal.test.tsx`, `ControlScreens.test.tsx`;
  e2e `new-look-director-sections.spec.ts` на 390 и 1440 (10 из 10). Кадры до/после,
  светлая и тёмная: `docs/design/oblik-2026-11-17/director-sections/` (в основной папке).
- Что осталось: окупаемость считается по комиссии рекламных клиентов из доски
  (когорта карточек периода) — сделки, закрытые позже, подтянутся только при
  пересчёте периода; на стенде рекламы нет, вид «подключено» проверен на
  подменённых данных. Кнопки выгрузок «Отчётов» на телефоне всё ещё стоят над
  цифрами. «Дни без контакта» у «Не связывались» считаются от создания карточки
  (контакта не было ни разу), сортировки по ним сервер пока не даёт.
