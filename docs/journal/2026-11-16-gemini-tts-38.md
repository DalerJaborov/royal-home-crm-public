# 16.11.2026 — Озвучка ассистента переведена на Gemini 3.8 TTS

- Что изменилось: цепочка моделей озвучки по умолчанию теперь `gemini-3.8-flash-lite-tts`, запасная `gemini-3.8-flash-tts` (раньше одна `gemini-2.5-flash-preview-tts`). `GEMINI_TTS_MODELS` и `GEMINI_WHISPER_TTS_MODELS` проброшены в api и worker через docker-compose.prod.yml. В `.env.example` убрана `gemini-2.5-flash-lite` (резерв теперь `gemini-3.5-flash-lite`).
- Почему: Google отключает 2.5 TTS 18.12.2026; «да» владельца 16.11.2026. Две модели в цепочке, чтобы 404 одной не обрывал озвучку; сменить модель можно правкой `.env.production` без выката кода.
- Чем проверено: тесты `tests/gemini-tts-models.test.ts` (выбор цепочки, переход к запасной на 404), `tts-quota-pause`, precheck --no-tests. Имена моделей сверены с aistudio.google.com/docs/models. Живой вызов не делался: в `.env` проекта нет ключа Gemini.
- Что осталось: прослушать озвучку таджикского и русского на проде; цепочку телефонной подсказки (`GEMINI_WHISPER_TTS_MODELS`, умолчание `gemini-3.1-flash-tts-preview`, легаси) сменить после проверки таджикского живым вызовом.
