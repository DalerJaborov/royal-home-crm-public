# 2026-11-25 — «Отправить объект» в чате видно всегда (фаза 2, шаг 1)

Владелец: «в переписке была кнопка „Отправить объект“, сейчас её нет».
Причина (ФАКТ по коду): в новом виде чата пункт «Объект из базы» в скрепке рисовался только у
диалога с карточкой клиента (`clientId && clientShortId`); у «Продавца из WhatsApp» без карточки
он молча пропадал, а сторож `chatCapabilitiesBothWidths` проверял только импорт `ChatPropertySend`.

Сделано: круглая кнопка-здание рядом со скрепкой (`data-testid="chat-send-property"`); пункт в
скрепке виден всегда; без карточки оба серые и по нажатию объясняют «Сначала примите заявку…».
Сторож проверяет видимый триггер и отсутствие условия вокруг пункта (проверен внесением поломки).

Проверено: tsc web, `chatCapabilitiesBothWidths` 9/9, стенд ПК и телефон.

Осталось (фаза 2 дальше): компактная шторка выбора «Мои / Рекомендуем / Все», карточка объекта
клиенту фото+подпись по каналам, быстрые ответы чипами.
