# Карточка клиента: уборка без нового каркаса (22.11.2026)

Решение владельца: новый макет карточки не нравится, раскладка и вкладки остаются как есть, только уборка и выравнивание. Кадры до/после: `docs/design/oblik-2026-11-17/card-tidy/` (before/after, 390 и 1440, один и тот же засеянный клиент).

## Убрано (данные в базе не тронуты)
- Блок «Запрос покупателя», «Уточнить пожелания», «Взять из разговора», раскрывашка «Из разговора и пожелания клиента»: файл `ClientBuyerRequirementsEditor.tsx` и его тест удалены. Пути сервера (`buyer-requirements`, `requirements-suggestion`) остались. Править пожелания можно через «Изменить данные».
- «Следующий шаг · Пока не назначен» (`ClientNextStep`): вместо него `ClientCardActions` только на телефоне («Назначить показ»); на ПК кнопка уже в шапке.
- В подборе: строка «Показано N из N. Сначала самые подходящие», подсказка «Выберите до 5 объектов», дубль кнопки «Посмотреть каталог (свободные)» в пустом состоянии. Счётчик остался на кнопке «Отправить · N».
- Плашка «Шанс сделки · NN/100» из шапки блока «Всё о клиенте»: теперь тихой строкой рядом с «Обновлено».
- Чипов «позвонить сейчас/первый звонок» и «попытка N из M» в карточке клиента в этой ветке нет (убраны раньше, #374/светофор).

## Приведено в порядок
- «С сайтов объявлений»: одна строка пояснения, метка «С сайта» у каждой строки, цена справа, WhatsApp/номер/объявление маленькими значками справа (44 px цель нажатия), строки разделены. Кнопки общие с другими экранами (`MarketWhatsAppButton`, `MarketShowPhoneButton`): новый режим `compact`, остальные экраны не изменены.
- «Заявка ждёт принятия» / «Новая заявка назначена вам»: тексты короче, кнопки те же.
- Удалены стили убранных блоков, `gen:typeset` пересобран.

## Рубильник
«Кнопка «Записать результат» в карточке клиента»: `clientRecordResultEnabled`, реестр `packages/shared/src/automationSwitches.ts` (группа «ИИ решает за агента»), колонка `Settings` по умолчанию `false` (миграция `20261122100000_client_record_result_switch`), отдаётся и рядовым сотрудникам (`toStaffSettings`). Выкл: кнопки нет ни в меню «Ещё», ни под кнопками на телефоне.
