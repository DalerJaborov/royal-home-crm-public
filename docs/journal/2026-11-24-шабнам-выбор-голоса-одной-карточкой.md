# 24.11.2026 — Шабнам: выбор голоса одной карточкой, кнопки называют то, что делают

- Что изменилось: выбор голоса для «Озвучь текст» (`telegram/assistantFreeNarration.ts`) теперь одна карточка-сообщение:
  образец-плеер с именем голоса, под ним подпись (имя, пол, «2 из 8», «рекомендуем» / «вы выбирали его в прошлый раз»,
  начало вашего текста) и кнопки. «Предыдущий / Следующий», «Все голоса / Женские / Мужские» и язык правят это же
  сообщение (`editMessageMedia` подменяет файл на месте), а не шлют новый файл и новое сообщение. Главная кнопка
  называется «🎙 Озвучить этим голосом» (раньше «✅ Выбрать»: по нажатию озвучка запускается сразу и тратит кредиты, а
  название этого не говорило). «Отмена» и «Озвучить» убирают карточку: вместо неё короткая строка («Отменено»,
  «Готовлю озвучку …»), а когда файл пришёл, строка «готовлю» удаляется, и в чате остаётся один mp3.
  Новый модуль `telegram/voicePickerCard.ts` (передача в Telegram: file_id образца запоминается, нажатия по одному
  сообщению идут по очереди, заменённую карточку помечает, чтобы запоздавший тап не создал вторую); в `telegram/api.ts`
  добавлены `sendAudioCard` и `editAudioCard` (файл с диска, байты, file_id; свой Bot API через общий том).
  Если подмена невозможна (у голоса нет образца, правка не прошла), новая карточка отправляется первой, и только потом
  прежняя удаляется.
- Почему: владелец 24.11 (скриншот чата): кнопки путают, прежние сообщения не удаляются, выглядит некрасиво.
- Чем проверено: `free-narration-draft.test.ts` (текстовая карточка листается на месте; карточка-плеер подменяется
  `editAudioCard` без второго файла; сбой правки → сначала новая, потом удаление, двойной тап молчит; отмена; выбор голоса:
  карточка и строка «готовлю» удалены, остался файл), новый `telegram-audio-card.unit.test.ts` (что уходит в Telegram),
  `free-narration.test.ts`. Живой проверки в Telegram ещё не было.
- Что осталось: «Другой голос» в карточке озвучки объекта (`nar:v`) и «Послушать образцы» (`fnr:s`) остались прежними
  (список кнопок и пачка файлов); их стоит свести к той же карточке. В `free-narration.test.ts` падает
  `REST … готовая озвучка отдаётся ссылкой` (404 вместо 200) — падает и на чистом `main`, к правке не относится.
