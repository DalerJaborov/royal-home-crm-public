# Ссылки в ответе Шабнам о монтаже

Шабнам может показать ссылку из результата проверки статуса объекта или очереди. Ссылки из текста, чужих полей и результата с ошибкой по-прежнему не проходят проверку. При невозможности проверить ссылку ответ приходит на выбранном языке.

Две машины полного прогона потеряли соединение при скачивании Prisma. Установка зависимостей в этом прогоне допускает одну повторную попытку. Для выпуска по-прежнему обязательны все тесты.
