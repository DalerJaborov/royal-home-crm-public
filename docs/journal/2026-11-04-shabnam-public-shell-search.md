# Shabnam public shell listing search

- Added a bounded anonymous Royal Home catalogue read for group replies. The reader projects only currently published, unsold cards and sends no group or customer data to the website.
- The Russian and Tajik shell query distinguishes an apartment from a private house and asks when the wording is ambiguous. Results require the shell stage and an unfinished repair label.
- Replies show at most three verified public cards. A failed catalogue read is distinguishable from an empty result.

Привязанный сотрудник по умолчанию ищет в CRM, включая неопубликованные объекты. Запрос явно про сайт и вопросы участников без привязки используют открытый каталог.
