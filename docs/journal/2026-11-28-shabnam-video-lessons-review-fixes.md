# 2026-11-28 Шабнам: видеоуроки, правки по слепому ревью

**Что.** Восемь замечаний ревью к `2026-11-28-shabnam-video-lessons.md`.

- Метка «урок уже отправлен» ставится только после успеха (`takeLessonSendSlot` возвращает `done(success)`); пока урок уходит, замок «отправляется». Сбой Telegram, aborted, нет файла снимают замок и возвращают место в минутном пределе. «Все уроки»: час отсчитывается с первого дошедшего сообщения (оглавления), провал на нём час не блокирует.
- Каталог: молчит только ENOENT («Уроки пока не загружены»). Нечитаемый манифест, битый JSON, не по схеме, плохой путь или симлинк наружу: ОДНА запись в журнал на загрузку кэша (`dedupKey: lessons-catalog-problem`), человеку «Уроки сейчас недоступны». `realpath` файла и обложки внутри `realpath` каталога (и при отправке тоже).
- Отказ Telegram 400/403: понятная фраза человеку, без записи в журнал и без повторной загрузки с диска (исключение: 400 «wrong file identifier» по file_id — грузим с диска). В «Все уроки» после такого отказа рассылка останавливается. Для этого `sendVideoFromDisk` теперь бросает `TelegramApiError` с кодом (`postMultipartWithRetry(..., typedErrors)`; текст ошибки тот же).
- Размеры видео: зашитые 1080x1920 убраны, `width`/`height` необязательно в manifest.json, без них в Telegram не передаются. Файл больше 50 МБ без `TELEGRAM_API_BASE_URL`: отказ без загрузки (+ запись в журнал с ключом).
- «Все уроки» в фоне проверяет `isShuttingDown()` перед каждым уроком, при обрыве одна строка в журнал и в консоль.
- `schema.prisma`: `LessonVideoCache` после `GeminiCache`, ссылка в комментарии на `lib/lessons/sender.ts`. Миграция не менялась.
- Промпт: блок `ASSISTANT_LESSONS_GUIDE` добавляется, только если актору объявлен `send_lesson` и каталог загружен (`lessonsGuideFor` в `ai/assistant.ts`).

**Проверено.** `tests/lessons-catalog.test.ts`, `tests/lessons-assistant-tools.test.ts`, `ai-assistant-tool-registry`, `build:api`, `map:check`.
