# 24.10.2026 — Остатки переписи экранов: зоны нажатия, выпадающий список, Настройки, набор номера, список клиентов

- Что изменилось (телефон 390, Android-UA, замер на стенде до/после):
  1. Вкладки `.seg-ai` («Команда», «Активность», «Вакансии»…): зона 40 → 44. Причина двойная: лента
     переносится на 2-3 строки (proto идёт позже royal-home и возвращает `flex-wrap:wrap`), накладки соседних
     строк при зазоре 4px делили его пополам; плюс запас ленты лежал под следующим блоком. Теперь зазор строк 8px
     (шаг 44), лента на своём слое, накладка `::before` на все `a/button[data-f]`. Кнопки `.pill.rh-btn.sm`
     дашборда: 43 → 45 (`inset:-2px` считался от внутреннего края рамки, теперь `--tap-pad`). `theme-2026-brand.css`.
  2. `SearchableSelect` («Кто принял объект», «Район»): шёл на Tailwind-утилитах, а `.rh2 .wiz button`/`.rh2 button`
     обнуляли рамку и отступы (зона 332×26, список без стиля). Переведён на классы `.rh-select*` (поле как `.fld input`:
     44px, рамка `--line-strong`; список — карточка с разделителями). Логика выбора, ARIA и Escape не менялись.
     Тест `components/SearchableSelect.test.tsx`.
  3. Настройки → «Деньги» и все вкладки: `.mod .acts{flex:none}` не давал кнопкам переноситься — «Обновить с alif.tj»
     уходило за экран (right=458). До 819px блок сжимается до ширины строки. Проверено: все вкладки Настроек без
     горизонтальной прокрутки (390 = 390), кнопка [32..193].
  4. Номеронабиратель: общее правило шторок `html[data-mobile-ux] [role=dialog]:not([data-no-sheet])` (вес 0-3-1) обнуляло
     нижний отступ листа (низ трубки = 844 из 844). Правило `.rh2 .scr .dp-back .dp` тяжелее: отступ 26px / 16px+безопасная зона.
  5. Список клиентов: `Row` уводил кнопку под текст при заголовке длиннее 40 знаков. Новый признак `compactAction`
     (одна круглая трубка) оставляет её справа в первой строке; имя переносится. `Row.test.tsx`.
- Почему: тестировщик на стенде нашёл остатки после основного PR переписи (#47).
- Чем проверено: стенд 5232/4732, `probe.cjs` (вкладки 44/45, кнопки 45, поле select рамка 1px, Деньги без прокрутки,
  набор 26px); `gen:typeset`+`audit:typeset`, `build:web`, `test:web` — коды 0.
- Что осталось: тот же механизм «общее правило шторок бьёт отступ своего листа» проверен по `role="dialog"`:
  окна с `data-no-sheet` (ассистент, входящая заявка) под него не попадают; остальные листы задают отступ внутренним блоком.
