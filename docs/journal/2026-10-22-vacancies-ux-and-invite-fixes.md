# 22.10.2026 — Подбор сотрудников: удобный экран, привязка анкет, починки приглашений

## Почему
Владелец: «по 4 штучки по вакансиям, а всего 250 с чем-то; у половины нет информации; сделай
удобно, все функции, печать, бесконечный скролл, удалить навсегда; ищи баги».
Прод 22.10 (чтение базы): 314 анкет, 305 без вакансии (старый бот вакансию не ставил, привязка
была только по одной анкете вручную), 249 в «Новых», 99 без имени/телефона/возраста/опыта,
191 без оценки цвета. Экран после #23 скрыл цвет оценки и не имел фильтра «без вакансии».

## Что изменилось
- Сервер (`routes/vacancies.ts`): фильтр `positionKey=__none`, счётчики `positionCounts` и
  `priorityCounts`, `POST /` (ручной кандидат, 409 на дубль телефона), `POST /bulk`
  (привязка к вакансии, этап, удаление), `DELETE /:id` — навсегда, только директор/админ
  (`lib/candidateErase.ts`, файлы стираются после транзакции). `interviewAt` только с поясом.
  Поиск по номеру без пробелов.
- Скрипт `apps/api/scripts/relink-job-applications-22-10.ts`: привязка старых анкет к вакансии
  по тексту (`lib/vacancyPick.ts`), дозаполнение пустых полей ИИ-извлечением засыпки, пересчёт
  цвета. По умолчанию план без записи, `--apply` пишет.
- Приглашения (`lib/recruitmentCommunications*.ts`): отказ звонка до набора больше не вешает
  кандидата в UNKNOWN навсегда; повтор того же приглашения после отказа разрешён; номер SMS через
  `toSmsPhone`; таджикский адрес для таджикского текста; проверка длины SMS и число частей;
  предупреждение, если звонок ассистента не успеет до встречи; ссылка на карту офиса по
  умолчанию (поиск Google Maps по настоящему адресу); SMS не ждут звонков в очереди;
  contact-options без блокировок; 2GIS в белом списке ссылок.
- Экран: чипы этапов, вакансий (в т.ч. «Без вакансии») и цвета со счётчиками; бесконечная
  лента; галочки и панель массовых действий; печать анкет (по листу А4 на анкету); «+ Кандидат»;
  собеседования сегодня; «Удалить навсегда» с вводом слова; все прежние действия и правка
  телефона; на телефоне анкета открывается на весь экран.
- `GET /vacancies/positions` пишет причину отказа в журнал ошибок.

`build:api`, `build:web`, `test:web` зелёные; 41 файл тестов сервера по разделу на своей базе —
