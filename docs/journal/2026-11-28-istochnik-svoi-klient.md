# 28.11.2026 — источник «Свой клиент» и группы в блоке «Откуда приходят»

**Просьба владельца:** в блоке «Откуда приходят» не все варианты / слишком много строк; добавить «когда агент сам находит клиента, а не пришёл в офис, просто свой клиент».

**Сделано**
- `ClientSource` + `OWN_CLIENT` («Свой клиент»): enum в `packages/shared/src/enums.ts`, `labels.ts`, фраза-заглушка в `clientDisplayName.ts`, Prisma-enum и миграция `20261128190000_client_source_own_client` (только `ADD VALUE`, старые строки не меняются; «Пришёл в офис» не перезаписан).
- Новый реестр `packages/shared/src/clientSourceGroups.ts`: группы для людей (Переписки / Звонки / Сайт / Реклама / Свои клиенты / Рекомендации / Пришли в офис), `groupSourceRows`, простые подписи для агента, `isAgentCreatedClientSource`.
- Блок «Откуда приходят» (`DirectorBlocks.tsx → SourcesBlock`) показывает группы; каналы внутри — в подстроке; «0 с.» не рисуется (нет комиссии — справа число заявок), сделки и процент — только если сделки есть. API и Excel/PDF по-прежнему отдают строки по каждому источнику.
- Форма клиента: новый клиент по умолчанию «Свой клиент»; у агента четыре понятных варианта (Свой клиент / Рекомендация / Позвонил сам / Пришёл в офис); у руководства — полный список, «Свой клиент» первым. Одна форма и для ПК, и для телефона.
- Шабнам/ассистент: `OWN_CLIENT` в фильтре поиска и в подсказке инструмента «создать клиента».

**Ловушка (учтена):** `WALK_IN` исторически значит ещё и «карточку завёл агент руками» (продавец при внесении объекта). Проверки «номер не подтверждён связью» (`ownerVerificationSources`, `sellerBypassProbe`, `sellerProbeCall`) теперь смотрят `isAgentCreatedClientSource` — и `WALK_IN`, и `OWN_CLIENT`, иначе «Свой клиент» выпал бы из проверок.
