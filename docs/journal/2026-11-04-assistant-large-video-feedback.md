# 04.11.2026 — Крупное видео объясняет ограничение Telegram

- Изменение: помощник сотрудника явно сообщает предел облачного Bot API для видео больше 20 МБ и предлагает загрузку через CRM. Сообщает, что файл не сохранился. Проверяются обычное видео, видеокружок и видео-документ по MIME или расширению. При локальном Bot API этот облачный предел не применяется.
- Причина: ночной аудит миграции обнаружил, что крупный ролик без подписи получал только реакцию, хотя скачать его из облачного Bot API невозможно. Локальный Bot API ещё не настроен из-за отсутствующих API ID/hash и выбранного образа.
- Проверка: два новых regression-сценария (video и MOV-документ) падали на прежнем коде: пояснения не было. После исправления прошли все 55 тестов Telegram-помощника и сборка API. Используются синтетическая PostgreSQL и заглушки Telegram; настоящие сообщения и платные вызовы не отправлялись.
- Осталось: штатный release и отдельная настройка локального Bot API после появления необходимых реквизитов. Поддержка скачивания крупных файлов не создаётся одной этой подсказкой.
