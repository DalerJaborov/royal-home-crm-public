# 07.11.2026 — Где Шабнам не справилась с поиском (разбор прод-журнала)

- Источник (ФАКТ, прод, только чтение): «Настройки → Система → Журнал ИИ-ассистента», 140 записей, первые 3 страницы
  (последние дни 05–07.11). Журнал хранит инструмент, аргументы и число найденного, но НЕ текст вопроса и ответа;
  дословные реплики из Telegram-группы здесь недоступны (см. «Что осталось»). Два провала владельца взяты из его слов.
- Номера телефонов и имена клиентов в разбор не вошли.

## Провалы по классам

1. **Корзина не искалась вообще.** Вопрос агента (со слов владельца): «найди в корзине удалённый объект около Ашана, была
   коробка». Журнал 07.11 12:07: `search_properties {stage:SHELL, locationNames:[Ашан], query:Ашан}` → 0, потом
   `find_property {ref:Ашан}` → 1, `search_properties {query:Ашан}` → 1 (живой ОБ-000161), `status:WITHDRAWN` → 4.
   Все инструменты ищут только `deletedAt: null`. Ответ: «корзину найти не получится». *Причина:* нет инструмента по Корзине.
2. **Ориентир не разбирается, только подстрока.** «хавли дом в стороне Воданасоса до 2,5 млн», 07.11 12:24–12:25: 7 вызовов
   `search_properties` подряд, из них 5 — по 0 записей (`query:"Воданасос"`, `"Водонасос"`, `locationNames:[Воданасос]` и т.д.),
   8 записей дал только `semanticQuery` без типа/ориентира, 4 — с добавленными районами Исмоили Сомони и Сино. Финал: «шагов не
   хватило», затем «вариантов нет», хотя в Сино дома были. *Причина:* поиск по тексту «Воданасос» в адресе/названии; народное
   название и его район/радиус (`folkPlaces`, `landmarks`) не используются; ни радиуса, ни расстояния.
3. **Тот же класс у Ноза, 05.11 13:05–13:06 («Караболо», «91 микрорайон»):** 6 вызовов подряд по разным написаниям
   (Караболо / Кара-Боло / 91-й микрорайон / 91 мкр) — почти все 0, 8 записей даёт только `type:APARTMENT` без места.
   Баходур 05.11 22:36 — «91 микрорайон» перебирал 4 написания в одном вызове (1 запись).
4. **Лимит шагов.** `MAX_TOOL_ROUNDS=4` (и 6 попыток к Gemini) кончался на переборе написаний ориентира; человек получал
   «Не удалось собрать ответ за разумное число шагов» и терял уже найденное.
5. **«Нет» без полной проверки.** Умед 05.11 21:07–21:10 («Колхози Россия», «Россия», «1070000»): 7 пустых поисков, ссылка
   Instagram → 0. Ни Корзина, ни карточки продавцов с этим ориентиром не проверялись (пустая карточка продавца с ориентиром
   — тоже находка: у «Ашана» есть ПР-000456 без объекта).
6. **Ошибки аргументов (мелкие):** Ноза 06.11 `find_clients {agentName:"me"}` → отказ; Далер 05.11 `get_client_card {clientId:"849"}`
   → отказ (номер вместо id). В этой правке не чинится.
