# 2026-11-18 — «Робот звонит собственнику»: выключатель гасит функцию целиком

## Что изменилось
- Выключатель `sellerProbeCallEnabled` («Работа с продавцами») раньше останавливал только
  звонки и проверки по показам (`lib/sellerProbeCall.ts`). Два других источника продолжали
  заводить черновики проверок (`SellerProbeCall`, `previewOnly`) мимо него:
  - `scheduleManualOwnerVerification` — при создании объекта на продавца «с улицы»;
  - `scheduleExposureOwnerVerifications` — ежечасно по отправленным покупателю объектам.
- Теперь оба спрашивают тот же выключатель. Сигнал расследования по покупателю
  (`recordInvestigationSignal`) по-прежнему пишется: это не звонок собственнику.
- Подпись «выкл»: «Робот собственникам не звонит и проверки не готовит.»

## Почему
Владелец 18.11.2026: «Выключи эту функцию полностью, она не нужна». На проде выключатель уже
стоит «выкл» (SQL по слову владельца), режим звонков `PREVIEW`, звонков не было ни одного.

## Чем проверено
- `tests/owner-verification-sources.test.ts` — 19/19; новый тест краснеет, если убрать проверку
  выключателя (проверено нарочной поломкой).
- `npm run precheck`.

## Что осталось
- Код функции не удалён. Строки на экране нет, поэтому включить обратно — правкой
  `SELLER_SWITCH_HIDDEN_KEYS` (вернуть строку) и щелчком.

## Дополнение: функцию не видно на экране
Владелец: «И саму видимость функции тоже убери, чтобы не было путаницы». На экранах объектов
её не было; убрана оттуда, где она была видна:
- «Работа с продавцами» — строка выключателя скрыта (`SELLER_SWITCH_HIDDEN_KEYS` в shared,
  экран берёт `SELLER_SWITCH_VISIBLE_KEYS`); колонка и проверка в коде остаются, значение «выкл».
- Настройки бота — переключатель «Звонить покупателю после показа» больше не обещает звонок
  собственнику ни в заголовке, ни в подсказке.
- Безопасность → «Предпросмотр новых проверок» — черновики проверок собственника не
  показываются, пока выключатель выключен (`GET /security/cases/automation-preview`).
- Тест `apps/web/src/pages/settings/__tests__/sellerSwitchesHidden.test.ts`.
