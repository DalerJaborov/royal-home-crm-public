# 28.10.2026 — Недвижимость продавца Somon

- Проверка продавца учитывает объявления о недвижимости, а другие товары и вакансии не считаются объектами.
- Объявление с одним или двумя объектами может быть отправлено без слов «я собственник», с просьбой подтвердить продавца при звонке.
- Неполные профили и неопределённые категории выделяются в отдельную ручную проверку; лимиты запросов Somon сохраняются.
- Подтверждение собственника и гарантированный охват всех объявлений площадки невозможны; нужны штатные проверки и наблюдение реального потока.
