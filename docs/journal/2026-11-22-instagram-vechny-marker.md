## После ревью (22.11.2026, независимый ревьюер PR #391)

- Что: подстраховка и тишина вокруг ключа компании.
  1. Ключ компании выбирался первым без подстраховки: отказ Meta в правах (10, 200–299) или в
     ключе (190/102, 401) ронял публикацию у всех, даже с живым личным ключом. Теперь сама
     публикация идёт через дверь `instagramPublisher.ts::publishViaInstagramPublisher`: отказ ключа
     компании на СОЗДАНИИ контейнера (или слайда карусели) — один повтор личным ключом (контейнера
     нет — дубля нет); на `media_publish` повтора нет. Код Meta приходит из `PublishResult.graphError`
     (`socialPublish.ts::InstagramGraphRefusal`, шаг `create`/`publish`). Истории: если ключ компании
     не ответил даже на лимит публикаций — серия идёт личным ключом. Неверный комментарий «не выбран
     — значит мёртвый личный ключ» исправлен.
  2. Новые права в «Маркере удаления Instagram» стали необязательными (`tokenScopes.ts::optional`):
     суточная проверка без них не ставит «сломан» и не будит директора; нехватка — припиской.
  3. 190 на маркере Страницы — `benchPage` (выдача забыта сразу, пауза 5 мин); отказ в правах —
     пауза ТОЛЬКО публикации на 30 мин (`noteCompanyPublishRefused`), переписка через Страницу не
     трогается. `instagramCompanyPublishRoute` учитывает обе паузы.
  4. Отказ ключу компании в правах — тревога руководству «к сведению», раз в сутки на Страницу
     (метка `ig-publish:<страница>`); мёртвый ключ — как раньше, директору (`meta-system-user`).
  5. Сторож `instagram-publisher-one-door.test.ts`: публикация — только внутри двери и её
     `igUserId, token`; лимит — `publisher.igUserId, publisher.token`. Проверен поломкой
     (`creds.igToken` в `photoPosts.ts` — красный).
  7. «Проверить права»: главный текст словами («Ключ компании пока не может: …»), `ads_*` —
     серое «Не обязательно», название права мелко под описанием. Ошибка ключа — русской фразой
     без кодов (`COMPANY_KEY_REJECTED_TEXT`), ответ Meta — только в журнал ошибок.
- Чем проверено: `build:shared`, `build:api`, `build:web` зелёные; 29 файлов тестов API по
  публикации, ключам и правам — 387 зелёных (`instagram-publish-company-key` 22, сторож 4);
  `map` + `map:check` совпадают.
- Чего тесты не ловят: живой ответ Meta системному пользователю без `ads_*` (НЕТ ДАННЫХ); паузы в
  памяти процесса (api и worker держат свои — отказ в worker не ставит паузу в api).
