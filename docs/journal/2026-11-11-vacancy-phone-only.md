# 11.11.2026 — вакансии: бот не обсуждает условия, даёт номер специалиста

## Что изменилось
- Решение владельца (10–11.11): бот не обсуждает с кандидатом условия работы и не задаёт анкету.
  Он называет открытую должность и пишет одну строку: «Всю информацию о работе даст по телефону
  наш специалист Ноза: 777 070 100. Позвоните, пожалуйста.» (тадж.: «Маълумоти пурраро дар бораи кор
  мутахассиси мо Ноза бо телефон медиҳад: …. Лутфан занг занед.»).
- Текст и номер — в одном месте: `packages/shared/src/recruitmentContact.ts` (`RECRUITMENT_CONTACT`,
  `recruitmentPhoneLine`). Номер совпадает с `COMPANY_PHONE_DIGITS`, поэтому маска номеров его не прячет.
- `ai/customerAgentRenderer.ts`: условия из каталога (`detailsRu/Tg`) кандидату больше не выводятся;
  вопрос для вакансии с открытыми позициями — `none` (нет «Какая должность…», резюме, анкеты); на
  повторном ходе после показа вакансии — только строка с номером.
- `ai/recruitmentRecoveryReply.ts`: досылка «не дождавшимся ответа» тоже заканчивается номером, без
  условий и без просьбы о резюме.
- Старые тесты, проверявшие выбор абзацев условий и анкетные вопросы, переписаны под новое поведение.
- Прод (отдельное «да» владельца): вакансия `real-estate-agent` переименована в «Менеджер по продажам
  недвижимости» / «Менеҷери фурӯши амволи ғайриманқул», revision 4→5, запись в AuditLog. Условия в
  каталоге не трогали — бот их больше не показывает.

Продолжает запись `2026-11-10-instagram-nick-guard-and-vacancy-reply.md` (там — вакансия без адреса).
