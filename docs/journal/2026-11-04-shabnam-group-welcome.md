# 04.11.2026 — Шабнам встречает коллег в Telegram

- Когда привязанный директор или администратор добавляет бота в рабочую группу, Шабнам подключается и один раз приветствует коллег на русском и таджикском. Новых участников встречает отдельно; близкие по времени входы не дублируют приветствие.
- Без обращения по имени она отвечает только на ясный вопрос по номеру объекта и только по карточке CRM. Обычные реплики, клиенты и действия по записи не запускают эту подсказку.
- «Шабнам, помолчи» останавливает инициативу на 30 минут, прямые обращения продолжают работать. Директор может полностью отключить её командой /assistant_off.
- Для коротких голосовых применяются уместные подсказки ElevenLabs: тёплая интонация, пауза или лёгкий выдох. Текст, правила доступа и лимиты сохраняются.
