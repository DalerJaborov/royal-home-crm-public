один модуль с памятью разговора; свободная модель ядра в этом режиме не
отвечает; тексты — из одного набора фраз.

- [ ] 1.1 Модуль `apps/api/src/ai/operator/`: `understand` (один

  удобное время; при сбое — запасные правила), `decide` (чистая функция:
  состояние + понимание + контекст → новое состояние, ключи фраз, действия),

  `BotConversation.leadOnlyPending`, версия 2, чтение версии 1 без падения).
  Тесты: каждая строка таблицы `SPEC.md` — тест `decide`; сторож фраз (нет
  «Рудаки», нет «—», не длиннее двух предложений, у каждого ключа обе версии).
  Исполнитель: `architect`.
- [ ] 1.2 Подключение: `lib/customerLeadOnlyCore.ts` (`planCustomerLeadOnlyTurn`)

  существующим приёмом (`customer-lead-only-intake`, `acceptLead`) с объектом

  недостижимыми, удалить в этой же правке. Рубильник один: `botLeadOnlyMode`.
